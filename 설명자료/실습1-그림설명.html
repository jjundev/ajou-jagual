01 · 먼저 게임의 규칙

로봇은 → 또는 ↑로 한 칸씩 가요.

출발점은 (0,0). 좌표 (x,y)는 오른쪽으로 x칸, 위로 y칸인 자리예요.

→ → ↑

(0,0) → (1,0) → (2,0) → (2,1)

어느 순간에도 y가 x보다 커지면 안 돼요.
대각선 y=x 위쪽은 출입 금지예요.

목적지만 검사하는 게 아니에요. 지나가는 모든 좌표가 x ≥ y여야 해요.

자료: PDF 2–4쪽. 0축은 뒤에서 재귀를 멈추는 기준으로 사용합니다.

03 · 마지막 한 걸음의 비밀

도착 직전에는 어디에 있었을까요?

왼쪽에서 오는 길과 아래에서 오는 길은 마지막 방향이 달라요. 겹치지 않으므로 그냥 더하면 됩니다.

f(x,y) = f(x−1,y) + f(x,y−1)

f(x,y)는 “(0,0)에서 (x,y)까지 규칙을 지켜 가는 길의 수”예요.

실제 로봇은 →·↑로 이동하지만, 계산은 목적지에서 왼쪽·아래를 되짚어 물어봅니다.

자료: PDF 5쪽. 그림의 (7,4) 왼쪽에 쓰인 ‘6,3’은 수식과 위치상 ‘6,4’의 오기로 보이며, 여기서는 (x−1,y)로 설명합니다.

04 · 언제 질문을 멈출까요?

이미 답을 아는 두 경우가 있어요.

0개

출입 금지인 좌표

y < 0 또는 x < y
예: (1,2)는 갈 수 없어요.

1개

바닥줄에 있는 좌표

유효한 좌표에서 y == 0
예: (3,0)은 →→→ 한 가지뿐.

(0,0)도 아무 이동도 하지 않는 방법 1개로 셉니다.

① 금지 좌표?
0을 돌려줘요.
② 바닥줄?
1을 돌려줘요.
③ 그 외에는?
작은 답 두 개를 더해요.

이 멈춤 규칙을 기저 조건이라고 해요. 매번 x나 y가 1 줄어 결국 멈춤 규칙에 도달합니다.

자료: PDF 3–4, 14쪽. 금지 조건부터 검사하면 (-1,0) 같은 좌표도 0으로 처리됩니다.

05 · 재귀는 작은 나에게 물어보기

“(2,2)는 몇 개?”를 잘게 나눠요.

f(2,2)
↙　↘
f(1,2) = 0
금지 좌표라 즉시 끝!
f(2,1)
f(1,1) + f(2,0)
= 1 + 1 = 2
f(1,1)이 1인 이유도 펼쳐 보기

f(1,1) = f(0,1) + f(1,0)
= 0 (금지 좌표) + 1 (바닥줄)
= 1

작은 답이 돌아오면: f(2,2) = 0 + 2 = 2

함수가 자기 자신을 다시 호출하는 것이 재귀예요. 호출할 때마다 별도의 x, y를 가진 작은 계산이 시작됩니다.

자료: PDF 6–8, 13–14쪽.

06 · 숫자 지도를 눌러 보세요

내 숫자 = 왼쪽 숫자 + 아래 숫자

0~7 중 선택

선택한 목적지는 노랑, 두 이웃은 연두로 표시해요. 대각선 위는 0입니다.

07 · 이제 C 코드로 옮겨요

빈칸에 들어갈 것은 세 가지 규칙.

아래는 설명용 구현입니다. 원본 Practice 1.c는 수정하지 않았습니다.

int catalan(int x, int y)
{
    if (y < 0 || x < y)  // 갈 수 없는 곳
        return 0;

    if (y == 0)           // 바닥줄: 길은 하나
        return 1;

    return catalan(x - 1, y)
         + catalan(x, y - 1);
}
기호 번역

|| : 둘 중 하나라도 참
== : 같은지 확인
return : 답을 돌려주고 이번 호출 끝

원본의 result는?

지금은 0으로 초기화하고 그대로 반환하므로 항상 0이에요. 위 구현은 답을 바로 반환해 result가 필요 없어요.

원본의 result 틀을 유지한다면
int result = 0;
if (y < 0 || x < y)
    result = 0;
else if (y == 0)
    result = 1;
else
    result = catalan(x - 1, y)
           + catalan(x, y - 1);
return result;
함수맡은 일
main좌표 입력 → 두 방식으로 계산 → 출력 → 반복
catalan직접 작성할 함수. 재귀로 길의 수 계산
combination조합을 계산하는 보조 함수
catalan_comb조합 공식으로 비교용 답 계산

실습 목표는 catalan 안에서 catalan을 다시 호출하는 것입니다. 조합 공식을 그대로 부르는 것으로 대체하지 않아요. PDF는 비교용 함수 내부는 이해하지 않아도 된다고 안내합니다.

자료: PDF 10–14쪽 및 Practice 1.c.

왜 큰 숫자는 나중에 다룰까요?

단순 재귀는 같은 좌표를 여러 번 계산해 입력이 커질수록 느려져요. 또한 원본의 int와 long long은 저장할 수 있는 정수 크기가 정해져 있습니다. 먼저 자료의 작은 좌표로 확인하세요.

원본 main은 숫자 두 개가 정상 입력된다고 가정합니다. 종료 실험에는 문자 대신 2 4나 0 -1을 넣으세요.

스스로 확인: f(3,2)는 몇 개일까요?

f(3,2) = f(2,2) + f(3,1) = 2 + 3 = 5.
