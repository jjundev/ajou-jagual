# 값과 주소는 어떻게 전달될까?

0928 강의 개념을 함수 호출의 저장 공간 변화로 확인한다.

C는 항상 값을 전달합니다. 포인터 인자도 주소 값의 복사이고, 그 주소를 따라가면 원본에 쓸 수 있습니다.

기본 입력과 전체 preset을 확인한다. 정수 범위 -99..99, 기호 주소. 값 전달도 주소 전달도 C의 인자 값 복사다.

원본 swap 본문은 p22와 일치한다. 비교 함수·호출자·NULL 진단은 보충 예제다. 원본 구형 main()은 근거에 보존하고 검산용 source.c에 int main(void)와 헤더를 사용한다. 독립 검산은 컴파일러 부재로 Python 표를 사용한다. UB는 실행하지 않는다.
