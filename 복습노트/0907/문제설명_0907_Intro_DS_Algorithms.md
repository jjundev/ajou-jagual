### P1. 두 정수 바꾸기

textbook-ch01-q01 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0907_Intro_DS_Algorithms.html#p1)

#### 주어진 조건

2개의 정수를 서로 교환하는 알고리즘을 의사 코드로 작성해보자.

#### 기출 원문

1장 자료구조와 알고리즘 · 01번 · 책 36쪽

2개의 정수를 서로 교환하는 알고리즘을 의사 코드로 작성해보자.

#### 문제를 내 말로 읽어요

원래 a와 b의 값을 서로 바꿔요. 한 값을 덮어쓰기 전에 보관할 곳이 필요해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“서로 교환”은 swap이에요. 대입은 오른쪽 값을 읽어 왼쪽 저장소를 바꾸므로, 임시 변수 temporary variable로 옛 a를 보존해야 해요.

#### 종이에 적을 첫 줄

`temp ← a`

#### 왜 이렇게 푸는지 함께 따라가요

`temp ← a
a ← b
b ← temp`

#### 완성 답과 검산

a=3,b=8에서 temp=3 → a=8,b=8 → a=8,b=3이에요. 임의의 옛 값 A,B도 최종 a=B,b=A이므로 두 조건을 만족해요.

#### 이 문제에서 조심할 점

a←b 다음 b←a를 쓰면 원래 a가 이미 사라져 두 값이 같아져요.

#### 설명을 닫고 다시 해 봐요

1. temp ← a
2. 임시 보관 → a에 b → b에 옛 a
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

temp ← a

#### 떠올릴 개념·공식

임시 보관 → a에 b → b에 옛 a

#### 검산

본문의 조건과 독립 추적을 함께 확인해요.

### P2. 두 정수 중 큰 수

textbook-ch01-q02 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0907_Intro_DS_Algorithms.html#p2)

#### 주어진 조건

사용자로부터 받은 2개의 정수 중에서 더 큰 수를 찾는 알고리즘을 의사코드로 작성해보자.

#### 기출 원문

1장 자료구조와 알고리즘 · 02번 · 책 36쪽

사용자로부터 받은 2개의 정수 중에서 더 큰 수를 찾는 알고리즘을 의사코드로 작성해보자.

#### 문제를 내 말로 읽어요

두 정수를 읽어 큰 쪽을 내보내요. 같은 값이면 어느 쪽을 골라도 같은 최댓값이에요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“더 큰 수”는 comparison과 selection의 단서예요. a≥b와 a&lt;b는 가능한 입력을 겹치지 않게 전부 나눠요.

#### 종이에 적을 첫 줄

`read a, b`

#### 왜 이렇게 푸는지 함께 따라가요

`read a, b
if a >= b then output a
else output b`

#### 완성 답과 검산

3,8→8; 8,3→8; -2,-7→-2; 4,4→4예요. 두 분기에서 출력이 두 입력 이상이며 실제 입력 중 하나이므로 max의 정의를 만족해요.

#### 이 문제에서 조심할 점

초기 최대값을 0으로 두면 음수 두 개에서 잘못된 답이 나와요.

#### 설명을 닫고 다시 해 봐요

1. read a, b
2. 입력 두 개를 비교해 큰 값 선택
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

read a, b

#### 떠올릴 개념·공식

입력 두 개를 비교해 큰 값 선택

#### 검산

### P3. 1부터 n까지 더하기

textbook-ch01-q03 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0907_Intro_DS_Algorithms.html#p3)

#### 주어진 조건

1부터 n까지의 합을 계산하는 알고리즘을 의사 코드로 작성해보자.

#### 기출 원문

1장 자료구조와 알고리즘 · 03번 · 책 36쪽

1부터 n까지의 합을 계산하는 알고리즘을 의사 코드로 작성해보자.

#### 문제를 내 말로 읽어요

1부터 양의 정수 n까지 빠짐없이 더하는 알고리즘이에요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“1부터 n까지”는 누적 합 accumulator의 단서예요. 합의 항등원은 0이고 각 반복에서 현재 i를 정확히 한 번 더해요.

#### 종이에 적을 첫 줄

`sum ← 0`

#### 왜 이렇게 푸는지 함께 따라가요

`sum ← 0
for i ← 1 to n
    sum ← sum + i
output sum`

#### 완성 답과 검산

n=4에서 sum은 0→1→3→6→10이에요. i까지 끝났을 때 sum=1+…+i라는 불변식이 초기·유지·종료를 만족해요. 별도 공식 n(n+1)/2도 10을 주어요.

#### 이 문제에서 조심할 점

i&lt;n으로 반복하면 n을 빼먹어요. C로 옮길 때는 합이 정수 타입 범위 안에 있어야 해요.

#### 설명을 닫고 다시 해 봐요

1. sum ← 0
2. 0에서 시작해 1..n 누적
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

sum ← 0

#### 떠올릴 개념·공식

0에서 시작해 1..n 누적

#### 검산

본문의 조건과 독립 추적을 함께 확인해요.

### P4. 큐에서 꺼내는 순서

textbook-ch05-q01 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0907_Intro_DS_Algorithms.html#p4)

#### 주어진 조건

문자 A, B, C, D, E를 큐에 넣었다가 다시 꺼내어 출력하면 어떻게 되는가?

(a)

A, B, C, D, E

(b)

E, D, C, B, A

(c)

A, B, C, E, D

(d)

B, A, C, D, E

#### 기출 원문

5장 큐 · 01번 · 책 171쪽

문자 A, B, C, D, E를 큐에 넣었다가 다시 꺼내어 출력하면 어떻게 되는가?

(a)

A, B, C, D, E

(b)

E, D, C, B, A

(c)

A, B, C, E, D

(d)

B, A, C, D, E

#### 문제를 내 말로 읽어요

A부터 E까지 차례로 큐에 넣고 모두 꺼내요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“큐(queue)”는 먼저 온 것이 먼저 나가는 FIFO의 단서예요. enqueue는 뒤(rear)에 붙이고 dequeue는 앞(front)에서 꺼내요.

#### 종이에 적을 첫 줄

첫 삭제 직전 큐를 [A,B,C,D,E]로 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

정답이에요. 앞에서 차례로 삭제하면 A→B→C→D→E예요.

E부터 꺼내는 것은 스택의 LIFO예요. 큐의 첫 삭제 A와 달라요.

처음 세 글자는 맞지만 D가 E보다 먼저 들어왔으므로 끝 두 글자를 바꿀 수 없어요.

B가 A보다 먼저 나가면 먼저 들어온 A를 건너뛰므로 FIFO를 위반해요.

#### 완성 답과 검산

다섯 삭제 뒤 큐는 빈 상태이고 출력은 ABCDE예요.

첫 출력만 비교해도 E≠A로 배제돼요.

네 번째 삭제는 D여야 하므로 E가 나오는 보기를 배제해요.

첫 삭제가 A여야 하므로 B가 나오는 보기를 배제해요.

#### 이 문제에서 조심할 점

큐와 스택을 혼동하지 않아요. 보기 a~d를 각각 비교하되 답은 하나예요.

#### 설명을 닫고 다시 해 봐요

1. 첫 삭제 직전 큐를 [A,B,C,D,E]로 적어요.
2. FIFO → (a) ABCDE
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

첫 삭제 직전 큐를 [A,B,C,D,E]로 적어요.

#### 떠올릴 개념·공식

FIFO → (a) ABCDE

#### 검산

본문의 조건과 독립 추적을 함께 확인해요.
