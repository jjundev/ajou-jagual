정답: (a) 벽돌 자체는 데이터, 벽의 구조는 자료구조, 쌓는 절차는 알고리즘이며, 알고리즘은 유한한 명령의 순서여야 종료 후 올바른 결과를 낸다. (b) 새 해결 방법을 고르면 설계, 주어진 방법의 비용을 평가하면 분석이며, 시간·공간 비용 절감과 가독성·재사용성을 통한 유지보수 비용 절감을 함께 고려해야 한다.

코드가 짧다는 사실만으로 실행이 빠르다고 결론내리지 않아요. 가독성과 실행 비용은 별도로 판단해요.

지역 변수가 언제나 공간을 절감한다는 절대 명제는 틀려요. 주소로 넘긴다고 호출자 객체의 복사본이 새로 생기는 것도 아니에요.

int find_max_score(int n)
{
    int i, tmp;
    tmp = score[0];
    for(i=1;i<n;i++){
        if(score[i] > tmp) tmp = score[i];
    }
    return tmp;
}
  1. (a) find_max_score(4)를 실행할 때 tmp의 값 변화와 최종 반환값을 쓰세요.
  2. (b) tmp = 0으로 초기화할 때 생기는 오류와, 이 함수가 유효한 알고리즘으로 유한하게 종료하기 위한 n의 조건 및 종료 이유를 설명하세요.
