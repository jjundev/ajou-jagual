코드가 짧다는 사실만으로 실행이 빠르다고 결론내리지 않아요. 가독성과 실행 비용은 별도로 판단해요.

### P6. 지역 변수·함수 분리와 자원 공유

**강의 예제 기반 자체 출제** S1 p7 · 추가 근거 p6

한 함수 안에서만 필요한 큰 임시 배열을 전역 변수로 두는 설계와 그 함수의 지역 변수로 두는 설계를 비교하세요. 모든 지역 변수가 언제나 전역 변수보다 메모리를 적게 쓰는지, 재귀 호출에서도 그런지 설명하세요. 읽기 쉬운 함수로 작업을 나누고 큰 원본을 복사하지 않고 주소로 공유할 때의 장점과 공유값 변경의 주의점도 쓰세요. 재귀 부분은 메모리 판단을 위한 보충 조건이에요. 추가로, int를 unsigned int로 바꾸면 바이트 크기가 줄어드나요? 원소 10개만 필요한데 100칸 배열을 잡으면 사용하지 않는 칸이 몇 개인지도 쓰세요.

<details><summary>강의 예제 보기</summary>

</details>

<details><summary>힌트 보기</summary>

누가 쓰는가·언제까지 필요한가·동시에 몇 개가 존재하는가의 세 칸을 적어요.

</details>

<details><summary>풀이 보기</summary>

1. 한 함수에서만 쓰는 임시 자원의 필요 범위부터 정해요.
2. 전역 객체의 수명은 전체 실행이고 자동 지역 객체는 블록 진입·종료에 따라 존재해요.
3. 여러 호출이 동시에 활성인 경우 각 호출의 자동 객체가 별도로 필요해요.
4. 역할별 함수 이름은 흐름을 드러내고 주소 공유는 한 원본을 함께 보게 해요. 공유 변경이 다른 사용자에게 전파되는지도 확인해요.
5. 타입의 값 범위와 크기는 구별해요. int와 unsigned int는 같은 크기이며, 100칸 중 실제 필요한 10칸을 빼면 90칸이 남아요.

**정답:** 임시 배열은 필요한 범위에 지역화하면 접근 범위와 수명을 제한할 수 있어요. 전역 객체는 프로그램 실행 동안 존재해요. 지역 변수라고 항상 메모리가 줄지는 않으며 동시에 활성인 재귀 호출마다 별도 배열이 있으면 공간이 늘어요. 함수 분리는 역할을 읽고 재사용하기 좋게 하고 주소 공유는 원본 복사 비용을 줄이지만 다른 사용자가 보는 값도 바뀔 수 있어요. unsigned int와 int의 크기는 같아서 부호 없는 타입으로 바꾸는 것만으로 공간이 줄지 않아요. 필요한 10칸 대신 100칸을 잡으면 90칸이 남아요.

지역 변수가 언제나 공간을 절감한다는 절대 명제는 틀려요. 주소로 넘긴다고 호출자 객체의 복사본이 새로 생기는 것도 아니에요.

</details>

### P4. 최대값 탐색의 초기값과 종료 조건

**후속 수업 보충:** 이 최대값 알고리즘의 분석은 0914 수업에서 다뤘어요. 이 문항은 보존하되 0907 핵심 범위의 평가 문항으로 세지 않아요.

**강의 예제 기반 자체 출제** S1 p21

아래 함수는 전역 배열 `int score[MAX];`(MAX는 n 이상인 상수)의 앞 n개를 입력으로 받아요. score={-8,-3,-10,-1}, n=4일 때 tmp의 변화와 반환값을 적으세요. tmp를 0으로 초기화하면 생기는 오류, n에 필요한 조건, 이 반복이 유한한 이유도 설명하세요.

```c
int find_max_score(int n)
{
    int i, tmp;
    tmp = score[0];
    for(i=1;i<n;i++){
        if(score[i] > tmp) tmp = score[i];
    }
    return tmp;
}
```

<details><summary>강의 예제 보기</summary>

S1 p21 · Software_1_자료구조및알고리즘.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

```c
int find_max_score(int n)
{
    int i, tmp;
    tmp = score[0];
    for(i=1;i<n;i++){
        if(score[i] > tmp) tmp = score[i];
    }
    return tmp;
}
```

</details>

<details><summary>힌트 보기</summary>

배열은 데이터를 보관하는 자료구조이고 반복·비교는 최대값을 찾는 알고리즘이에요.

</details>

<details><summary>풀이 보기</summary>

1. 배열은 데이터를 보관하는 자료구조이고 반복·비교는 최대값을 찾는 알고리즘이에요.
2. 첫 원소 -8을 tmp에 놓아요. i=1에서 -3으로 바꾸고, i=2에서는 -10이 작으므로 유지해요. i=3에서 -1로 바꿔요.
3. 반복 직전 tmp는 이미 읽은 원소들의 최대값이에요. 매번 다음 원소와 비교하므로 마지막에는 전체 최대값이 돼요.
4. 입력 범위와 종료 조건은 코드가 유효한 알고리즘이 되기 위한 조건이에요. n=0은 이 함수의 계약에서 제외해요.

**정답:** tmp: -8 → -3 → -3 → -1, 반환 -1. 0으로 초기화하면 배열에 없는 0을 잘못 반환한다. 1≤n≤배열 용량이고 앞 n개가 초기화되어야 한다. i가 1씩 증가해 n에 도달하므로 종료한다.

최대값의 초기값을 무조건 0으로 놓으면 음수만 있는 입력에서 틀려요.
