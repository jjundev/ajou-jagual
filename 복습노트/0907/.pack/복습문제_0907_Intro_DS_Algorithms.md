### P4. 최대값 탐색의 초기값과 종료 조건

**강의 예제 기반 자체 출제** S1 p21

강의 코드에서 score의 앞 n개가 입력이에요. score={-8,-3,-10,-1}, n=4일 때 tmp의 변화와 반환값을 적으세요. tmp를 0으로 초기화하면 생기는 오류, n에 필요한 조건, 이 반복이 유한한 이유도 설명하세요.

```c
int find_max_score(int n)
{
    int i, tmp;
    tmp = score[0];
    for(i=1;i<n;i++){
        if(score[i] > tmp) tmp = score[i];
    }
    return tmp;
}
```

<details><summary>강의 예제 보기</summary>

S1 p21 · Software_1_자료구조및알고리즘.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

```c
int find_max_score(int n)
{
    int i, tmp;
    tmp = score[0];
    for(i=1;i<n;i++){
        if(score[i] > tmp) tmp = score[i];
    }
    return tmp;
}
```

</details>

<details><summary>힌트 보기</summary>

배열은 데이터를 보관하는 자료구조이고 반복·비교는 최대값을 찾는 알고리즘이에요.

</details>

<details><summary>풀이 보기</summary>

1. 배열은 데이터를 보관하는 자료구조이고 반복·비교는 최대값을 찾는 알고리즘이에요.
2. 첫 원소 -8을 tmp에 놓아요. i=1에서 -3으로 바꾸고, i=2에서는 -10이 작으므로 유지해요. i=3에서 -1로 바꿔요.
3. 반복 직전 tmp는 이미 읽은 원소들의 최대값이에요. 매번 다음 원소와 비교하므로 마지막에는 전체 최대값이 돼요.
4. 입력 범위와 종료 조건은 코드가 유효한 알고리즘이 되기 위한 조건이에요. n=0은 이 함수의 계약에서 제외해요.

**정답:** tmp: -8 → -3 → -3 → -1, 반환 -1. 0으로 초기화하면 배열에 없는 0을 잘못 반환한다. 1≤n≤배열 용량이고 앞 n개가 초기화되어야 한다. i가 1씩 증가해 n에 도달하므로 종료한다.

최대값의 초기값을 무조건 0으로 놓으면 음수만 있는 입력에서 틀려요.

</details>
