}
힌트 보기

foo(12, 18)을 손으로 따라가 보세요. 나머지가 0이 되는 순간 무엇을 돌려주는지 보면 돼요.

풀이 보기
  1. 끝나는 조건부터 봐요. x % y == 0이면, 즉 y가 x를 나누어떨어지게 하면 y를 돌려주고 끝나요. 이때 y는 x와 y를 둘 다 나누는 수 중 가장 커요.
  2. 아니면 foo(y, x % y)를 다시 불러요. x % y는 y보다 작아서 두 번째 값이 부를 때마다 줄어들어요. 그래서 언젠가 나누어떨어지는 순간이 와요.
  3. foo(12, 18): 12 % 18 = 12, 0이 아니에요 → foo(18, 12)
  4. foo(18, 12): 18 % 12 = 6 → foo(12, 6)
  5. foo(12, 6): 12 % 6 = 0 → 6을 돌려줘요.
  6. 돌아올 때는 받은 6을 그대로 위로 넘겨요. foo(12, 6) → foo(18, 12) → foo(12, 18) 모두 6이에요. 12와 18을 둘 다 나누는 가장 큰 수가 6이에요.
  7. 왜 답이 바뀌지 않을까요? $x = q \cdot y + r$ ($r$은 $x$를 $y$로 나눈 나머지)이면, $x$와 $y$를 둘 다 나누는 수는 $r$도 나누고, $y$와 $r$을 둘 다 나누는 수는 $x$도 나눠요. 그래서 $(x, y)$와 $(y, r)$의 공약수가 같아요.
  8. 수업과의 연결: 0914 수업(60:20–61:16)에서 말한 순환의 두 조건, "끝나는 조건"과 부를 때마다 "크기가 줄어든다"를 foo가 그대로 갖췄어요.

정답: x와 y의 최대공약수를 구해주는 (함수)

풀이 보기
  1. 넷째 루프: k가 0부터 29까지 돌아요. 한 번 들어가면 대입이 30번이에요.
  2. 셋째 루프 for(p=0; j<i; j++): 둘째 루프가 막 시작해 j = 0일 때, j를 0 → 1 → … → i로 올리며 i번 돌아요. j = i가 되면 멈춰요.
  3. 그다음 둘째 루프가 j를 더 올려도 j > i라서 셋째 루프는 다시 돌지 않아요. 그래서 i마다 대입은 $30 \cdot i$번이에요.

  6. 빅오: $T(n) = 15n^2 - 15n$에서 최고차항 $n^2$만 남기고 계수 15를 떼면 $O(n^2)$예요. 루프가 네 겹이어도 $O(n^4)$가 아니에요.
  7. 수업과의 연결: 0914 수업 S1 p29에서 알고리즘 C의 대입 연산을 루프 횟수로 센 방법 그대로예요. 교수님이 루프 개수만 보지 말고 "얼마나 가는지"도 보라고 했어요(40:35).

정답: $T(n) = 30n(n-1)/2$, 빅오 표기법 $O(n^2)$

풀이 보기
  1. 끝나는 조건: j가 0이면 i가 답이에요. 0은 어떤 수로도 나누어떨어지니, i와 0을 둘 다 나누는 가장 큰 수는 i예요.
  2. 크기가 줄어든다: $i$를 $j$로 나눈 나머지를 $r$이라 하면 $(i, j)$와 $(j, r)$의 공약수는 같아요. $r$은 $j$보다 작아서 부를 때마다 두 번째 수가 줄고, 결국 0이 돼요.
  3. 두 조건을 그대로 코드로 옮겨요. 
    int gcd(int i, int j){
    if ( j == 0 ) return i;
    else return gcd( j, i%j );
}
  4. 입력 12 18로 따라가요: gcd(12, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0), 여기서 j == 0이라 6을 돌려줘요. 첫 호출에서 i < j여도 나머지가 12라서 두 수가 저절로 자리를 바꿔요.
  5. 돌아올 때는 스택에 쌓인 호출이 위에서부터 6을 그대로 넘겨요. 화면에는 임의의 두 양의 정수 입력:gcd:6이 찍혀요.

정답: if ( j == 0 ) return i; else return gcd( j, i%j );

  2. 가운데 j 루프: j = i … n−1, $n - i$번이에요. i마다 대입은 $10(n - i)$번이에요.
  3. i별로 세면: i = 0 → $10n$, i = 1 → $10(n-1)$, …, i = n−1 → $10 \cdot 1$
  4. 모두 더해요. $$10\,(n + (n-1) + \cdots + 1) = 10 \cdot \frac{n(n+1)}{2}$$ 그래서 $T(n) = 10n(n+1)/2 = 5n(n+1)$이에요. n = 3이면 30 + 20 + 10 = 60 = 5·3·4로 맞아요.
  5. 빅오: $5n(n+1) = 5n^2 + 5n$에서 최고차항 $n^2$만 남기고 계수 5를 떼면 $O(n^2)$예요. 안쪽 횟수 10은 계수에만 들어가요.
  6. 수업과의 연결: 0914 수업 S1 p29에서 알고리즘 C의 대입 연산을 바깥 루프 횟수 × 안쪽 루프 횟수로 센 방법과 같아요.

정답: $T(n) = 10n(n+1)/2 = 5n(n+1)$, 빅오 표기법 $O(n^2)$

  1. 넷째 루프: k = 1 … 19, 대입 19번이에요. k<20이지만 1부터 시작해서 하나 적어요.
  2. 셋째 루프 for(p=1; j<=i; j++): 둘째 루프가 막 시작해 j = 1일 때, j를 1 → 2 → … → i로 올리며 i번 돌아요. j = i + 1이 되면 멈춰요.
