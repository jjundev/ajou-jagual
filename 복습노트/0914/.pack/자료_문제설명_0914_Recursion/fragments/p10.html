문제를 내 말로 읽어요

T(n)=7n+10이 무엇을 세는지 고르는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

“시간 복잡도 함수”는 기준 기본 연산(operation)의 실행 횟수를 입력 크기 n의 함수로 표현한 것이에요. 같은 연산을 같은 비용으로 세는 모형이며 실제 초 단위 실행 시간과 같지는 않아요.

종이에 적을 첫 줄

n=3일 때 T(3)=31회라고 적어요.

왜 이렇게 푸는지 함께 따라가요

정답은 (1) 연산의 횟수예요. 입력 개수 n에 비례하는 7n회와 입력에 무관한 10회를 더한 식이에요. 메모리 사용량이면 공간 복잡도이고 입력 개수 자체는 n이에요.

완성 답과 검산

n=0→10회, n=1→17회, n=2→24회로 입력 1개 증가마다 7회 늘어요. 함수의 단위가 “연산 회수”인지 확인해요.

이 문제에서 조심할 점

7n+10을 7n+10초라고 말하려면 각 연산의 시간에 대한 별도 가정이 필요해요.

설명을 닫고 다시 해 봐요

  1. n=3일 때 T(3)=31회라고 적어요.
  2. 시간 복잡도는 연산 횟수
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄
