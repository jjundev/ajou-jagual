문제를 내 말로 읽어요

이는 수학적 유사코드예요. 객체 범위를 쓰고 sub(3,5),sub(5,3),add(INT_MAX,1)의 결과를 구하세요. 사용자가 내부 표현을 몰라도 되는 이유와 add를 signed int C 코드로 그대로 옮길 때의 주의점을 설명하세요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “자연수 ADT의 연산 계약”예요. 자연수 범위 밖의 음수가 나오지 않도록 sub는 작은 수에서 큰 수를 뺄 때 0을 반환해요. C의 signed overflow는 정상 계산이 아니에요. x,y가 0..INT_MAX라면 INT_MAX-y는 안전하므로 먼저 비교하고 안전한 경우에만 더해요.

종이에 적을 첫 줄

sub(3,5): 3<5이므로 0이에요.

왜 이렇게 푸는지 함께 따라가요

  1. 자연수 범위 밖의 음수가 나오지 않도록 sub는 작은 수에서 큰 수를 뺄 때 0을 반환해요.
  2. add는 수학적 합이 상한을 넘으면 INT_MAX로 포화시킨다는 계약이에요. 이 계약은 배열이나 비트 등 내부 표현과 구별돼요.
  3. C의 signed overflow는 정상 계산이 아니에요. x,y가 0..INT_MAX라면 INT_MAX-y는 안전하므로 먼저 비교하고 안전한 경우에만 더해요.

객체 0..INT_MAX. 결과 0,2,INT_MAX. ADT는 객체와 연산 계약을 제공하고 표현을 숨긴다. C에서는 x+y 자체가 overflow할 수 있으므로 x>INT_MAX-y를 먼저 검사해야 한다.
