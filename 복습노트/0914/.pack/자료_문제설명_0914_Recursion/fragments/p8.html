문제를 내 말로 읽어요

n은 0 이상의 정수이고 결과가 int에 들어간다고 가정해요. factorial(3)의 호출 순서와 반환 순서를 쓰고, factorial(0)의 값도 구하세요. 종료 조건과 문제 크기가 줄어드는 부분을 찾아 설명하세요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “팩토리얼의 호출과 반환을 분리하기”예요. 먼저 종료 조건 n<=1을 표시해요. factorial(3)은 아직 곱셈을 끝내지 못하고 factorial(2)를 기다려요. 0은 바로 종료 조건을 만족하므로 1을 반환해요. 호출할 때 감소하는 n과 반환 때 계산하는 곱을 구분해요.

종이에 적을 첫 줄

factorial(3)=3×factorial(2)라고 적어요.

왜 이렇게 푸는지 함께 따라가요

  1. 먼저 종료 조건 n<=1을 표시해요. factorial(3)은 아직 곱셈을 끝내지 못하고 factorial(2)를 기다려요.
  2. factorial(2)도 factorial(1)을 기다려요. factorial(1)은 1을 반환해요.
  3. 아래에서 올라오며 2×1=2, 3×2=6을 계산해요. 각 호출의 n은 서로 다른 지역 변수예요.
  4. 0은 바로 종료 조건을 만족하므로 1을 반환해요. 호출할 때 감소하는 n과 반환 때 계산하는 곱을 구분해요.

호출 3→2→1, 반환 1→2→6. factorial(0)=1. n<=1이 종료 조건이고 n-1로 크기가 줄어든다.

이 문제에서 조심할 점

호출하는 순간 3×2×1이 한 번에 계산된다고 생각하지 마세요. 아직 끝나지 않은 곱셈이 각 호출에 남아 있어요.
