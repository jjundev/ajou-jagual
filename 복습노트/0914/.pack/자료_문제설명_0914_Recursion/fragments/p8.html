문제를 내 말로 읽어요

순환 함수 factorial(3)의 호출 순서와 반환 순서를 분리해 추적하고, 종료 조건과 문제 크기가 줄어드는 식을 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “팩토리얼의 호출과 반환을 분리하기”예요. 순환 함수는 종료 조건(기저 조건)에 도달할 때까지 더 작은 인자(n - 1)로 자기 자신을 호출하며 내려가고, 기저 조건에서 값이 반환되면 역순으로 곱셈을 마무리해요.

종이에 적을 첫 줄

factorial(3) = 3 * factorial(2)라고 적고 하위 호출을 따라가요.

왜 이렇게 푸는지 함께 따라가요

(a) factorial(3)은 factorial(2)를 부르고, factorial(2)는 factorial(1)을 부르므로 호출 인자 순서는 3 → 2 → 1이에요. factorial(1)이 종료 조건을 만나 1을 반환하면 factorial(2)가 2 * 1 = 2를, factorial(3)이 3 * 2 = 6을 반환하므로 반환값 순서는 1 → 2 → 6이에요. factorial(0)은 처음부터 0 <= 1이 참이므로 1을 반환해요.

(b) 순환을 멈추는 종료 조건은 if (n <= 1) return 1;의 n <= 1이고, 순환 호출의 인자 n - 1이 호출마다 문제 크기를 1씩 줄여 결국 종료 조건에 도달하게 해요.

완성 답과 검산

(a) 호출 순서 3 → 2 → 1과 반환 순서 1 → 2 → 6이 스택의 후입선출(LIFO) 순서와 일치하며, $3! = 6$, $0! = 1$과도 맞아요.

(b) 정수 $n \ge 2$에서 매번 n - 1을 전달하면 유한 번 뒤에 반드시 n == 1이 되어 n <= 1 조건에 도달함을 확인해요.

이 문제에서 조심할 점

호출하는 순간 3 * 2 * 1이 한 번에 계산된다고 생각하지 마세요. 아직 끝나지 않은 곱셈이 각 호출에 남아 있어요.

설명을 닫고 다시 해 봐요

  1. factorial(3)의 호출 순서와 반환값 순서를 화살표로 나누어 적어요.
  2. factorial(0)이 어느 분기로 들어가 무엇을 반환하는지 확인해요.
  3. 종료 조건과 문제 크기를 줄이는 식을 코드에서 찾아 적어요.

첫 줄

factorial(3) = 3 * factorial(2)라고 적고 하위 호출을 따라가요.

떠올릴 개념·공식

순환은 종료 조건(n <= 1)과 문제 크기 감소(n - 1)로 구성되며 호출 역순으로 반환돼요.

검산

(a) 호출 3 → 2 → 1, 반환 1 → 2 → 6, factorial(0) = 1 (b) 종료 조건 n <= 1, 크기 감소 n - 1.
