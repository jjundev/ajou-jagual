### P6. 자연수 ADT의 연산 계약

**강의 예제 기반 자체 출제** S1 p24

이는 수학적 유사코드예요. 객체 범위를 쓰고 sub(3,5),sub(5,3),add(INT_MAX,1)의 결과를 구하세요. 사용자가 내부 표현을 몰라도 되는 이유와 add를 signed int C 코드로 그대로 옮길 때의 주의점을 설명하세요.

```c
Nat_No
zero() ::= return 0;
sub(x,y) ::= if(x<y) return 0;
             else return x-y;
add(x,y) ::= if((x+y)<=INT_MAX) return x+y;
             else return INT_MAX;
```

<details><summary>강의 예제 보기</summary>


<details><summary>힌트 보기</summary>

자연수 범위 밖의 음수가 나오지 않도록 sub는 작은 수에서 큰 수를 뺄 때 0을 반환해요.

</details>

<details><summary>풀이 보기</summary>

1. 자연수 범위 밖의 음수가 나오지 않도록 sub는 작은 수에서 큰 수를 뺄 때 0을 반환해요.
2. add는 수학적 합이 상한을 넘으면 INT_MAX로 포화시킨다는 계약이에요. 이 계약은 배열이나 비트 등 내부 표현과 구별돼요.
3. C의 signed overflow는 정상 계산이 아니에요. x,y가 0..INT_MAX라면 INT_MAX-y는 안전하므로 먼저 비교하고 안전한 경우에만 더해요.

**정답:** 객체 0..INT_MAX. 결과 0,2,INT_MAX. ADT는 객체와 연산 계약을 제공하고 표현을 숨긴다. C에서는 x+y 자체가 overflow할 수 있으므로 x&gt;INT_MAX-y를 먼저 검사해야 한다.

강의 유사코드를 그대로 C의 정수 연산이라고 간주해 INT_MAX+1을 실행하지 마세요.

</details>

### P8. 팩토리얼의 호출과 반환을 분리하기

**강의 예제 기반 자체 출제** S2 p4

n은 0 이상의 정수이고 결과가 int에 들어간다고 가정해요. factorial(3)의 호출 순서와 반환 순서를 쓰고, factorial(0)의 값도 구하세요. 종료 조건과 문제 크기가 줄어드는 부분을 찾아 설명하세요.

```c
int factorial(int n)
{
    if(n <= 1) return 1;
    else return n * factorial(n-1);
}
```

<details><summary>강의 예제 보기</summary>

S2 p4 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

```c

{
    if(n <= 1) return 1;
    else return n * factorial(n-1);
}
```

</details>

<details><summary>힌트 보기</summary>

먼저 종료 조건 n&lt;=1을 표시해요. factorial(3)은 아직 곱셈을 끝내지 못하고 factorial(2)를 기다려요.

</details>

<details><summary>풀이 보기</summary>

1. 먼저 종료 조건 n&lt;=1을 표시해요. factorial(3)은 아직 곱셈을 끝내지 못하고 factorial(2)를 기다려요.
2. factorial(2)도 factorial(1)을 기다려요. factorial(1)은 1을 반환해요.
3. 아래에서 올라오며 2×1=2, 3×2=6을 계산해요. 각 호출의 n은 서로 다른 지역 변수예요.
4. 0은 바로 종료 조건을 만족하므로 1을 반환해요. 호출할 때 감소하는 n과 반환 때 계산하는 곱을 구분해요.

**정답:** 호출 3→2→1, 반환 1→2→6. factorial(0)=1. n&lt;=1이 종료 조건이고 n-1로 크기가 줄어든다.

호출하는 순간 3×2×1이 한 번에 계산된다고 생각하지 마세요. 아직 끝나지 않은 곱셈이 각 호출에 남아 있어요.
