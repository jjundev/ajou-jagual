p = NULL, t = root로 시작해요. p는 직전에 지난 부모이고 t는 현재 노드예요. t가 NULL이 아니면 같은 키가 있는지 먼저 검사하고, 같으면 연결하지 않고 종료해요. 다르면 p = t로 옮긴 뒤 새 키가 p의 키보다 작으면 t = p->left, 크면 t = p->right로 내려가요.

반복이 끝났을 때 p == NULL이면 root = z예요. 그렇지 않으면 새 키가 작을 때 p->left = z, 클 때 p->right = z로 연결해요. 이 조건의 =는 상태 변경을 뜻하며, 같음을 확인하는 조건은 ==로 적었어요.

    if (z->key = t->key) return;
    p←t;
    if z->key < p->key
        then t←p->left;
        else t←p->right;
}
if p=NULL
    then root←z;// 트리가 비어있음
else if z->key < p->key // insert
    then p->left←z
    else p->right←z

힌트 보기

현재 노드가 바뀌기 직전의 노드를 부모로 기억해요. 같은 키와 빈 트리는 서로 다른 종료 경로예요.

풀이 보기

  1. (a) 각 반복에서 키를 비교한 뒤 부모와 현재 노드를 한 단계씩 옮겨요.

    시점(p, t)비교와 다음 상태
    첫 반복(NULL, 18)9 < 18이므로 왼쪽으로 내려가요.
    둘째 반복(18, 7)9 > 7이므로 오른쪽으로 내려가요.
    셋째 반복(7, 12)9 < 12이므로 왼쪽 빈 링크로 내려가요.
    종료(12, NULL)t == NULL이므로 반복을 끝내요.

  2. 종료 때 부모 p는 키 12 노드를 가리켜요. 9 < 12이므로 p->left = z로 연결해요. 노드 수는 8개가 돼요.

    레벨 순서: 18 7 26 3 12 31 9 27

  3. (b) 두 번째 9의 비교 경로는 18, 7, 12, 9예요. 기존 9에서 같은 키를 만나 바로 끝내요. 연결하는 문장에 도달하지 않으므로 노드 수는 8개로 유지되고 모든 링크도 그대로예요.

  4. (c) 빈 트리에서는 처음부터 t = root = NULL이에요. 따라서 반복은 0회이고 p도 NULL로 남아요. root = z를 실행해 키 9인 노드가 루트가 돼요.

정답: (a) (NULL, 18), (18, 7), (7, 12), 종료 (12, NULL), 12의 왼쪽에 9 (b) 8개 유지, 링크 변경 없음 (c) 0회, root가 키 9 노드
