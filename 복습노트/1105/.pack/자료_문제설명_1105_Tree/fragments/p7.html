핵심 조건과 구할 것

“노드의 개수가 $n$인 이진탐색트리(BST)의 높이는 항상 일정하다”의 O/X를 판별해요.

  • 보편 주장(“항상 일정”)을 반박하려면 같은 $n$과 BST 키 순서 조건을 지키면서 높이가 다른 두 트리 하나만 찾으면 돼요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구·공식이 문제에 쓰는 이유와 조건
높이(height)루트를 레벨 1로 세는 최대 깊이 (정리노트)일반 BST의 높이는 $\lceil\log_2(n+1)\rceil \le h \le n$ 범위에서 입력 순서에 따라 변해요.
이진탐색트리(BST)키 유일성 + 왼쪽 < 부모 < 오른쪽 (정리노트)반례로 드는 두 트리 모두 BST 순서 조건을 만족해야 유효한 반박이 돼요.

종이에 쓰는 실제 첫 줄

n = 3 (키: 1, 2, 3) 고정
트리 A: 루트 2 (왼쪽 1, 오른쪽 3)  vs  트리 B: 루트 1 → 오른쪽 2 → 오른쪽 3

왜 이렇게 푸는지 함께 따라가요

구분노드 수 $n$연결 모양 (레벨 순서)BST 조건높이
트리 A (균형)32의 왼쪽 1, 오른쪽 3 (2 1 3)1 < 2 < 3 만족2
트리 B (경사)31의 오른쪽 2, 그 오른쪽 3 (1 2 3)1 < 2 < 3 만족3

같은 $n=3$에서 높이가 $2 \ne 3$이므로 “항상 일정하다”는 거짓이에요. 정답은 X예요.

완성 답과 검산

완성 답: X

  • BST 유효성 검산: 트리 A와 트리 B 모두 중위 순회 결과가 1 2 3 오름차순이며 키 중복이 없어요.
  • 경계값 검산: $n=1$일 때는 높이가 1로 유일하지만, $n \ge 2$부터 이미 모양이 갈려요(예: $n=2$는 루트 2-왼쪽 1 / 루트 1-오른쪽 2라 높이는 둘 다 2지만, $n=3$부터 높이 자체가 2와 3으로 달라져요).

실수하면 답이 이렇게 망가져요

“BST는 탐색용이라 늘 균형 잡힌다”고 생각하면: AVL·레드-블랙 트리 같은 균형 트리가 아닌 일반 BST는 입력 순서대로 매달리므로 오름차순(1, 2, 3) 삽입 시 높이 $n$까지 한쪽으로 길어져 O로 오판하기 쉬워요.

반례에 BST 조건을 깨는 트리를 쓰면: 예컨대 1의 왼쪽에 3을 붙이면 BST가 아니므로 유효한 반례가 되지 않아요.

해설을 가리고 스스로 확인해요

  1. $n=3$에서 BST 조건을 지키면서 높이가 2인 경우 1개와 3인 경우 1개의 삽입 순서를 각각 적어 보세요.
  2. 만약 문제가 “높이가 가장 작은 BST” 또는 “완전이진트리”라는 조건을 추가했다면 O/X가 어떻게 바뀔까요?

떠올릴 개념·공식

일반 BST 높이는 $\lceil\log_2(n+1)\rceil \le h \le n$으로 입력 순서에 따라 변해요.

첫 줄

$n=3$ 고정: 2(1,3) 높이 2 vs 1→2→3 높이 3.

핵심 답

X — 같은 3개 키(1,2,3)의 유효한 BST라도 높이가 2와 3으로 달라져요.

검산

두 반례 모두 중위 1 2 3으로 BST 유효, $n=3$에서 높이 $2 \ne 3$ 확인.
