# 중위 순회 내용 검토

강의 PDF S7 19쪽을 렌더링해 이진 탐색 트리의 부모·자식과 출력 3, 7, 12, 18, 26, 27, 31을 확인했다. `s0-inorder` 정리노트의 LVR 설명 및 같은 트리와 대조했다. 화면의 C 코드와 입문·빈 사례는 별도 보충으로 표시했다.

| 입문 사례 단계 | 실행과 읽기·쓰기 | 완료 후 상태 |
|---|---|---|
| line-7 | 호출 3의 3행. `p`와 노드 1의 `left`를 읽고 NULL을 새 호출 4의 `p`에 복사 | 호출 4의 2행이 다음. 호출 3은 4행으로 복귀 대기. 출력 없음 |
| line-8 | 호출 4의 2행. 자기 `p`에서 NULL을 읽고 반환 | 호출 4의 `p` 수명 종료. 호출 3의 4행이 다음. 출력 없음 |
| line-9 | 호출 3의 4행. 자기 `p`가 가리키는 노드 1의 `key`를 읽어 출력 | `1 `이 stdout에 추가되고 노드 1의 출력 순번은 1. 호출 3의 5행이 다음 |
| line-10 / line-11 | 오른쪽 링크의 NULL을 호출 5에 복사한 뒤 2행에서 반환 | 호출 5의 `p` 수명 종료. 호출 3의 6행이 다음. 출력은 `1 ` |
| 빈 사례 line-1 / line-2 | `root`의 NULL을 새 `p`에 복사하고 2행에서 반환 | 호출자로 복귀하며 순회 완료. 노드와 출력 없음 |

`&call-3.p`는 호출 3의 매개변수 자체 주소다. 그 안의 `&node-1`은 노드 객체의 기호 주소다. 멤버의 기호 주소 `&node-1.key`도 노드 메모리에 따로 표시한다. 반환된 `p`는 마지막 값과 수명 종료를 함께 표시하며 트리 객체의 값은 유지된다. 현재 줄, 활성 호출, 트리, 출력 순번을 같은 단계에서 확인했다.
