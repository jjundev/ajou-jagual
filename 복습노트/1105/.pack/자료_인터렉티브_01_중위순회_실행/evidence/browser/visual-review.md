# 1105 패널 너비와 줄 기록 검토

- Chromium 1440×900, 1024×768, 375×812의 두 테마에서 사례 3개의 줄 상태 450개를 확인했다. 외부 요청과 콘솔 오류는 없었다.
- Chromium과 WebKit 1440px에서 양쪽 경계를 끌고, 화살표와 Shift 조합으로 조절했다. 새로고침 후 복원, 더블클릭과 Home 초기화, 1280px에서 중앙 400px 확보와 창 확대 시 저장 폭 복원을 확인했다.
- 모바일 Chromium과 WebKit 터치 환경에서 양쪽 서랍이 닫힌 상태로 시작하고 별도 너비 조절이 나타나지 않는다. 왼쪽 서랍을 열거나 다시 열면 줄 기록이 바로 보인다.
- 줄 기록에는 접기 버튼이 없고 0단계는 맨 위, 이후 현재 행은 3행 중 가운데에 놓인다. 직접 스크롤한 뒤 실행 위치로 버튼으로 자동 추적을 재개했다.
- 너비 조절 후 데스크톱, 375px 모바일의 스크린샷에서 경계 강조선과 줄 기록의 간격 및 가독성을 확인했다.
- 포인터 예제 3개는 18개 Chromium 조합의 852개 상태를 확인했다. C 독립 검산은 세 사례의 실행 관찰과 출력이 일치했다.
