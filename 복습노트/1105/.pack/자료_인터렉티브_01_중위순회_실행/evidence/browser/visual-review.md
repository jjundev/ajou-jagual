# 브라우저 시각 검토

Chromium의 1440×900, 1024×768, 375×812 화면을 밝은·어두운 테마에서 열었다. 입문 사례의 왼쪽 NULL 화면에서 굵은 호출 경로와 점선 NULL 끝이 그림 안에 들어오고 재생·출력 바를 가리지 않는 것을 확인했다. 모바일 메모리 서랍에서 NULL 값, 각 호출의 자기 주소, 호출자가 재개할 4행을 읽을 수 있었다.

강의 사례의 첫 출력에는 노드 3만 출력 순번 1을 표시한다. 한 줄 뒤로 이동하면 출력 순번과 stdout이 비고, 종료된 NULL 프레임과 다음 4행이 보인다. 모바일 완료 화면에서는 7개 노드의 출력 번호와 출력 문자열 전체를 확인했다.
