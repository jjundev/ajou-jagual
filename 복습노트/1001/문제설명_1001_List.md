### P1. 배열에 끼워 넣기

textbook-ch03-q08 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_1001_List.html#p1)

#### 주어진 조건

크기가 n인 배열 array에서 임의의 위치 loc에 정수 value를 삽입하는 함수 insert()를 작성하라. 정수가 삽입되면 그 뒤에 있는 정수들은 한 칸씩 뒤로 밀려야 한다. 현재 배열에 들어있는 원소의 개수는 items개라고 하자. (여기서 items &lt;&lt; n라고 가정)

`void insert(int array[], int loc, int value){
    ....
}`

#### 기출 원문

3장 배열, 구조체, 포인터 · 08번 · 책 98쪽 · PDF 2쪽

크기가 n인 배열 array에서 임의의 위치 loc에 정수 value를 삽입하는 함수 insert()를 작성하라. 정수가 삽입되면 그 뒤에 있는 정수들은 한 칸씩 뒤로 밀려야 한다. 현재 배열에 들어있는 원소의 개수는 items개라고 하자. (여기서 items &lt;&lt; n라고 가정)

`void insert(int array[], int loc, int value){
    ....
}`

#### 문제를 내 말로 읽어요

현재 items개를 저장한 여유 있는 배열에서 loc에 새 값을 넣어요. items는 원문 인자에 없어서 전역으로 두어요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

삽입 insertion은 빈 칸을 만들기 위해 뒤 원소를 오른쪽으로 옮겨요. 뒤에서부터 복사해야 아직 필요한 값을 덮어쓰지 않아요. 전제는 0≤loc≤items&lt;용량이에요.

#### 종이에 적을 첫 줄

`for (int i = items-1; i >= loc; --i)`

#### 왜 이렇게 푸는지 함께 따라가요

`int items; /* 현재 길이: 호출 전에 설정 */
void insert(int array[], int loc, int value) {
    for (int i=items-1; i>=loc; --i)
        array[i+1] = array[i];
    array[loc] = value;
    ++items;
}`

#### 완성 답과 검산

[10,20,30],items=3,loc=1,value=99에서 30→칸3,20→칸2 후 [10,99,20,30],items=4예요. 원래 loc 이상인 각 원소 k는 k+1로 이동하고 이전 원소의 순서는 유지돼요. 끝 loc=items이면 이동 0번이에요.

#### 이 문제에서 조심할 점

앞에서 오른쪽으로 복사하면 다음 원소가 덮여 같은 값이 반복돼요. 용량 초과와 잘못된 loc은 호출 전에 거부해요.

#### 설명을 닫고 다시 해 봐요

1. for (int i = items-1; i &gt;= loc; --i)
2. 뒤→앞 복사, loc 저장, 길이 증가
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

for (int i = items-1; i &gt;= loc; --i)

#### 떠올릴 개념·공식

뒤→앞 복사, loc 저장, 길이 증가

### P2. 삽입 때 옮기는 원소 수

textbook-ch03-q09 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_1001_List.html#p2)

#### 주어진 조건

앞의 문제에서 구현한 insert() 함수의 시간 복잡도는?

바로 앞 교과서 문항에서 작성한 함수를 기준으로 답해 보세요.

#### 기출 원문

3장 배열, 구조체, 포인터 · 09번 · PDF 2쪽

앞의 문제에서 구현한 insert() 함수의 시간 복잡도는?

#### 문제를 내 말로 읽어요

바로 앞 insert의 이동 횟수로 시간 복잡도를 구해요. 용량 n과 현재 길이 items를 구분해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

for 인덱스는 items−1에서 loc까지 양끝 포함이라 반복 횟수는 items−loc예요. 원소 이동마다 상수 비용이고 마지막 저장·길이 증가도 상수예요.

#### 종이에 적을 첫 줄

이동 횟수=items−loc를 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

T=상수×(items−loc)+상수예요. 첫 위치 loc=0의 최악은 O(items), 끝 loc=items의 최선은 O(1)이에요. 현재 길이를 n이라 부르는 관례에서는 최악 O(n)이지만 이 원문의 n은 배열 용량이에요.

#### 완성 답과 검산

items=3일 때 loc=0,1,2,3의 이동 횟수는 3,2,1,0이에요. 독립 C 이동 추적과 비교해요.

#### 이 문제에서 조심할 점

용량이 크더라도 사용하지 않는 빈 칸을 모두 이동하지 않아요.

#### 설명을 닫고 다시 해 봐요

1. 이동 횟수=items−loc를 적어요.
2. 최악 O(items), 끝 O(1)
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

이동 횟수=items−loc를 적어요.

#### 떠올릴 개념·공식

최악 O(items), 끝 O(1)

#### 검산

본문의 조건과 독립 추적을 함께 확인해요.

### P3. 배열에서 한 원소 지우기

textbook-ch03-q10 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_1001_List.html#p3)

#### 주어진 조건

크기가 n인 배열 array에서 임의의 위치 loc에 있는 정수를 삭제하는 함수 delete()를 작성하라. 정수가 삭제되면 그 뒤에 있는 정수들은 한 칸씩 앞으로 이동하여야 한다. 현재 배열에 들어있는 원소의 개수는 items개라고 하자. (여기서 items &lt;&lt; n라고 가정)

`int delete(int array[], int loc){
    ....
}`

#### 기출 원문

3장 배열, 구조체, 포인터 · 10번 · PDF 2쪽

크기가 n인 배열 array에서 임의의 위치 loc에 있는 정수를 삭제하는 함수 delete()를 작성하라. 정수가 삭제되면 그 뒤에 있는 정수들은 한 칸씩 앞으로 이동하여야 한다. 현재 배열에 들어있는 원소의 개수는 items개라고 하자. (여기서 items &lt;&lt; n라고 가정)

`int delete(int array[], int loc){
    ....
}`

#### 문제를 내 말로 읽어요

loc의 값을 삭제하고 그 값을 반환해요. 뒤 원소들을 앞으로 당긴 후 길이를 줄여요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

삭제 deletion는 원소의 논리적 길이를 줄이는 연산이에요. 0≤loc&lt;items 전제에서 먼저 삭제값을 저장해야 이동으로 덮여도 반환할 수 있어요. 왼쪽 복사는 앞에서 뒤 순서예요.

#### 종이에 적을 첫 줄

`int removed = array[loc];`

#### 왜 이렇게 푸는지 함께 따라가요

`int items;
int delete(int array[], int loc) {
    int removed = array[loc];
    for (int i=loc; i<items-1; ++i)
        array[i] = array[i+1];
    --items;
    return removed;
}`

#### 완성 답과 검산

[10,20,30,40],loc=1이면 removed=20, 칸1←30,칸2←40 후 items=3이며 유효 목록은 [10,30,40]이에요. 마지막 메모리 40이 남아도 길이 밖이라 목록 원소가 아니에요. 삭제 전후 순서와 반환 20을 별도 확인해요.

#### 이 문제에서 조심할 점

길이를 먼저 줄여 잘못된 끝 조건을 쓰거나 삭제값을 이동 후 읽으면 답이 바뀌어요. 이 코드는 C이며 C++의 delete 예약어와 혼동하지 않아요.

#### 설명을 닫고 다시 해 봐요

1. int removed = array[loc];
2. 값 저장 → 앞 이동 → 길이 감소 → 반환
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

int removed = array[loc];

#### 떠올릴 개념·공식

값 저장 → 앞 이동 → 길이 감소 → 반환

#### 검산

### P4. 삭제 때 옮기는 원소 수

textbook-ch03-q11 · [원 문제 보기](%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_1001_List.html#p4)

#### 주어진 조건

앞의 문제에서 구현한 delete() 함수의 시간 복잡도는?

바로 앞 교과서 문항에서 작성한 함수를 기준으로 답해 보세요.

#### 기출 원문

3장 배열, 구조체, 포인터 · 11번 · PDF 2쪽

앞의 문제에서 구현한 delete() 함수의 시간 복잡도는?

#### 문제를 내 말로 읽어요

앞 delete 함수의 이동 횟수를 세어요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

i=loc..items−2라 이동 횟수는 items−loc−1이에요. 삭제값 저장·길이 감소·반환은 상수 비용이에요.

#### 종이에 적을 첫 줄

이동 횟수=items−loc−1을 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

첫 원소 loc=0을 지우면 items−1번 이동하여 최악 O(items)예요. 끝 loc=items−1이면 이동 없이 O(1)이에요. 현재 길이와 용량 n을 구별해요.

#### 완성 답과 검산

items=4에서 loc=0,1,2,3이면 이동은 3,2,1,0번이에요. 삽입과 달리 삭제 위치 자신의 값은 이동 대상이 아니라서 한 번 적어요.

#### 이 문제에서 조심할 점

삽입의 items−loc를 그대로 쓰지 않아요.

#### 설명을 닫고 다시 해 봐요

1. 이동 횟수=items−loc−1을 적어요.
2. 최악 O(items), 끝 O(1)
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

이동 횟수=items−loc−1을 적어요.

#### 떠올릴 개념·공식

최악 O(items), 끝 O(1)

#### 검산

본문의 조건과 독립 추적을 함께 확인해요.
