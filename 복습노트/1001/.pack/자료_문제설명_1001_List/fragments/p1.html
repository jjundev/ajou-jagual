문제를 내 말로 읽어요

배열 리스트 {10, 20, 30, 40}의 인덱스 1에 25를 끼워 넣을 때 뒤에서 앞으로 원소를 옮기는 과정과 삽입 위치에 따른 시간 복잡도를 구하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “배열 리스트 삽입의 이동 방향”이에요. 삽입 위치 position부터 기존 마지막 원소 length - 1까지 뒤에서 앞으로(i--) 한 칸씩 오른쪽으로 복사해야 아직 읽지 않은 원소를 덮어쓰지 않아요.

종이에 적을 첫 줄

i = L->length - 1 = 3에서 L->list[4] = L->list[3]부터 역순으로 실행해요.

왜 이렇게 푸는지 함께 따라가요

(a) i = 3, 2, 1 순서로 L->list[4] = L->list[3](40), L->list[3] = L->list[2](30), L->list[2] = L->list[1](20)을 차례로 이동한 뒤 L->list[1] = 25를 저장하고 L->length를 5로 늘려요. 따라서 최종 유효 원소는 {10, 25, 20, 30, 40}, length = 5예요. 만약 앞에서 뒤(i++)로 복사하면 list[2]의 30이 먼저 20으로 덮어써져 원래 값을 잃게 돼요.

(b) 길이 n인 리스트의 position = k에 삽입할 때 인덱스 k .. n - 1의 원소를 옮기므로 이동 횟수는 n - k회예요. 맨 끝 삽입(position = n)은 이동 횟수 0회로 최선 $O(1)$이고, 맨 앞 삽입(position = 0)은 n회 이동하므로 최악 $O(n)$이에요.

완성 답과 검산

(a) n = 4, k = 1에서 이동 횟수는 4 - 1 = 3회(40, 30, 20)이고, 기존 세 원소가 한 칸씩 밀린 자리에 25가 들어가 원소 5개가 모두 보존돼요.

(b) k = n을 n - k에 대입하면 0회($O(1)$), k = 0을 대입하면 n회($O(n)$)로 최선·최악 이동 횟수 공식과 일치해요.

이 문제에서 조심할 점

length를 먼저 늘린 뒤 이동 범위를 잡거나 position < length로만 검사하면 맨 끝 삽입 경계가 달라져요.

설명을 닫고 다시 해 봐요

  1. i = 3, 2, 1에 대해 L->list[i+1] = L->list[i] 대입 결과를 차례로 적어요.
  2. 앞에서 뒤로 복사할 때 덮어써지는 원소를 직접 확인해요.
  3. position = k일 때 이동 횟수 n - k로 최선과 최악 복잡도를 계산해요.

첫 줄

i = L->length - 1 = 3에서 L->list[4] = L->list[3]부터 역순으로 실행해요.

떠올릴 개념·공식

배열 리스트 삽입은 i = length - 1부터 position까지 역방향(i--)으로 복사하며 이동 횟수는 n - k회예요.

검산

(a) i = 3, 2, 1 이동 후 list[0..4] = {10, 25, 20, 30, 40}, length = 5 (b) 이동 횟수 n - k회, 최선 $O(1)$, 최악 $O(n)$
