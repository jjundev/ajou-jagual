문제를 내 말로 읽어요

현재 items개를 저장한 여유 있는 배열에서 loc에 새 값을 넣어요. items는 원문 인자에 없어서 전역으로 두어요.

이 문제를 봤을 때 떠올릴 개념과 공식

삽입 insertion은 빈 칸을 만들기 위해 뒤 원소를 오른쪽으로 옮겨요. 뒤에서부터 복사해야 아직 필요한 값을 덮어쓰지 않아요. 전제는 0≤loc≤items<용량이에요.

종이에 적을 첫 줄

for (int i = items-1; i >= loc; --i)

왜 이렇게 푸는지 함께 따라가요

int items; /* 현재 길이: 호출 전에 설정 */
void insert(int array[], int loc, int value) {
    for (int i=items-1; i>=loc; --i)
        array[i+1] = array[i];
    array[loc] = value;
    ++items;
}

완성 답과 검산

[10,20,30],items=3,loc=1,value=99에서 30→칸3,20→칸2 후 [10,99,20,30],items=4예요. 원래 loc 이상인 각 원소 k는 k+1로 이동하고 이전 원소의 순서는 유지돼요. 끝 loc=items이면 이동 0번이에요.

이 문제에서 조심할 점

앞에서 오른쪽으로 복사하면 다음 원소가 덮여 같은 값이 반복돼요. 용량 초과와 잘못된 loc은 호출 전에 거부해요.

설명을 닫고 다시 해 봐요

  1. for (int i = items-1; i &gt;= loc; --i)
  2. 뒤→앞 복사, loc 저장, 길이 증가
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.
