### P1. 배열에 끼워 넣기

크기가 n인 배열 array에서 임의의 위치 loc에 정수 value를 삽입하는 함수 insert()를 작성하라. 정수가 삽입되면 그 뒤에 있는 정수들은 한 칸씩 뒤로 밀려야 한다. 현재 배열에 들어있는 원소의 개수는 items개라고 하자. (여기서 items &lt;&lt; n라고 가정)

```
void insert(int array[], int loc, int value){
    ....
}
```

<details><summary>풀이 보기</summary>

1. items는 현재 원소 수이고 배열에는 여유 공간이 있어요. 원문 함수의 인수가 아니므로 여기서는 전역 변수로 둬요.
2. items-1 위치부터 loc까지 역순으로 오른쪽에 복사해요.
3. loc에 value를 넣고 items를 1 늘려요. 앞·중간·끝 삽입 모두 같은 코드예요.
4. 수업과의 연결: 1001 수업 정리노트의 “배열 리스트의 삽입” 토픽과 강의록에서 다룬 연산·표현을 적용해요.

```c
int items;
void insert(int array[], int loc, int value) {
    for (int i = items; i > loc; --i) array[i] = array[i - 1];
    array[loc] = value;
    ++items;
}
```

**정답:** 뒤에서 loc까지 밀고 array[loc]=value; items++

</details>

<details><summary>풀이 보기</summary>

1. loc은 0 이상 items 미만인 유효한 위치예요.
2. array[loc+1]부터 끝까지 왼쪽으로 한 칸씩 복사해요.
3. 현재 원소 수를 줄이고 보관했던 삭제값을 반환해요. 끝의 남은 메모리 값은 논리적인 리스트 원소가 아니에요.
4. 수업과의 연결: 1001 수업 정리노트의 “배열 리스트의 삭제” 토픽과 강의록에서 다룬 연산·표현을 적용해요.

```c
int items;
int delete(int array[], int loc) {
    int removed = array[loc];
    for (int i = loc; i < items - 1; ++i) array[i] = array[i + 1];
    --items;
    return removed;
}
```

**정답:** 삭제값 저장 → 뒤 원소를 앞으로 → items-- → 삭제값 반환

</details>
