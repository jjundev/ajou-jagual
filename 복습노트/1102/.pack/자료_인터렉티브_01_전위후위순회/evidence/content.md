# 내용 검토

강의록 S7 10쪽·12쪽과 1102 정리노트의 전위·후위 순회 코드를 대조했다. 10쪽의 전위는 현재 값을 출력한 뒤 왼쪽과 오른쪽을 방문한다. 12쪽의 후위는 왼쪽과 오른쪽 호출을 모두 마친 뒤 현재 값을 출력한다. 1102 녹취 Part 03–05의 설명도 이 순서와 일치한다.

- 호출자 1행과 함수 5·6행에서 루트 또는 구조체의 해당 링크에 저장된 포인터 값이 새 호출의 p에 복사된다. 재귀 호출에서는 pre도 호출자에서 복사한다. 노드의 data·left·right에는 쓰기가 없다.
- 2행에서 p를 검사한다. NULL이면 data나 자식 링크를 읽지 않고 그 호출을 끝낸다. 왼쪽 호출은 6행으로, 오른쪽 호출은 7행으로 복귀한다.
- 3·7행은 pre를 읽는다. 전위에서 4행, 후위에서 8행만 실행된다. printf가 읽은 data Cell이 해당 노드의 출력 순번에 연결된다. 동일값 사례의 두 7은 서로 다른 Cell에 있으므로 각 노드의 출력 순번을 구별할 수 있다.
- 비대칭 트리에서 전위는 8→3→1→10→14, 후위는 1→3→14→10→8이다. NULL 루트에서는 두 방식 모두 출력 없이 끝난다.
- 두 슬라이드의 순서를 walk의 pre 분기로 비교할 수 있도록 보충했다. NULL 조기 반환, 출력의 공백, Node 별칭과 숫자 예제는 학습용 구성이다.
