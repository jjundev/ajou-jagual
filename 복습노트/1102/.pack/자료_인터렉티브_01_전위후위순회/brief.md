# 전위·후위 순회 한 줄씩 실행하기

같은 트리에서 출력 줄의 위치를 바꾸면 루트와 자식의 출력 순서가 어떻게 달라질까요?

재귀 함수를 한 함수에 합치고 pre로 출력 위치를 고릅니다. NULL 조기 반환과 출력 구분용 공백을 추가했습니다. 트리와 호출자는 보충 예제입니다.

- 전위 · 같은 값 두 노드
- 전위 · 빈 트리
- 후위 · 비대칭 트리
- 후위 · 같은 값 두 노드
- 후위 · 빈 트리
