핵심 조건과 구할 것

6노드 트리(R → X, Y, X → L1, L2, Y → 왼쪽 L3)에서 (a) get_node_count(X, Y, R), (b) get_height(R), (c) get_height가 + 1을 하는 이유를 구해요(강의 예제 기반 자체 출제).

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구·공식이유와 조건
get_node_count $\text{count}(v) = 1 + \text{count}(L) + \text{count}(R)$ NULL은 0을 돌려주며, 자신(1)과 양쪽 서브트리 합을 모두 더해요(정리노트).
get_height $h(v) = 1 + \max(h(L), h(R))$ NULL은 0이며, 두 서브트리 중 더 높은 쪽 하나만 골라 자신의 1층을 더해요(정리노트).

종이에 쓰는 실제 첫 줄

단말 노드(L1, L2, L3): 좌우 모두 NULL(0)  →  count = 1 + 0 + 0 = 1,  height = 1 + max(0, 0) = 1

왜 이렇게 푸는지 함께 따라가요

(a) get_node_count 상향식 계산
노드재귀 식 (NULL = 0)반환값
L1, L2, L31 + 0 + 01
X1 + count(L1) + count(L2) = 1 + 1 + 13
Y1 + count(L3) + 0 = 1 + 1 + 0 (오른쪽 NULL)2
R1 + count(X) + count(Y) = 1 + 3 + 26
(b) get_height 상향식 계산
노드재귀 식 (NULL = 0)반환값
L1, L2, L31 + max(0, 0)1
X1 + max(1, 1)2
Y1 + max(1, 0)2
R1 + max(2, 2)3
(c) + 1을 더하는 이유

max(...)는 왼쪽·오른쪽 서브트리 중 더 높은 쪽의 높이만 반환하므로, 현재 노드(서브트리 루트) 자신이 차지하는 한 층을 포함하려고 1을 더해요.

완성 답과 검산

(a) 완성 답: X = 3, Y = 2, R = 6. 전체 노드 수 직접 세기(R, X, Y, L1, L2, L3 = 6개) 및 1 + X(3) + Y(2) = 6과 일치해요(S7 p16 그림의 반환 패턴과 동일).

(b) 완성 답: 3. 루트에서 단말까지 가장 긴 경로 R → X → L1의 노드 개수가 3개이므로 높이 3과 일치해요.

(c) 완성 답: 1은 현재 노드 자신이 차지하는 한 층이에요. 경계값 대입 검산: 만약 1 +를 지우면 단말 노드 1개(L1)에서도 max(0, 0) = 0이 되어, 모든 트리의 높이가 0으로 무너져요. 두 함수 모두 node != NULL을 먼저 검사하고 지역 변수를 0으로 초기화하므로 NULL 역참조가 없어요.

실수하면 답이 이렇게 망가져요

높이도 개수처럼 양쪽을 더하면(1 + h(L) + h(R)): R에서 1 + 2 + 2 = 5가 되어 실제 층 수(3)가 아니라 노드 개수 식과 섞여 버려요.

Y의 오른쪽 자식이 비어 있는데 NULL을 1로 보거나 Y를 1로 세면: Y는 자신(1) + L3(1) + NULL(0) = 2예요.

해설을 가리고 스스로 확인해요

  1. get_node_count와 get_height가 함께 나오면 → 양쪽 재귀 결과를 +로 합치는지 max로 고르는지부터 표시하고 단말(1)에서 위로 채운다.
  2. 재귀 코드의 + 1 의미를 물으면 → + 1을 지웠을 때 단말 노드(NULL 두 개)에서 얼마가 반환되는지 대입해 확인한다.

떠올릴 개념·공식

개수: $1 + L + R$ (양쪽 합산), 높이: $1 + \max(L, R)$ (큰 쪽만 선택).

첫 줄

단말 L1~L3부터 count = 1, height = 1로 채워 올라가요.

핵심 답

(a) X 3, Y 2, R 6 (b) 3 (c) 1은 현재 노드 자신이 차지하는 한 층.

검산

노드 6개 보존, 최장 경로 R→X→L1 길이 3, +1 제거 시 모든 높이 0.
