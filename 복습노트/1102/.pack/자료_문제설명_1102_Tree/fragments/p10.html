문제를 읽어 볼게요

재귀 함수 mystery를 루트 3에서 불렀을 때 돌려주는 값 하나를 구하는 문제예요. 트리는 3 아래에 5와 1, 5 아래에 4와 2, 1 아래에 8과 6이 있어요. 함수가 어떤 노드의 값을 돌려주고 어떤 노드는 건너뛰는지 가려내는 게 핵심이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

함수 안에서 mystery(p->left)와 mystery(p->right)를 다시 부른다는 단서에서, 두 서브트리를 먼저 재귀 호출하고 돌아온 값을 합치는 꼴을 떠올려요. S7 p16~p17의 get_node_count, get_height와 같은 구조이고, 자식 결과를 먼저 받고 마지막에 지금 노드에서 합치니 후위 순회(LRV) 순서로 계산이 끝나요.

재귀는 종료 조건부터 읽어요.

  • p == NULL: 빈 자리는 0
  • 왼쪽·오른쪽이 모두 NULL인 단말 노드(terminal node): 자기 data
  • 그 밖(자식이 있는 노드): 두 서브트리 결과 중 큰 값, 곧 $\max(\text{왼쪽 결과}, \text{오른쪽 결과})$

셋째 경우에 자기 data를 쓰지 않는다는 점이 이 함수의 뜻을 정해요. 개념 위치: 높이 get_height.

첫 줄을 이렇게 써요

“단말 노드: 4, 2, 8, 6 → 각각 자기 값을 돌려줌.”

왜 이렇게 푸는지 함께 따라가요

아래에서 위로 반환값을 채워요. 호출은 루트에서 내려가지만, 값은 단말에서 정해져 올라와요.

노드해당 경우반환값
4, 2, 8, 6단말 노드4, 2, 8, 6
5자식 있음$\max(4, 2) = 4$
1자식 있음$\max(8, 6) = 8$
3(루트)자식 있음$\max(4, 8) = 8$

루트 3, 5, 1 자신의 값은 비교에 들어가지 않아요. 결국 이 함수는 단말 노드 값 중 가장 큰 값을 돌려주고, 이 트리에서는 8이에요.

이 트리는 모든 노드가 자식 0개 또는 2개라 p == NULL 줄은 실제로 쓰이지 않아요. 자식이 하나뿐인 노드가 있으면 빈 쪽에서 0이 올라와 비교에 들어가요.

완성 답과 검산

정답: 8.

뜻으로 다시 확인해요. 단말 노드 값 {4, 2, 8, 6}의 최댓값은 8이에요. 전체 노드 최댓값도 8이지만, 그건 이 트리에서 겹친 것이에요. 예를 들어 루트가 9였어도 결과는 8이에요.

함수 몸체를 그대로 둔 C 프로그램에 이 트리를 만들어 cc -std=c11 -Wall -Wextra로 컴파일·실행했더니 경고 없이 8이 나왔어요. 모든 함수가 NULL을 먼저 확인한 뒤에만 자식을 읽어서 정의되지 않은 동작도 없었어요. TreeNode와 max 정의는 문제에 없어 검산용으로 보충했어요(문제는 max가 큰 값을 돌려준다고 가정). 교과서에는 인쇄된 정답이 없어서 공식 답과의 대조는 하지 못했어요.

여기서 헷갈리기 쉬워요

  • “트리 전체의 최댓값”이라고 외우면 틀려요. 자식이 있는 노드는 자기 data를 비교하지 않아요.
  • 합(+)으로 착각해 4 + 2 + 8 + 6을 더하기 쉬워요. 이 함수는 max로 하나만 골라 올려요.

설명을 닫고 다시 해 봐요

  1. 세 경우(NULL·단말·그 밖)를 먼저 적고, 단말부터 반환값을 채워 보세요.
  2. 루트 값을 9로 바꾸면 결과가 바뀌는지 생각해 보세요.

첫 줄

단말 노드 4, 2, 8, 6은 자기 값을 돌려줘요.

떠올릴 개념·공식

  • 재귀는 종료 조건부터: NULL → 0, 단말 → data
  • 자식이 있으면 $\max(\text{왼쪽}, \text{오른쪽})$ — 자기 값은 안 씀
  • 두 서브트리 먼저, 합치기는 나중: 후위 순회 꼴

답과 검산

8 = 단말 노드 값의 최댓값. C11 실행 결과도 8이에요. 교과서 인쇄 정답은 없어요.

조건·구분과 확인

  • 트리 전체 최댓값과는 다른 함수예요. 루트가 더 커도 결과는 그대로예요.
