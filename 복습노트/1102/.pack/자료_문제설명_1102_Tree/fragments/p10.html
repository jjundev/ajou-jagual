핵심 조건과 구할 것

7노드 이진 트리(루트 3, 자식 5·1, 단말 4·2·8·6)의 루트에 재귀 함수 mystery(p)를 호출했을 때 반환값을 구해요(교과서 인쇄 정답은 없어요).

이 문제를 봤을 때 떠올릴 개념과 공식

코드 단서꺼낼 도구·해석이유와 조건
if (p == NULL) / 단말 조건 재귀 종료 조건 2개 빈 노드는 0, 자식이 모두 NULL인 단말 노드만 자기 p->data를 반환해요.
max(mystery(left), mystery(right)) 후위 순회 꼴 상향식 max 결합 S7 get_height처럼 양쪽 반환값만 비교하고, 내부 노드의 p->data는 식에 쓰지 않아요(정리노트).

종이에 쓰는 실제 첫 줄

단말 노드(left == NULL && right == NULL): 4, 2, 8, 6  →  각각 자기 data(4, 2, 8, 6) 반환

왜 이렇게 푸는지 함께 따라가요

호출은 루트 3에서 내려가지만 반환값은 단말에서부터 계산되어 올라와요.

노드 (data)분기 조건반환값 계산결과
4, 2, 8, 6단말 노드자기 p->data 반환4, 2, 8, 6
5자식 있음 (else)max(4, 2) (자기 값 5 미사용)4
1자식 있음 (else)max(8, 6) (자기 값 1 미사용)8
3 (루트)자식 있음 (else)max(4, 8) (자기 값 3 미사용)8

즉, mystery는 단말 노드 값 중 최댓값을 돌려주는 함수이고 답은 8이에요. 이 트리는 모든 노드가 자식 0개 또는 2개라 p == NULL 분기는 타지 않지만, 외자식 노드가 있다면 빈 쪽에서 0이 올라와 max 비교에 들어가요.

완성 답과 검산

완성 답: 8 (교과서 인쇄 정답 미기재).

  • 함수 성질 검산: 단말 집합 {4, 2, 8, 6}의 최댓값 $\max\{4, 2, 8, 6\} = 8$ 과 같아요.
  • 경계값·변형 검산: 루트 3을 9로 바꿔 대입해도 else 분기가 p->data를 참조하지 않으므로 max(4, 8) = 8이 불변이에요. 빈 트리 mystery(NULL)은 첫 if에서 0을 반환하며, NULL을 먼저 검사한 뒤 자식을 읽으므로 정의되지 않은 동작도 없어요.

실수하면 답이 이렇게 망가져요

“트리 전체의 최댓값”이라고 단정하면: 이 트리에서는 최댓값 8이 마침 단말에 있어 답이 같지만, 루트가 9인 트리에서는 내부 노드 값을 비교하지 않으므로 9가 아니라 8이 나와 틀려요.

결합 연산을 max 대신 +로 착각하면: 단말 값을 모두 더해 4 + 2 + 8 + 6 = 20을 답으로 적는 실수가 나요.

해설을 가리고 스스로 확인해요

  1. 트리 재귀 함수 코드를 보면 → else 분기 안에 자기 p->data가 들어 있는지부터 밑줄 쳐 확인한다.
  2. 반환값을 추적할 때 → 루트부터 식을 펼치지 말고 단말 노드 값부터 적어 위로 max를 올린다.

떠올릴 개념·공식

NULL→0, 단말→data, 내부 노드→max(left, right) (자기 data 미사용).

첫 줄

단말 4, 2, 8, 6이 먼저 자기 값을 반환해요.

핵심 답

8 (= 단말 노드 값의 최댓값, 인쇄 정답 없음).

검산

루트를 9로 바꿔도 결과는 8, mystery(NULL) = 0으로 안전.
