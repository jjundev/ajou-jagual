=== UB 점검 ===
- 두 프로그램 모두 -Wall -Wextra 경고 0건, ASan+UBSan 실행에서 보고 0건, exit 0.
- mystery: p==NULL 을 먼저 검사한 뒤에만 p->left/p->right 를 읽음 -> NULL 역참조 없음. 자식이 하나뿐인 노드도 NULL 쪽은 0 을 돌려받음(이 트리엔 그런 노드 없음).
- get_node_count/get_height: count/height 를 0 으로 초기화하고 node!=NULL 일 때만 역참조 -> 미초기화·NULL 역참조 없음. Y 의 오른쪽 NULL 은 0 반환.
- main 의 노드는 모든 필드를 초기화한 자동 변수(left/right 명시 NULL).
- 참고: max 는 사용자 정의 함수(표준 헤더에 없음)라 이름 충돌 없음. p12 의 data 는 char 라 L1·L2·L3 를 '1','2','3' 으로 저장(라벨 표기만의 차이, 결과 무관).
- (c) +1 을 빼면 모든 노드에서 max(0,0)=0 이 전파되어 높이가 항상 0 -> +1 은 현재 노드 자신의 층 하나를 세기 위함.
