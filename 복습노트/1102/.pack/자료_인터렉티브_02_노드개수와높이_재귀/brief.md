# 노드 개수와 높이의 재귀 반환

양쪽 자식이 돌려준 값은 어느 호출의 변수에 들어가고, 개수와 높이에서 어떻게 쓰일까요?

강의의 두 알고리즘을 calc로 합치고 sum으로 계산을 고릅니다. 양쪽 호출을 별도 문장에 두어 화면의 왼쪽→오른쪽 실행이 C 코드와 일치합니다. p16의 트리 모양을 보존하고 식별용 숫자와 다른 트리 사례를 보충했습니다.
