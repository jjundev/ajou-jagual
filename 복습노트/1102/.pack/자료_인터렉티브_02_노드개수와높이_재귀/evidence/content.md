# 내용 검토

강의록 S7 16쪽·17쪽, 1102 정리노트의 get_node_count·get_height 절, 녹취 Part 07을 대조했다. 16쪽의 트리 모양과 각 하위 트리의 개수 3·2를 확인했다. 17쪽 코드에 따라 높이는 현재 루트 한 층을 포함한다.

- 호출자 1행과 함수 4·5행에서 root 또는 해당 자식 링크가 가리키는 주소 값을 새 호출의 p에 복사한다. 재귀 호출에서 sum도 현재 호출에서 복사된다. 노드 필드는 그대로 유지된다.
- 2행에서 NULL이면 0을 호출자의 목적지에 쓴 뒤 현재 호출의 매개변수 수명이 끝난다. 왼쪽 호출의 저장 목적지는 호출자의 l이고 복귀 위치는 5행이다. 오른쪽 호출의 저장 목적지는 호출자의 r이고 복귀 위치는 6행이다. 루트의 저장 목적지는 result다.
- 3행은 l과 r을 선언한다. 각 값은 해당 자식이 반환한 순간부터 읽을 수 있다. 6행에서 sum을 평가한다. 7행과 8행의 계산은 두 자식 호출이 모두 끝난 뒤 각각 l과 r을 읽고, 개수는 1 + l + r, 높이는 1 + max(l, r)를 반환한다. 호출자의 값을 쓴 뒤 현재 호출의 지역 Cell 수명이 끝난다.
- 강의 트리에서 루트의 두 개수는 3과 2이고 결과는 6이다. 루트의 두 높이는 2와 2이고 결과는 3이다. 한 노드와 빈 트리에서는 두 계산 모두 각각 1과 0이다. 오른쪽 경사 사례는 오른쪽 높이가 더 큰 경우를 보여 준다.
- 강의 표현을 비교용 calc로 보충했다. 두 자식 호출을 별도 문장으로 두어 왼쪽에서 오른쪽으로 진행하는 순서를 명시했다. 8행의 max는 독립 C 검산에서 작은 정수 함수로 보충했으며, 재생에서는 해당 산술식과 함수 반환을 한 줄로 보여 준다.
