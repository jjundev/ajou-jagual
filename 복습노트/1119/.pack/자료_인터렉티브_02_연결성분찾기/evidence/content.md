# 내용 검토

- 강의록 p17의 외부 루프는 visited[i]가 0일 때만 count를 증가시키고 dfs_mat을 부른다. 슬라이드 여백의 성분 번호 표기를 p14의 실질적인 방문 대입문인 visited[v] = count로 옮겼다. 부모 간선 기록은 학습용으로 추가했다.
- 바깥 함수가 가진 i는 값으로 DFS의 v에 전달된다. 바깥 함수는 DFS 전체가 반환할 때까지 같은 i에서 대기하므로, 그동안 count도 그대로다. 재귀 호출의 v는 직전 프레임의 w를 복사한다.
- 강의 사례의 i = 0에서 count가 1이 되고 0, 1, 2가 1을 받는다. i = 1과 i = 2는 읽기만 하고 건너뛴다. i = 3에서 count가 2가 되고 3, 4가 2를 받는다. 마지막 i = 4는 이미 표시되어 있다.
- (2,3)을 추가하면 첫 DFS가 3, 4까지 방문해 모든 값이 1이다. (3,4)를 제거하면 i = 3에서 3만 값 2를 받고 i = 4가 다시 count를 올려 값 3을 받는다. 세 사례는 출력 순서가 같아도 visited와 count가 다르므로 별도로 확인했다.
