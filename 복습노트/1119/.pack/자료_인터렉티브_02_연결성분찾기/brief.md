# 학습 질문

DFS가 반환된 다음 바깥 루프의 i와 count는 어떻게 움직이며, 간선 하나가 성분 번호를 어떻게 바꾸나요?

## 입력과 관찰

강의 예제는 간선 (0,1), (0,2), (3,4)입니다. 보충 사례는 (2,3)을 연결해 하나로 합치거나 (3,4)를 제거해 3과 4를 고립시킵니다.

visited는 시작 전 모두 0입니다. 첫 DFS는 count 1, 두 번째 DFS는 count 2를 쓰며, 각 DFS는 다음 count 증가 전에 끝납니다. 출력은 DFS가 실제 방문한 순서입니다.

## 출처와 검산

강의록 Software_10_Graph.pdf p14, p17 및 1119 정리노트와 STT를 참고했습니다. 화면의 코드는 출처가 표시된 보충 C입니다. 동일한 C 함수의 분기와 상태 변경을 clang 실행으로 관찰해 Trace와 대조합니다.
