핵심 조건과 구할 것

정점 0에서 출발한 DFS와 BFS가 각각 어떤 간선을 타고 처음 방문했는지를 모아 두 신장 트리를 그려요.

  • 간선 10개, 정점 8개: 트리에는 간선이 $8-1=7$개만 남고 3개는 빠져요.
  • 작은 번호 먼저: 이웃을 볼 때 항상 오름차순으로 봐요. 이 규칙 때문에 답이 하나로 정해져요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구이 문제에 쓰는 이유
‘DFS(0) spanning tree’깊이 우선 탐색(depth-first search, DFS)의 재귀 호출과 호출 스택미방문 이웃을 찾으면 그 간선 (v, w)로 바로 내려가요. 이 간선이 트리 간선이에요(정리노트 DFS 추적).
‘BFS(0) spanning tree’너비 우선 탐색(breadth-first search, BFS)의 큐(queue)꺼낸 정점의 미방문 이웃을 한꺼번에 방문 표시하고 넣어요. 표시할 때 쓴 간선이 트리 간선이에요(정리노트 BFS 추적).
‘spanning tree’신장 트리 = 모든 정점 + 사이클 없음, 간선 $n-1$개탐색이 끝났을 때 트리 간선이 7개인지로 검산해요(정리노트 신장 트리).

종이에 쓰는 실제 첫 줄

0: 1, 2    1: 0, 3, 4    2: 0, 5, 6    3: 1, 7
4: 1, 7    5: 2, 7       6: 2, 7       7: 3, 4, 5, 6

그림의 간선을 정점별 이웃 목록(오름차순)으로 옮겨 적고, 이 목록만 보며 추적해요.

왜 이렇게 푸는지 함께 따라가요

  1. DFS(0): 현재 정점의 이웃을 작은 번호부터 보다가 미방문이면 즉시 그쪽으로 재귀 호출해요.
    방문트리 간선건너뛴 이웃호출 스택
    $0$ 시작-[0]
    $1$ 0-1-[0, 1]
    $3$ 1-30(방문함)[0, 1, 3]
    $7$ 3-71(방문함)[0, 1, 3, 7]
    $4$ 7-43(방문함)[0, 1, 3, 7, 4]
    $5$ 7-54의 이웃 1, 7 모두 방문 → 4 반환[0, 1, 3, 7, 5]
    $2$ 5-2-[0, 1, 3, 7, 5, 2]
    $6$ 2-60, 5(방문함)[0, 1, 3, 7, 5, 2, 6]

    6에서 7은 이미 방문했고, 돌아오면서 남은 이웃(7의 6, 1의 4, 0의 2)도 모두 방문했으니 새 간선은 없어요.

  2. DFS(0) 결과: 방문 순서 0, 1, 3, 7, 4, 5, 2, 6 · 트리 간선 0-1, 1-3, 3-7, 7-4, 7-5, 5-2, 2-6. {{SVG:p1-dfs}}
  3. BFS(0): 큐 앞에서 하나 꺼내고, 그 정점의 미방문 이웃을 작은 번호부터 모두 방문 표시한 뒤 큐 뒤에 넣어요.
    꺼낸 정점새로 방문(트리 간선)큐(앞→뒤)
    시작0[0]
    $0$ 1 (0-1), 2 (0-2)[1, 2]
    $1$ 3 (1-3), 4 (1-4)[2, 3, 4]
    $2$ 5 (2-5), 6 (2-6)[3, 4, 5, 6]
    $3$ 7 (3-7)[4, 5, 6, 7]
    4, 5, 6, 7없음(이웃 모두 방문함)[] 종료
  4. BFS(0) 결과: 방문 순서 0, 1, 2, 3, 4, 5, 6, 7 · 트리 간선 0-1, 0-2, 1-3, 1-4, 2-5, 2-6, 3-7. 7은 3을 꺼낼 때 먼저 표시되니 4-7, 5-7, 6-7은 빠져요. {{SVG:p1-bfs}}

완성 답과 검산

완성 답: DFS(0) 트리 간선 0-1, 1-3, 3-7, 7-4, 7-5, 5-2, 2-6 / BFS(0) 트리 간선 0-1, 0-2, 1-3, 1-4, 2-5, 2-6, 3-7.

  • 개수: 두 트리 모두 간선 7개 $=8-1$이고, 정점 0~7이 모두 한 번씩 등장해요.
  • 빠진 간선 확인: DFS에서 빠진 0-2, 1-4, 6-7은 각각 방문할 때 상대가 이미 방문된 간선이에요. 예를 들어 0-2를 넣으면 0-1-3-7-5-2-0 사이클이 생겨요.
  • BFS 깊이: BFS 트리에서 7의 깊이는 3(0→1→3→7)이고, 그래프에서 0과 7 사이 최소 간선 수도 3이에요. BFS는 가까운 정점부터 방문하니 두 값이 같아야 해요.

오해하기 쉬운 이유와 반례

  • DFS도 형제를 먼저 다 표시한다고 생각하면: 0에서 1, 2를 함께 표시해 0-2를 트리 간선으로 넣게 돼요. 실제 DFS는 1로 내려간 뒤 7, 5를 거쳐 5-2로 2에 도착해요.
  • DFS가 7에서 4로 간 뒤 4의 자식으로 5를 붙이면: 4의 이웃은 1, 7뿐이라 4는 막다른 정점이에요. 5는 7로 되돌아온 뒤 7의 다음 이웃으로 방문되니 간선은 7-5예요.

해설을 닫고 스스로 확인해요

  1. 그래프 그림을 보면 → 정점별 오름차순 이웃 목록부터 적는다.
  2. DFS는 호출 스택 열, BFS는 큐 열을 만든 표로 추적하고, 끝나면 트리 간선이 $n-1$개인지 센다.
  3. 시작을 7로 바꾸면 BFS(7)의 첫 줄 큐는 무엇이 될지 적어 보세요.

첫 줄

오름차순 이웃 목록 0: 1, 2 / 1: 0, 3, 4 / … / 7: 3, 4, 5, 6.

핵심 판단

DFS는 미방문 이웃으로 즉시 내려가고(스택), BFS는 꺼낸 정점의 이웃을 한꺼번에 표시해요(큐). 방문할 때 쓴 간선이 트리 간선이에요.

답과 검산
