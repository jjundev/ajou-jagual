핵심 조건과 구할 것

find_connected_component(g)를 한 번 호출했을 때의 (a) 출력 순서, (b) 최종 visited[0..7], (c) 최종 count와 그 의미를 구해요.

  • 바뀐 한 줄: dfs_mat이 방문 표시로 1(TRUE) 대신 count를 적어요(visited[v] = count;).
  • 그래프: 간선 (0,2), (0,5), (1,3), (2,5), (3,6), (4,6), 정점 7은 간선 없음. 전역 visited와 count는 처음에 0이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구이 문제에 쓰는 이유
for(i=0; i<g->n; i++) if(!visited[i])연결 성분(connected component) 세기DFS 한 번이 성분 하나를 통째로 방문하니, 새 DFS를 시작하는 횟수가 성분 수예요(정리노트 연결 성분).
visited[v] = count;성분 번호표같은 DFS 안에서는 count가 변하지 않으니 한 성분의 정점이 모두 같은 번호를 받아요.
!visited[w]0이면 미방문count는 dfs_mat을 부르기 전에 1 이상이 되므로, 0이 아닌 값은 모두 ‘방문함’이에요.
w = 0..n-1 순회인접 행렬 DFS의 이웃 오름차순출력 순서(a)를 정해요(정리노트 DFS 코드).

종이에 쓰는 실제 첫 줄

0: 2, 5    1: 3    2: 0, 5    3: 1, 6    4: 6    5: 0, 2    6: 3, 4    7: (없음)
i=0: visited[0]==0 → count=1, dfs_mat(g,0)

왜 이렇게 푸는지 함께 따라가요

단계일어나는 일출력 누적visited[0..7]

0의 이웃w=2 미방문 → dfs_mat(g,2)0 21 0 1 0 0 0 0 0
2의 이웃0 방문함, w=5 → dfs_mat(g,5)0 2 51 0 1 0 0 1 0 0
복귀5의 0, 2 방문함 → 반환, 0의 w=5도 방문함0 2 51 0 1 0 0 1 0 0

(a) 출력은 0 2 5 1 3 6 4 7이에요. 성분마다 DFS 방문 순서대로 찍혀요.

(b) visited = [1, 2, 1, 2, 2, 1, 2, 3]이에요. 정점 0, 2, 5는 성분 1, 정점 1, 3, 4, 6은 성분 2, 정점 7은 성분 3이에요.

(c) count = 3이에요. 연결 성분이 3개라는 뜻이고, 간선이 없는 정점 7도 혼자서 하나의 연결 성분이에요.

완성 답과 검산

(a) 0 2 5 1 3 6 4 7 — 정점 8개가 한 번씩 나와요. 출력을 count가 바뀌는 곳에서 끊으면 0 2 5 | 1 3 6 4 | 7이고, 각 묶음의 정점이 (b)에서 같은 번호(1, 2, 3)를 받아요. 같은 두 함수에 선언·main을 붙여 cc -std=c11 -Wall로 실행해도 출력이 같아요.

(b) [1, 2, 1, 2, 2, 1, 2, 3] — 간선 6개의 양 끝이 모두 같은 번호예요: (0,2)=1·1, (0,5)=1·1, (2,5)=1·1, (1,3)=2·2, (3,6)=2·2, (4,6)=2·2. 번호가 다른 정점 사이에 간선이 없으니 성분 구분이 맞아요.

(c) count = 3 — visited의 최댓값 3과 같고, 성분 크기 $3+4+1=8$이 정점 수와 맞아요. 수업 예제(간선 (0,1), (0,2), (3,4))의 count = 2와 같은 방식이에요.

오해하기 쉬운 이유와 반례

  • count를 DFS 안에서 올린다고 착각하면: 방문할 때마다 번호가 커져 visited가 [1, 4, 2, 5, 7, 3, 6, 8]처럼 방문 순서 번호가 돼요. count++는 바깥 for 문에만 있어서 새 DFS를 시작할 때만 커져요.
  • 간선 없는 정점 7을 성분에서 빼면: count를 2로 답하게 돼요. 정점 하나도 최대로 연결된 부분 그래프라서 성분 하나예요.

해설을 닫고 스스로 확인해요

  1. visited[i] = count 코드를 보면 → count가 증가하는 위치(바깥 for 문)부터 표시한다.
  2. 간선 (5, 7)을 추가하면 (a)~(c)가 어떻게 바뀔지 표로 다시 따라가 보세요.

첫 줄

이웃 목록 0: 2, 5 / 1: 3 / … / 7: 없음, i=0에서 count=1, dfs_mat(g,0).

핵심 판단

count는 새 DFS를 시작할 때만 1 커지고, DFS 한 번이 한 성분 전체에 같은 번호를 적어요.
