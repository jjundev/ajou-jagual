정점 8개(0~7)인 무방향 그래프를 인접 행렬 g->adj_mat로 저장했어요(g->n = 8). 간선은 (0,2), (0,5), (1,3), (2,5), (3,6), (4,6)이고 정점 7은 간선이 없어요. 간선 (u,v)가 있으면 adj_mat[u][v]와 adj_mat[v][u]가 1, 나머지는 0이에요.

GraphType은 정점 수 n과 인접 행렬 adj_mat을 가진 구조체이고, visited[]와 count는 전역 변수라 처음에 모두 0이에요. 아래 코드로 find_connected_component(g)를 한 번 호출해요.

void dfs_mat(GraphType *g, int v)
{
    int w;
    visited[v] = count;
    printf("%d ", v);
    for(w=0; w<g->n; w++)
        if( g->adj_mat[v][w] && !visited[w] )
            dfs_mat(g, w);
}
void find_connected_component(GraphType *g)
{
    int i;
    count = 0;
    for(i=0; i<g->n; i++)
        if(!visited[i]){
            count++;
            dfs_mat(g, i);
        }
}
