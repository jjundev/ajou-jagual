# 내용 검토

- S9 p18의 왼쪽 네 원소에서 [10, 27]과 [12, 20]을 합병하는 그림을 확인했다. STT Part 06–07 및 정리노트 s1-merge-join과 대조했다.
- p21 의사코드의 b1, b2, index 초기값과 범위 확인을 보충 C의 3–8행에 대응시켰다. 오른쪽 경계와 왼쪽 경계는 right와 mid를 직접 읽는다.
- 8행 아래에서 선택된 쪽의 배열 원소를 읽고 9행 또는 12행에서 sorted에 쓴 뒤, 선택된 인덱스 하나와 공통 index를 늘린다. 기본 예제에서는 오른쪽 소진 뒤 27이 왼쪽 꼬리에서 복사된다. 별도 예제에서는 왼쪽 소진 뒤 오른쪽 꼬리를 복사한다.
- 같은 키 2에서는 원문과 같은 <가 오른쪽을 먼저 선택한다. <= 보충 사례는 왼쪽을 먼저 선택한다. 최종 키 배열은 같으나 첫 선택의 원본 인덱스가 각각 2와 0으로 다르다. 이 차이를 동일 입력에서 확인했다.
- 27–28행의 원본 갱신은 sorted[0..3]을 순서대로 읽어 list[0..3]에 쓴다. 반환 뒤 sorted의 수명을 끝내며 list는 호출자에 남는다.
