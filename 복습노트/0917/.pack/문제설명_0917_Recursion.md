#### 문제를 내 말로 읽어요

빈 gcd 본문을 채워 양의 두 정수의 최대공약수를 반환해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“순환 함수”와 “최대공약수”에서 gcd(i,j)=gcd(j,i%j)를 떠올려요. %를 계산하기 전에 j=0을 검사해야 나눗셈 오류 없이 종료해요.

#### 종이에 적을 첫 줄

`if (j == 0) return i;`

#### 왜 이렇게 푸는지 함께 따라가요

`int gcd(int i, int j) {
    if (j == 0) return i;
    return gcd(j, i % j);
}`

#### 완성 답과 검산

gcd(48,18)→(18,12)→(12,6)→(6,0)→6이에요. 반환값은 추가 계산 없이 위 호출로 전달돼요. 공약수 집합 보존과 두 번째 인자의 감소가 정확성과 종료를 증명해요. 입력 변환 성공과 양의 int 범위를 가정해요.

#### 이 문제에서 조심할 점

if 앞에서 i%j를 계산하면 마지막 호출에서 %0을 하게 돼요. “0이 모든 수를 나눈다”가 아니라 모든 양의 수가 0을 나눈다는 뜻이에요.

#### 설명을 닫고 다시 해 봐요

1. if (j == 0) return i;
2. j=0 종료, 아니면 gcd(j,i%j)
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 떠올릴 개념·공식

j=0 종료, 아니면 gcd(j,i%j)

### P5. 거듭제곱: 홀수 분기와 호출 크기

lecture-s02-p10-power · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p5)

**강의 예제 기반 자체 출제** S2 p10

아래 순환 함수 `power(x, n)`은 `n >= 0`일 때 지수를 절반으로 줄여 $x^n$을 구해요(중간 계산은 `double` 범위 안에 있다고 가정해요).

`double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return /* 빈칸 */;
}`

#### 구할 것

- (a) 홀수 분기의 `/* 빈칸 */`에 들어갈 반환식을 쓰고, `power(2, 5)`의 `(x, n)` 호출 순서와 각 단계 반환값을 구하세요.
- (b) 한 번에 `x`를 한 번씩 곱하는 `slow_power(x, n)`과 `power(x, n)`의 시간복잡도를 빅오 표기로 비교하고 이유를 설명하세요.

<details><summary>강의 예제 보기</summary>

S2 p10 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

`double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return x*power(x*x,(n-1)/2);
}`

</details>

#### 문제를 내 말로 읽어요

지수를 절반으로 줄이는 순환 거듭제곱 함수 `power(x, n)`의 홀수 분기 식을 완성해 `power(2, 5)`를 추적하고, 단순 반복 곱셈 `slow_power`와 시간복잡도를 비교하는 문제예요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “거듭제곱: 홀수 분기와 호출 크기”예요. 홀수 $n = 2k + 1$이면 $x^n = x \cdot (x^2)^{(n-1)/2}$ 항등식이 성립하며, 호출마다 지수가 절반으로 줄면 시간복잡도는 $O(\log n)$이 돼요.

#### 종이에 적을 첫 줄

`5 = 2 * 2 + 1`이므로 `2 * power(4, 2)`부터 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

(a) 홀수 $n$에서는 $x$를 한 번 곱하고 밑을 $x^2$, 지수를 $(n-1)/2$로 줄여야 하므로 빈칸 식은 `x * power(x * x, (n - 1) / 2)`예요. `power(2, 5)`는 `(2, 5) → (4, 2) → (16, 1) → (256, 0)` 순서로 호출되며, `(256, 0)`에서 `1`을 반환한 뒤 역순으로 `1 → 16 → 16 → 32`를 반환해요.

(b) `power(x, n)`은 매 단계 지수 `n`이 절반으로 줄어 호출 횟수가 $\log_2 n$에 비례하므로 $O(\log n)$이고, `slow_power(x, n)`은 루프를 `n`번 돌며 곱하므로 $O(n)$이에요($n \ge 1$).

#### 완성 답과 검산

(a) $2^5 = 32$이고, 역순 계산 $1 \to 16 \times 1 = 16 \to 16 \to 2 \times 16 = 32$와 정확히 일치해요.

(b) 지수 $n = 2^k$일 때 `power`는 약 $k = \log_2 n$번 호출되고 `slow_power`는 $n$번 반복됨을 확인해요.

#### 이 문제에서 조심할 점

짝수 분기를 `power(x, n / 2)`로 쓰면 밑을 제곱하지 않아 원래 거듭제곱과 달라져요.

#### 설명을 닫고 다시 해 봐요

1. 홀수 지수 항등식으로부터 홀수 분기 반환식을 적어요.
2. `power(2, 5)`의 `(x, n)` 호출 쌍과 반환값을 차례로 추적해요.
3. `power`와 `slow_power`의 빅오 시간복잡도를 비교해요.

**페이지 요약**

#### 첫 줄

`5 = 2 * 2 + 1`이므로 `2 * power(4, 2)`부터 적어요.

#### 떠올릴 개념·공식

홀수 지수: $x^n = x \cdot (x^2)^{(n-1)/2}$, 절반 감소 순환의 복잡도는 $O(\log n)$.

#### 검산

(a) `x * power(x * x, (n - 1) / 2)`, 호출 `(2, 5) → (4, 2) → (16, 1) → (256, 0)`, 반환 `1 → 16 → 16 → 32` (b) `power`: $O(\log n)$, `slow_power`: $O(n)$.

### P6. 피보나치의 중복 호출과 반복 상태

lecture-s02-p12-fibonacci · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p6)

**강의 예제 기반 자체 출제** S2 p12

아래는 피보나치 수열을 순환으로 구현한 `fib(n)` 함수예요.

`int fib(int n)
{
    if(n==0) return 0;
    if(n==1) return 1;
    return fib(n-1)+fib(n-2);
}`

#### 구할 것

- (a) `fib(6)`의 반환값과 실행 중 `fib(3)`이 호출되는 횟수를 구하고, 순환 구현에서 같은 부분 문제가 중복 호출되는 이유를 설명하세요.
- (b) 반복 구현에서 `last = F(i - 2)`, `current = F(i - 1)`인 상태를 다음 단계로 갱신할 때 임시 변수 `tmp`를 사용한 세 대입문을 순서대로 쓰세요.

<details><summary>강의 예제 보기</summary>

S2 p12 · 추가 근거 p13,14 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

`int fib(int n)
{
    if(n==0) return 0;
    if(n==1) return 1;
    return fib(n-1)+fib(n-2);
}`

</details>

#### 문제를 내 말로 읽어요

순환 피보나치 `fib(6)`의 결과와 `fib(3)` 중복 호출 횟수·원인을 구하고, 반복 피보나치에서 이전 두 항을 갱신하는 대입문을 작성하는 문제예요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “피보나치의 중복 호출과 반복 상태”예요. $F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)$에서 순환 구현은 같은 하위 문제를 저장 없이 반복 호출하고, 반복 구현은 직전 두 항(`last`, `current`)과 임시 변수 `tmp`로 상태를 한 칸씩 밀어요.

#### 종이에 적을 첫 줄

`F(0) = 0, F(1) = 1`을 적고 `fib(6)`의 두 자식을 `fib(5), fib(4)`로 나눠요.

#### 왜 이렇게 푸는지 함께 따라가요

(a) 수열을 차례로 구하면 `0, 1, 1, 2, 3, 5, 8`이므로 `fib(6) = 8`이에요. 호출 트리에서 `fib(6)`은 `fib(5)`와 `fib(4)`를 부르고, `fib(5)` 하위(`fib(4) + fib(3)`)에서 `fib(3)`이 `2`번, `fib(4)` 하위(`fib(3) + fib(2)`)에서 `fib(3)`이 `1`번 불려 총 `3`회 호출돼요. 두 자식 호출의 하위 문제가 겹치는데 이미 구한 값을 저장하지 않기 때문에 중복 호출이 생겨요.

(b) 반복 구현에서는 `current`가 새 합으로 덮어써지기 전에 먼저 `tmp = current;`로 보관하고, `current += last;`로 다음 항 $F(i)$를 만든 뒤, `last = tmp;`로 이전 `current`를 `last`에 넣어요.

#### 완성 답과 검산

(a) 호출 횟수를 $C(n)$이라 하면 `fib(3)` 호출 수는 $C(6 \to 3) = C(5 \to 3) + C(4 \to 3) = (1 + 1) + 1 = 3$회로 트리와 일치해요.

(b) `last = 1, current = 2`에 세 문장을 실행하면 `tmp = 2`, `current = 3`, `last = 2`가 되어 다음 두 항 `(2, 3)`으로 정확히 갱신돼요.

#### 이 문제에서 조심할 점

값 `F(3) = 2`와 `fib(3)`의 호출 횟수 `3`회를 혼동하지 마세요.

#### 설명을 닫고 다시 해 봐요

1. `fib(6)`의 호출 트리를 그려 `fib(3)`이 몇 번 나타나는지 세어요.
2. 순환 구현에서 중복 호출이 발생하는 이유를 한 문장으로 적어요.
3. `tmp`, `current`, `last`의 갱신 대입 순서 3줄을 적고 값을 대입해 확인해요.

**페이지 요약**

#### 첫 줄

`F(0) = 0, F(1) = 1`을 적고 `fib(6)`의 두 자식을 `fib(5), fib(4)`로 나눠요.

#### 떠올릴 개념·공식

순환 피보나치는 하위 호출이 겹쳐 중복 계산하며, 반복 구현은 `tmp`로 이전 `current`를 보존해요.

#### 검산

(a) `fib(6) = 8`, `fib(3)` 호출 `3`회 (하위 호출 중복·미저장) (b) `tmp = current; current += last; last = tmp;`

### P7. 함수 foo는 무엇을 할까요

2019-mid-q8 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p7)

입력 조건: x와 y는 양의 정수예요. y=0은 이 함수의 유효 입력이 아니에요.

아래에 함수 foo의 코드가 있어요. 이 함수를 호출하면 무엇을 하는 함수인지 답해 보세요.

함수 foo는 ( ) 함수이다.

`int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}`

<details><summary>기출 원문 보기</summary>

2019 중간 8번 · 2점 · 출제자 미상

> "아래에는 함수 foo에 대한 코드가 있으며 이 함수를 호출(사용)하였을 때 무엇을 하는 함수인지에 대해서 답을 하시오. 함수 foo는 ( ) 함수이다. (2점)"

`int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}`

</details>

입력 x와 y는 양의 정수예요. y=0에서 나머지 연산은 정의되지 않아요.

#### 문제를 내 말로 읽어요

코드가 어떤 문제를 푸는지 이름이 아니라 인자 변화로 판단해요. 입력은 양의 정수 x,y로 두어요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

x%y라는 “나머지”와 (y,x%y) 호출은 Euclidean algorithm의 단서예요. x=qy+r일 때 x,y의 공약수 집합은 y,r의 공약수 집합과 같아요. y&gt;0일 때 0≤r&lt;y예요.

#### 종이에 적을 첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

(48,18)→(18,12)→(12,6)에서 나머지가 0이 되어 6을 반환해요. 공약수 d가 x,y를 나누면 x−qy=r도 나누고, 반대로 y,r을 나누면 qy+r=x도 나눠요. 그래서 매 호출의 최대공약수가 같아요. 나머지가 양의 이전 y보다 작아 종료해요.

#### 완성 답과 검산

48의 약수와 18의 약수 중 공통 최대는 6이에요. 순서를 바꾼 foo(18,48)도 (48,18)로 이어져 6이에요. 따라서 답은 최대공약수 GCD예요.

#### 이 문제에서 조심할 점

원 함수는 y=0에서 %0이므로 정의되지 않아요. 양의 입력 조건 없이 모든 정수에 안전하다고 쓰지 않아요.

#### 설명을 닫고 다시 해 봐요

1. foo(48,18)에서 나머지 12를 첫 줄에 적어요.
2. 나머지로 줄이는 유클리드 호제법
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

#### 떠올릴 개념·공식

나머지로 줄이는 유클리드 호제법

#### 검산
