#### 문제를 내 말로 읽어요

빈 gcd 본문을 채워 양의 두 정수의 최대공약수를 반환해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“순환 함수”와 “최대공약수”에서 gcd(i,j)=gcd(j,i%j)를 떠올려요. %를 계산하기 전에 j=0을 검사해야 나눗셈 오류 없이 종료해요.

#### 종이에 적을 첫 줄

`if (j == 0) return i;`

#### 왜 이렇게 푸는지 함께 따라가요

`int gcd(int i, int j) {
    if (j == 0) return i;
    return gcd(j, i % j);
}`

#### 완성 답과 검산

gcd(48,18)→(18,12)→(12,6)→(6,0)→6이에요. 반환값은 추가 계산 없이 위 호출로 전달돼요. 공약수 집합 보존과 두 번째 인자의 감소가 정확성과 종료를 증명해요. 입력 변환 성공과 양의 int 범위를 가정해요.

#### 이 문제에서 조심할 점

if 앞에서 i%j를 계산하면 마지막 호출에서 %0을 하게 돼요. “0이 모든 수를 나눈다”가 아니라 모든 양의 수가 0을 나눈다는 뜻이에요.

#### 설명을 닫고 다시 해 봐요

1. if (j == 0) return i;
2. j=0 종료, 아니면 gcd(j,i%j)
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

#### 떠올릴 개념·공식

j=0 종료, 아니면 gcd(j,i%j)

### P3. 3씩 줄어드는 호출

textbook-ch02-q09 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p3)

`int recursive(int n)
{

원래 sum의 결과를 유지하면서 자기 호출을 반복문으로 바꿔요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“비순환적”은 accumulator와 loop의 단서예요. 원 코드가 양의 n에서 더한 항 1..n을 반복문도 한 번씩 더하면 같아요.

#### 종이에 적을 첫 줄

`int total = 0;`

#### 왜 이렇게 푸는지 함께 따라가요

`int sum(int n) {
    int total = 0;
    for (int i = 1; i <= n; ++i) total += i;
    return total;
}`

#### 완성 답과 검산

n=1→1, n=4→10으로 원 순환과 같아요. 각 i 뒤 total=1+…+i 불변식이 모든 양의 입력의 동일성을 보장해요. 계산이 int 범위 안이고 i++도 범위를 넘지 않는 입력을 가정해요.

순환이 아닌 코드를 요구하므로 본문에서 sum을 다시 부르면 안 돼요. n≤0은 원 코드의 정의된 입력이 아니에요.

#### 설명을 닫고 다시 해 봐요

1. int total = 0;
2. 0에서 1..n 누적, 호출 제거
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

### P5. 거듭제곱: 홀수 분기와 호출 크기

lecture-s02-p10-power · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p5)

**강의 예제 기반 자체 출제** S2 p10

n≥0이고 중간 계산이 double 범위 안에 있다고 가정해요. 홀수 분기를 가리고 반환식을 다시 쓰세요. power(2,5)의 (x,n) 호출 순서와 최종 반환값을 적고, 한 번씩 x를 곱하는 slow_power와 시간복잡도를 비교하세요.

`double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return /* 빈칸 */;
}`

<details><summary>강의 예제 보기</summary>

S2 p10 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

`double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return x*power(x*x,(n-1)/2);
}`

</details>

#### 문제를 내 말로 읽어요

n≥0이고 중간 계산이 double 범위 안에 있다고 가정해요. 홀수 분기를 가리고 반환식을 다시 쓰세요. power(2,5)의 (x,n) 호출 순서와 최종 반환값을 적고, 한 번씩 x를 곱하는 slow_power와 시간복잡도를 비교하세요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “거듭제곱: 홀수 분기와 호출 크기”예요. 홀수 n=2k+1이면 x^n=x×(x²)^k예요. 이 항등식에서 홀수 분기의 식이 나와요. 지수가 매번 절반으로 줄어 호출 깊이가 로그로 늘어요. 한 번에 1씩 줄이는 반복 곱셈은 n번 수행해요.

#### 종이에 적을 첫 줄

5=2×2+1이므로 2×power(4,2)부터 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

1. 홀수 n=2k+1이면 x^n=x×(x²)^k예요. 이 항등식에서 홀수 분기의 식이 나와요.
2. (2,5)는 2×power(4,2)를 기다리고, (4,2)는 power(16,1)을 기다려요.
3. (16,1)은 16×power(256,0)을 기다려요. 마지막 호출이 1을 반환하면 16,16,32로 돌아와요.
4. 지수가 매번 절반으로 줄어 호출 깊이가 로그로 늘어요. 한 번에 1씩 줄이는 반복 곱셈은 n번 수행해요.

홀수 분기 x\*power(x\*x,(n-1)/2). 호출 (2,5)→(4,2)→(16,1)→(256,0), 반환 1→16→16→32. power는 O(log n), slow_power는 O(n)이다(n≥1).

#### 완성 답과 검산

홀수 분기 x\*power(x\*x,(n-1)/2). 호출 (2,5)→(4,2)→(16,1)→(256,0), 반환 1→16→16→32. power는 O(log n), slow_power는 O(n)이다(n≥1).

시작 조건에서 다시 추적한 결과가 위 답과 일치해요. 지수가 매번 절반으로 줄어 호출 깊이가 로그로 늘어요. 한 번에 1씩 줄이는 반복 곱셈은 n번 수행해요.

#### 이 문제에서 조심할 점

짝수 분기를 power(x,n/2)로 쓰면 밑을 제곱하지 않아 원래 거듭제곱과 달라져요.

#### 설명을 닫고 다시 해 봐요

1. 주어진 시작 상태와 필요한 입력 조건을 적어요.
2. 첫 줄부터 연산 순서를 따라 답을 완성해요.
3. 경계 경우와 오류 경로를 확인해요.

**페이지 요약**

#### 첫 줄

5=2×2+1이므로 2×power(4,2)부터 적어요.

#### 떠올릴 개념·공식

홀수 n=2k+1이면 x^n=x×(x²)^k예요. 이 항등식에서 홀수 분기의 식이 나와요.

#### 검산

홀수 분기 x\*power(x\*x,(n-1)/2). 호출 (2,5)→(4,2)→(16,1)→(256,0), 반환 1→16→16→32. power는 O(log n), slow_power는 O(n)이다(n≥1).

### P6. 피보나치의 중복 호출과 반복 상태

lecture-s02-p12-fibonacci · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p6)

fib(6)의 값과 실행 중 fib(3)이 호출되는 횟수를 구하세요. 반복 구현에서 last=F(i-2), current=F(i-1)인 상태를 다음 단계로 갱신하려고 해요. tmp를 사용한 세 대입문을 쓰고, 왜 순환 구현에서 같은 부분 문제가 반복되는지 설명하세요.

    return fib(n-1)+fib(n-2);
}`

#### 문제를 내 말로 읽어요

fib(6)의 값과 실행 중 fib(3)이 호출되는 횟수를 구하세요. 반복 구현에서 last=F(i-2), current=F(i-1)인 상태를 다음 단계로 갱신하려고 해요. tmp를 사용한 세 대입문을 쓰고, 왜 순환 구현에서 같은 부분 문제가 반복되는지 설명하세요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “피보나치의 중복 호출과 반복 상태”예요. F(0)=0,F(1)=1이고 두 앞 항을 더하므로 0,1,1,2,3,5,8을 얻어요. last를 먼저 current로 바꿔 버리면 서로 다른 두 항의 합을 유지하지 못해요. 반복은 이미 구한 두 항을 재사용해요.

#### 종이에 적을 첫 줄

F(0)=0,F(1)=1을 적고 fib(6)의 두 자식을 fib(5),fib(4)로 나눠요.

#### 왜 이렇게 푸는지 함께 따라가요

1. F(0)=0,F(1)=1이고 두 앞 항을 더하므로 0,1,1,2,3,5,8을 얻어요.
2. fib(6)의 자식 fib(5),fib(4)를 나누어 그려요. fib(5) 쪽에서 fib(3)이 2번, fib(4) 쪽에서 1번 호출돼요.
3. 반복에서는 이전 current를 tmp에 먼저 보관해요. current에 last를 더해 새 항을 만들고 last를 이전 current로 옮겨요.
4. last를 먼저 current로 바꿔 버리면 서로 다른 두 항의 합을 유지하지 못해요. 반복은 이미 구한 두 항을 재사용해요.

fib(6)=8, fib(3)은 3회. tmp=current; current+=last; last=tmp;. 두 자식 호출의 하위 호출이 겹치고 계산 결과를 저장하지 않기 때문이다.

#### 완성 답과 검산

fib(6)=8, fib(3)은 3회. tmp=current; current+=last; last=tmp;. 두 자식 호출의 하위 호출이 겹치고 계산 결과를 저장하지 않기 때문이다.

시작 조건에서 다시 추적한 결과가 위 답과 일치해요. last를 먼저 current로 바꿔 버리면 서로 다른 두 항의 합을 유지하지 못해요. 반복은 이미 구한 두 항을 재사용해요.

#### 이 문제에서 조심할 점

### P7. 함수 foo는 무엇을 할까요

2019-mid-q8 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0917_Recursion.html#p7)

입력 조건: x와 y는 양의 정수예요. y=0은 이 함수의 유효 입력이 아니에요.

아래에 함수 foo의 코드가 있어요. 이 함수를 호출하면 무엇을 하는 함수인지 답해 보세요.

함수 foo는 ( ) 함수이다.

`int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}`

<details><summary>기출 원문 보기</summary>

2019 중간 8번 · 2점 · 출제자 미상

> "아래에는 함수 foo에 대한 코드가 있으며 이 함수를 호출(사용)하였을 때 무엇을 하는 함수인지에 대해서 답을 하시오. 함수 foo는 ( ) 함수이다. (2점)"

`int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}`

</details>

입력 x와 y는 양의 정수예요. y=0에서 나머지 연산은 정의되지 않아요.

#### 문제를 내 말로 읽어요

코드가 어떤 문제를 푸는지 이름이 아니라 인자 변화로 판단해요. 입력은 양의 정수 x,y로 두어요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

x%y라는 “나머지”와 (y,x%y) 호출은 Euclidean algorithm의 단서예요. x=qy+r일 때 x,y의 공약수 집합은 y,r의 공약수 집합과 같아요. y&gt;0일 때 0≤r&lt;y예요.

#### 종이에 적을 첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

(48,18)→(18,12)→(12,6)에서 나머지가 0이 되어 6을 반환해요. 공약수 d가 x,y를 나누면 x−qy=r도 나누고, 반대로 y,r을 나누면 qy+r=x도 나눠요. 그래서 매 호출의 최대공약수가 같아요. 나머지가 양의 이전 y보다 작아 종료해요.

#### 완성 답과 검산

48의 약수와 18의 약수 중 공통 최대는 6이에요. 순서를 바꾼 foo(18,48)도 (48,18)로 이어져 6이에요. 따라서 답은 최대공약수 GCD예요.

#### 이 문제에서 조심할 점

원 함수는 y=0에서 %0이므로 정의되지 않아요. 양의 입력 조건 없이 모든 정수에 안전하다고 쓰지 않아요.

#### 설명을 닫고 다시 해 봐요

1. foo(48,18)에서 나머지 12를 첫 줄에 적어요.
2. 나머지로 줄이는 유클리드 호제법
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

#### 떠올릴 개념·공식
