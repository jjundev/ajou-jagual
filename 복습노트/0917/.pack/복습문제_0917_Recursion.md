**정답:** x와 y의 최대공약수를 구해주는 (foo(48, 18) = 6)

셋째 루프를 글자 그대로 읽어 보세요. p가 아니라 j를 올리고, 조건도 `j<=i`예요. i 하나를 정해 두고 j가 어떻게 움직이는지 따라가 보세요.

<details><summary>풀이 보기</summary>

1. 문제 글은 `buffer[i][j] = 0;`이라고 했지만 코드의 대입은 `buffer[i][j] = 1;`이에요. 코드 속 이 대입 한 줄을 세면 돼요.
2. 넷째 루프: k = 1, 2, …, 29라서 대입이 29번이에요. k&lt;30이니 30번이 아니에요.
3. 셋째 루프 `for(p=1; j<=i; j++)`는 p를 1로 둘 뿐, 조건과 증가는 j에 걸려 있어요. 그래서 j가 i보다 커질 때까지 j를 올리며 돌아요.
4. i 하나를 정하면: 둘째 루프가 j=1로 들어와요 → 셋째 루프가 j = 1, 2, …, i로 i번 돌아요 → 이때 대입은 29·i번이에요.
5. 셋째 루프가 끝나면 j = i+1이고, 둘째 루프의 j++로 j = i+2가 돼요. 이 뒤로는 j&lt;=i가 늘 거짓이라 셋째 루프에 다시 들어가지 않아요. 그래서 i마다 대입은 29·i번뿐이에요.
6. i = 1, 2, …, n-1을 더하면 $29(1 + 2 + \cdots + (n-1)) = \frac{29n(n-1)}{2}$예요. 곧 T(n) = 29n(n-1)/2예요.
7. 확인: n = 4이면 i = 1, 2, 3에서 29 + 58 + 87 = 174이고, 29 × 4 × 3 / 2 = 174로 같아요.
8. 빅오: 네 겹 루프처럼 보여도 실제로는 $\frac{29}{2}n^2 - \frac{29}{2}n$이라서 최고차항의 차수만 남기면 $O(n^2)$예요.
9. 수업과의 연결: 0917 수업에서 power가 return 한 줄이라 $O(1)$처럼 보여도 안을 들여다봐야 $O(\log n)$이 보였듯, 루프 겹 수가 아니라 실제로 도는 횟수를 세야 해요. 계수와 꼬랑지를 떼는 건 factorial_iter의 $2n+1 = O(n)$과 같아요.

**정답:** T(n) = 29n(n-1)/2, O(n^2)
