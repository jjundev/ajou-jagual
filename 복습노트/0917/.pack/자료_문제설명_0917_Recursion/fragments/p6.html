문제를 내 말로 읽어요

순환 피보나치 fib(6)의 결과와 fib(3) 중복 호출 횟수·원인을 구하고, 반복 피보나치에서 이전 두 항을 갱신하는 대입문을 작성하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “피보나치의 중복 호출과 반복 상태”예요. $F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)$에서 순환 구현은 같은 하위 문제를 저장 없이 반복 호출하고, 반복 구현은 직전 두 항(last, current)과 임시 변수 tmp로 상태를 한 칸씩 밀어요.

종이에 적을 첫 줄

F(0) = 0, F(1) = 1을 적고 fib(6)의 두 자식을 fib(5), fib(4)로 나눠요.

왜 이렇게 푸는지 함께 따라가요

(a) 수열을 차례로 구하면 0, 1, 1, 2, 3, 5, 8이므로 fib(6) = 8이에요. 호출 트리에서 fib(6)은 fib(5)와 fib(4)를 부르고, fib(5) 하위(fib(4) + fib(3))에서 fib(3)이 2번, fib(4) 하위(fib(3) + fib(2))에서 fib(3)이 1번 불려 총 3회 호출돼요. 두 자식 호출의 하위 문제가 겹치는데 이미 구한 값을 저장하지 않기 때문에 중복 호출이 생겨요.

(b) 반복 구현에서는 current가 새 합으로 덮어써지기 전에 먼저 tmp = current;로 보관하고, current += last;로 다음 항 $F(i)$를 만든 뒤, last = tmp;로 이전 current를 last에 넣어요.

완성 답과 검산

(a) 호출 횟수를 $C(n)$이라 하면 fib(3) 호출 수는 $C(6 \to 3) = C(5 \to 3) + C(4 \to 3) = (1 + 1) + 1 = 3$회로 트리와 일치해요.

(b) last = 1, current = 2에 세 문장을 실행하면 tmp = 2, current = 3, last = 2가 되어 다음 두 항 (2, 3)으로 정확히 갱신돼요.

이 문제에서 조심할 점

값 F(3) = 2와 fib(3)의 호출 횟수 3회를 혼동하지 마세요.

설명을 닫고 다시 해 봐요

  1. fib(6)의 호출 트리를 그려 fib(3)이 몇 번 나타나는지 세어요.
  2. 순환 구현에서 중복 호출이 발생하는 이유를 한 문장으로 적어요.
  3. tmp, current, last의 갱신 대입 순서 3줄을 적고 값을 대입해 확인해요.

첫 줄

F(0) = 0, F(1) = 1을 적고 fib(6)의 두 자식을 fib(5), fib(4)로 나눠요.

떠올릴 개념·공식

순환 피보나치는 하위 호출이 겹쳐 중복 계산하며, 반복 구현은 tmp로 이전 current를 보존해요.

검산

(a) fib(6) = 8, fib(3) 호출 3회 (하위 호출 중복·미저장) (b) tmp = current; current += last; last = tmp;

조건·구분과 확인

  • 갱신 전 last=F(i-2)·current=F(i-1)이며 옛 current를 보존해 다음 두 항으로 옮겨요. F(3)의 값 2와 fib(3) 호출 3회를 구별해요.
