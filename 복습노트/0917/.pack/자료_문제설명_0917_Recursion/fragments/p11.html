문제를 내 말로 읽어요

양의 정수 n까지의 합을 순환으로 계산해요.

이 문제를 봤을 때 떠올릴 개념과 공식

“순환적인 프로그램”에서 S(n)=n+S(n−1), S(1)=1을 떠올려요. 큰 합을 마지막 항과 앞의 합으로 분해해요.

종이에 적을 첫 줄

if (n == 1) return 1;

왜 이렇게 푸는지 함께 따라가요

int sum(int n) {
    if (n == 1) return 1;
    return n + sum(n - 1);
}

완성 답과 검산

n=4에서 4+3+2+1=10이에요. 귀납적으로 sum(n−1)이 1..n−1의 합이면 현재 n을 더해 1..n의 합이 돼요. n은 양의 정수이며 결과가 int에 표현 가능하다고 가정해요.

이 문제에서 조심할 점

n≤0 입력에 이 바닥 조건을 그대로 쓰면 정상 종료가 안 돼요. 입력 범위를 적어요.

설명을 닫고 다시 해 봐요

  2. 바닥 1, n+sum(n−1)
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.
