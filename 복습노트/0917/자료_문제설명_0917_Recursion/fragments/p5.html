문제를 내 말로 읽어요

예시 10을 1010으로 출력하도록 dec_to_bin의 순환 본문을 채워요. 여기서는 양의 정수 입력을 기본으로 두어요.

이 문제를 봤을 때 떠올릴 개념과 공식

n=2q+r, r∈{0,1}에서 r=n%2는 맨 오른쪽 비트예요. 높은 자리 q=n/2를 먼저 출력해야 왼쪽부터 읽는 이진수(binary)가 돼요.

종이에 적을 첫 줄

if (n == 0) return;

왜 이렇게 푸는지 함께 따라가요

void dec_to_bin(int n) {
    if (n == 0) return;
    dec_to_bin(n / 2);
    printf("%d", n % 2);
}

완성 답과 검산

10→5→2→1→0으로 호출해요. 복귀할 때 1%2=1, 2%2=0, 5%2=1, 10%2=0을 출력하여 1010이에요. 1×8+0×4+1×2+0=10으로 역변환해 확인해요. 이 본문은 입력 0에 아무것도 출력하지 않으므로 0도 허용하려면 호출부에서 printf("0") 처리가 별도로 필요해요. 음수는 범위 밖이에요.

이 문제에서 조심할 점

printf를 순환 호출보다 먼저 쓰면 끝자리부터 출력해서 10에서 0101이 돼요.

설명을 닫고 다시 해 봐요

  1. if (n == 0) return;
  2. n/2 먼저 호출, 돌아와 n%2 출력
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.
