  2. 순환 호출하는 부분: 아니면 (j, i를 j로 나눈 나머지)로 다시 불러요. else return gcd( j, i%j );

  4. gcd(18, 12) → 18%12 = 6 → gcd(12, 6)
  5. gcd(12, 6) → 12%6 = 0 → gcd(6, 0)
  6. gcd(6, 0): j == 0이라 6을 돌려줘요. 화면에는 gcd:6이 찍혀요. 6은 48과 18의 최대 공약수가 맞아요.
  7. i < j로 넣어도 돼요. gcd(18, 48)은 18%48 = 18이라 gcd(48, 18)을 불러 두 수 자리가 바뀌고, 그다음은 위와 같아요.
  8. 완성한 함수예요. 
    int gcd(int i, int j){
    if ( j == 0 ) return i;
    else return gcd( j, i%j );
}
  9. 수업과의 연결: 0917 수업의 순환 알고리즘 두 조건 그대로예요. 순환을 멈추는 부분(j == 0)이 있고, 순환 호출은 나머지가 j보다 작아서 둘째 인자가 계속 줄어 0으로 수렴해요.

정답: if ( j == 0 ) return i; else return gcd( j, i%j ); (48 18 → gcd:6)

P5. 거듭제곱: 홀수 분기와 호출 크기

강의 예제 기반 자체 출제 S2 p10

아래 순환 함수 power(x, n)은 n >= 0일 때 지수를 절반으로 줄여 $x^n$을 구해요(중간 계산은 double 범위 안에 있다고 가정해요).

double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return /* 빈칸 */;
}
  1. (a) 홀수 분기의 /* 빈칸 */에 들어갈 반환식을 쓰고, power(2, 5)의 (x, n) 호출 순서와 각 단계 반환값을 구하세요.
  2. (b) 한 번에 x를 한 번씩 곱하는 slow_power(x, n)과 power(x, n)의 시간복잡도를 빅오 표기로 비교하고 이유를 설명하세요.
강의 예제 보기

S2 p10 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

double power(double x, int n)
{
    if(n==0) return 1;
    else if((n%2)==0) return power(x*x,n/2);
    else return x*power(x*x,(n-1)/2);
}
힌트 보기

홀수 $n = 2k + 1$이면 $x^n = x \cdot (x^2)^k$예요. 이 항등식에서 홀수 분기의 식이 나와요.

풀이 보기
  1. (a) 홀수 $n = 2k + 1$이면 $x^n = x \cdot (x^2)^{(n-1)/2}$이므로 홀수 분기 식은 x * power(x * x, (n - 1) / 2)예요. power(2, 5)는 (2, 5) → (4, 2) → (16, 1) → (256, 0) 순서로 호출되고, 역순으로 1 → 16 → 16 → 32를 반환해요.
  2. (b) power(x, n)은 매 호출마다 지수 n이 절반으로 줄어들어 호출 깊이가 $O(\log n)$인 반면, slow_power(x, n)은 지수를 1씩 줄이며 n번 반복 곱셈을 수행하므로 $O(n)$이에요($n \ge 1$).
  3. 수업과의 연결: 지수를 절반씩 줄이는 순환 거듭제곱과 단순 반복 거듭제곱의 시간복잡도($O(\log n)$ 대 $O(n)$) 비교와 이어져요.

정답: (a) 홀수 분기: x * power(x * x, (n - 1) / 2), 호출: (2, 5) → (4, 2) → (16, 1) → (256, 0), 반환: 1 → 16 → 16 → 32 (b) power는 지수가 절반씩 줄어 $O(\log n)$, slow_power는 n번 곱하므로 $O(n)$이다($n \ge 1$).

짝수 분기를 power(x, n / 2)로 쓰면 밑을 제곱하지 않아 원래 거듭제곱과 달라져요.

P6. 피보나치의 중복 호출과 반복 상태

강의 예제 기반 자체 출제 S2 p12

아래는 피보나치 수열을 순환으로 구현한 fib(n) 함수예요.

int fib(int n)
{
    if(n==0) return 0;
    if(n==1) return 1;
    return fib(n-1)+fib(n-2);
}
  1. (a) fib(6)의 반환값과 실행 중 fib(3)이 호출되는 횟수를 구하고, 순환 구현에서 같은 부분 문제가 중복 호출되는 이유를 설명하세요.
  2. (b) 반복 구현에서 last = F(i - 2), current = F(i - 1)인 상태를 다음 단계로 갱신할 때 임시 변수 tmp를 사용한 세 대입문을 순서대로 쓰세요.
강의 예제 보기

S2 p12 · 추가 근거 p13,14 · Software_2_Recursion.pdf. 강의 코드의 해당 연산을 발췌해 들여쓰기를 정리했습니다. 주변 선언·main·입출력을 생략한 발췌·번역은 완전한 실행 프로그램과 구별해요. 아래 질문·입력 조건은 자체 출제예요.

int fib(int n)
{
    if(n==0) return 0;
    if(n==1) return 1;
    return fib(n-1)+fib(n-2);
}
힌트 보기

F(0) = 0, F(1) = 1이고 두 앞 항을 더하므로 0, 1, 1, 2, 3, 5, 8을 얻어요.

풀이 보기
  1. (a) 피보나치 수열이 0, 1, 1, 2, 3, 5, 8이므로 fib(6) = 8이고, fib(6)의 두 자식 fib(5)와 fib(4) 쪽에서 fib(3)이 각각 2번, 1번 불려 총 3회 호출돼요. 두 자식 호출의 하위 호출 트리가 겹치는데 계산 결과를 저장하지 않고 매번 다시 계산하기 때문이에요.
  2. (b) 이전 current 값을 잃지 않도록 먼저 tmp = current;로 보관한 뒤, current += last;로 새 항을 구하고, last = tmp;로 직전 항을 옮겨요.
  3. 수업과의 연결: 순환 피보나치의 중복 계산 원인과 직전 두 항만 변수에 유지하는 반복 피보나치 구현을 비교한 내용과 이어져요.

정답: (a) fib(6) = 8, fib(3)은 3회 호출 (두 자식 호출의 하위 호출이 겹치고 계산 결과를 저장하지 않기 때문) (b) tmp = current; current += last; last = tmp;

값 F(3) = 2와 fib(3)의 호출 횟수 3회를 혼동하지 마세요.

"아래에는 함수 foo에 대한 코드가 있으며 이 함수를 호출(사용)하였을 때 무엇을 하는 함수인지에 대해서 답을 하시오. 함수 foo는 (   ) 함수이다. (2점)"
int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}
힌트 보기

foo(12, 18)을 손으로 따라가 보세요. 나머지가 0이 되는 순간 무엇을 돌려주는지 보면 돼요.

풀이 보기
  1. 끝나는 조건부터 봐요. x % y == 0이면, 즉 y가 x를 나누어떨어지게 하면 y를 돌려주고 끝나요. 이때 y는 x와 y를 둘 다 나누는 수 중 가장 커요.
  2. 아니면 foo(y, x % y)를 다시 불러요. x % y는 y보다 작아서 두 번째 값이 부를 때마다 줄어들어요. 그래서 언젠가 나누어떨어지는 순간이 와요.
  3. foo(12, 18): 12 % 18 = 12, 0이 아니에요 → foo(18, 12)
  4. foo(18, 12): 18 % 12 = 6 → foo(12, 6)
  5. foo(12, 6): 12 % 6 = 0 → 6을 돌려줘요.
  6. 돌아올 때는 받은 6을 그대로 위로 넘겨요. foo(12, 6) → foo(18, 12) → foo(12, 18) 모두 6이에요. 12와 18을 둘 다 나누는 가장 큰 수가 6이에요.
  7. 왜 답이 바뀌지 않을까요? $x = q \cdot y + r$ ($r$은 $x$를 $y$로 나눈 나머지)이면, $x$와 $y$를 둘 다 나누는 수는 $r$도 나누고, $y$와 $r$을 둘 다 나누는 수는 $x$도 나눠요. 그래서 $(x, y)$와 $(y, r)$의 공약수가 같아요.
  8. 수업과의 연결: 0914 수업(60:20–61:16)에서 말한 순환의 두 조건, "끝나는 조건"과 부를 때마다 "크기가 줄어든다"를 foo가 그대로 갖췄어요.
