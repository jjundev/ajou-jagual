# 이진 트리의 높이와 노드 수

노드 7개를 모두 사용하면 높이는 어떻게 달라질까요? 포화와 경사 사례를 전환해 노드를 한 번 셀 때마다 최대 레벨이 바뀌는 경우를 따라갑니다. 높이 3인 경사와 포화는 3개와 7개를 비교합니다. 루트만 있는 트리와 빈 트리는 경계 사례입니다.

- 강의 p5의 높이 3 대비, p6의 노드 7개 대비와 녹취 119–165행을 사용했습니다. 정리노트 §5–6의 루트 레벨 1 관례를 따릅니다.
- p5의 연산자와 문자 키는 p6과 같은 번호로 통일했습니다. 노드 번호는 높이 계산의 입력값으로 쓰이지 않습니다.
- 관찰용 C 방문 함수는 보충입니다. n과 h는 초기값 0인 정적 정수이며 노드는 미리 만들어 둡니다. report는 해설 단계에서 두 값을 확인하는 보충 호출입니다. 주소는 기호로 표시합니다.
