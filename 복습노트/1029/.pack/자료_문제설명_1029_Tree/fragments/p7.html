핵심 조건과 구할 것

노드 8개(A~H) 일반 트리 그림에서 트리 전체의 차수를 구해 보기 ①~④ 중 하나를 고르는 긍정형 단일 선택 객관식이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구·정의이 문제에 쓰는 이유
트리의 차수노드 차수(자식 수)의 최댓값(수업 보충 설명)트리의 차수는 루트 한 노드의 자식 수가 아니라, 모든 노드의 자식 수를 센 뒤 그중 가장 큰 값으로 정해요(정리노트).

종이에 쓰는 실제 첫 줄

A: 2 (B, C) | B: 3 (D, E, F) | C: 1 (G) | D: 1 (H) | E,F,G,H: 0

왜 이렇게 푸는지 함께 따라가요

노드자식 목록노드의 차수
AB, C2
BD, E, F3 (최댓값)
CG1
DH1
E, F, G, H없음0

모든 노드의 차수는 2, 3, 1, 1, 0, 0, 0, 0이고, 최댓값은 B의 3이에요. 보기마다 판정하면 다음과 같아요.

  • ① 3 (정답): 모든 노드 차수 중 최댓값(B의 자식 수)과 일치해요.
  • ② 4 (소거): 단말 노드 수(E, F, G, H 4개)를 차수로 착각한 값이에요.
  • ③ 6 (소거): 이 그림에서 자식이 6개인 노드는 없어요.
  • ④ 8 (소거): 전체 노드 수(A~H)예요.

완성 답과 10초 자가 검산

완성 답: ① 3 (교과서 자료에는 인쇄된 공식 답이 없어 정의에 따른 독립 계산으로 확인했어요).

차수 합 = 간선 수 검산: 모든 노드의 차수를 더하면 $2 + 3 + 1 + 1 + 0 + 0 + 0 + 0 = 7$이고, 노드 8개인 트리의 간선 수 $8 - 1 = 7$과 정확히 같아 자식 수를 빠뜨리거나 중복해서 세지 않았음을 바로 알 수 있어요.

실수하면 답이 이렇게 망가져요

  • 루트만 보고 차수를 적으면: 루트 A의 자식 수인 2를 트리의 차수로 착각해요(보기엔 없지만 주관식이면 2로 틀림).
  • 단말 노드 수·전체 노드 수와 섞으면: 단말 수 4(②)나 전체 노드 수 8(④)을 고르게 돼요.

해설을 가리고 스스로 확인해요

  1. 문제에서 “트리의 차수”를 보면 → 루트만 보지 않고 모든 노드의 자식 수를 적은 뒤 최댓값을 고르나요?
  2. 적어 둔 노드별 차수의 합이 노드 수 - 1(= 간선 수)과 같은지 바로 대조해 볼 수 있나요?

떠올릴 개념·공식

트리의 차수 = 모든 노드 차수(자식 수) 중 최댓값(수업 보충 설명).

첫 줄

A:2, B:3, C:1, D:1, E~H:0으로 모든 노드의 자식 수를 나열해요.

핵심 답

① 3 (B의 차수). ② 4는 단말 수, ④ 8은 전체 노드 수예요.

검산·고지

차수 합 $2+3+1+1 = 7 = 8 - 1$ 간선 수 일치. 교과서 공식 답은 없어요.
