핵심 조건과 구할 것

컴퓨터 디스크의 디렉토리(폴더) 구조를 표현하는 데 가장 알맞은 자료구조 이름을 빈칸에 쓰는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구·정의이 문제에 쓰는 이유
디렉토리 폴더 구조트리(tree): 부모–자식 계층 구조한 폴더 안에 여러 하위 폴더·파일이 갈라져 들어가고 각 항목은 바로 위 상위 폴더 하나에만 속하므로 계층형 트리와 정확히 맞아요(정리노트).

종이에 쓰는 실제 첫 줄

C:\ (루트) ─┬─ 문서 ─┬─ 과제.hwp (단말)
             │        └─ 필기.txt (단말)
             └─ 사진

왜 이렇게 푸는지 함께 따라가요

  • 계층·분기 구조: 최상위 C:\(루트) 아래에 여러 폴더가 갈래로 나뉘고, 더 이상 하위 항목이 없는 파일이 단말 노드(terminal node)에 대응해요.
  • 단일 부모: 각 폴더·파일(루트 제외)은 바로 위 상위 폴더 하나에 속하므로 부모–자식 관계가 성립해요.
  • 선형 구조 배제: 스택(stack)·큐(queue)·배열은 원소가 한 줄로 이어져 폴더 안의 다갈래 포함 관계를 직접 나타낼 수 없어요.

따라서 빈칸에 들어갈 자료구조는 트리예요.

완성 답과 10초 자가 검산

완성 답: 트리 (2017·2018 기출 답안과 일치).

조건 대조 검산: ① 최상위 드라이브 1개(루트), ② 루트 외 모든 폴더의 상위 폴더 1개(부모 유일), ③ 아래로 갈라지는 포함 관계(계층) — 트리의 정의 세 조건을 모두 충족해요.

실수하면 답이 이렇게 망가져요

“폴더를 들어갔다 나온다”는 탐색 동작에 끌려 스택을 적으면: 스택은 방문 경로를 임시로 기억할 때 쓰는 선형 도구일 뿐, 여러 갈래로 나뉜 폴더 구조 자체(문서 옆에 사진이 나란히 존재하는 분기)를 표현하지 못해요.

해설을 가리고 스스로 확인해요

  1. 문제에서 “폴더 구조·조직도·가계도”처럼 위아래 포함 관계가 보이면 → 가장 먼저 한 항목의 부모가 몇 개인지와 아래로 갈라지는지 확인하나요?
  2. 스택·큐(한 줄)와 트리(여러 갈래) 중 이 구조가 어느 쪽에 속하는지 1문장으로 구분할 수 있나요?

떠올릴 개념·공식

트리(tree): 루트 아래 부모–자식으로 갈라지는 계층형 자료구조.

첫 줄

C:\ → 문서 → 과제.hwp처럼 드라이브–폴더–파일 포함도를 그려 봐요.

핵심 답

트리. 드라이브=루트, 파일=단말이며 스택·큐는 분기 구조를 못 담아요.

검산

단일 루트·유일 부모·다갈래 계층 3조건이 트리 정의와 일치해요.
