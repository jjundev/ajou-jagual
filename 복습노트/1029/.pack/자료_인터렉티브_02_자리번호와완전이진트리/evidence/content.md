# 강의와 실행 의미 대조

- PDF 7쪽의 포화·완전 조건, 자리 번호 그림, 8쪽의 2i·2i+1 배치와 정리노트 §7–8 및 녹취 169–205행을 대조했다. 예제 입력은 학습용이다. 두 5노드 트리에는 모든 실재 노드의 부모가 존재한다.
- 1행은 처음 i를 1로 초기화하고 반복부터 i를 증가시킨 뒤 limit 이하인지 검사한다. 2행은 i의 배열 원소에서 포인터 값을 읽고 NULL 여부를 확인한다. 3행은 처음 발견한 빈자리에서만 gap에 i를 쓰며, 4행은 역참조나 노드 수 증가 없이 다음 번호로 진행한다.
- 6행은 NULL이 아닌 슬롯으로부터 key를 읽어 번호를 출력한다. 7행은 노드 수 n을 증가시키고 8행은 최종으로 관찰한 점유 인덱스를 갱신한다. 5·9행은 중괄호이며 배열 원소나 변수에 별도 접근을 만들지 않는다.
- 10행은 1부터 마지막 점유 자리까지의 개수와 실제 점유 수를 비교한다. 1, 2, 3, 4, 6의 경우 자리 5가 빈 상태에서 6번이 관찰되어 n=5와 last=6이 다르다. 1–5의 경우 6, 7번이 비어 있으나 5번까지는 연속이다.
- 11행은 n이 양수일 때만 n과 마지막 레벨 끝 번호를 비교한다. 포화인 1–7은 완전 조건도 만족하고, 다음 노드는 4번의 왼쪽 자리 8이다. 빈 사례의 용어 관례와 배열의 검사 범위를 brief에 적었다.
