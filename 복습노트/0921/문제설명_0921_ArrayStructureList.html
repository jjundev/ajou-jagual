"아래에는 함수 foo에 대한 코드가 있으며 이 함수를 호출(사용)하였을 때 무엇을 하는 함수인지에 대해서 답을 하시오.
함수 foo는 ( ) 함수이다. (2점)"

int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}

문제를 내 말로 읽어요

코드가 어떤 문제를 푸는지 이름이 아니라 인자 변화로 판단해요. 입력은 양의 정수 x,y로 두어요.

이 문제를 봤을 때 떠올릴 개념과 공식

x%y라는 “나머지”와 (y,x%y) 호출은 Euclidean algorithm의 단서예요. x=qy+r일 때 x,y의 공약수 집합은 y,r의 공약수 집합과 같아요. y>0일 때 0≤r<y예요.

종이에 적을 첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

왜 이렇게 푸는지 함께 따라가요

(48,18)→(18,12)→(12,6)에서 나머지가 0이 되어 6을 반환해요. 공약수 d가 x,y를 나누면 x−qy=r도 나누고, 반대로 y,r을 나누면 qy+r=x도 나눠요. 그래서 매 호출의 최대공약수가 같아요. 나머지가 양의 이전 y보다 작아 종료해요.

완성 답과 검산

48의 약수와 18의 약수 중 공통 최대는 6이에요. 순서를 바꾼 foo(18,48)도 (48,18)로 이어져 6이에요. 따라서 답은 최대공약수 GCD예요.

이 문제에서 조심할 점

원 함수는 y=0에서 %0이므로 정의되지 않아요. 양의 입력 조건 없이 모든 정수에 안전하다고 쓰지 않아요.

설명을 닫고 다시 해 봐요

  1. foo(48,18)에서 나머지 12를 첫 줄에 적어요.
  2. 나머지로 줄이는 유클리드 호제법
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

떠올릴 개념·공식

나머지로 줄이는 유클리드 호제법

이 문제를 봤을 때 떠올릴 개념과 공식

“순환 함수”와 “최대공약수”에서 gcd(i,j)=gcd(j,i%j)를 떠올려요. %를 계산하기 전에 j=0을 검사해야 나눗셈 오류 없이 종료해요.

종이에 적을 첫 줄

if (j == 0) return i;

왜 이렇게 푸는지 함께 따라가요

int gcd(int i, int j) {
    if (j == 0) return i;
    return gcd(j, i % j);
}

완성 답과 검산

gcd(48,18)→(18,12)→(12,6)→(6,0)→6이에요. 반환값은 추가 계산 없이 위 호출로 전달돼요. 공약수 집합 보존과 두 번째 인자의 감소가 정확성과 종료를 증명해요. 입력 변환 성공과 양의 int 범위를 가정해요.

이 문제에서 조심할 점

if 앞에서 i%j를 계산하면 마지막 호출에서 %0을 하게 돼요. “0이 모든 수를 나눈다”가 아니라 모든 양의 수가 0을 나눈다는 뜻이에요.

설명을 닫고 다시 해 봐요

  1. if (j == 0) return i;
  2. j=0 종료, 아니면 gcd(j,i%j)
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄

함수가 수행 도중에 자기 자신을 다시 호출하여 문제를 해결하는 기법을 ( ) 이라고 해요. 빈칸을 채워 보세요.

문제를 내 말로 읽어요

함수가 자기 자신을 호출한다는 설명에 맞는 이름을 쓰는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

“자기 자신을 다시 호출”은 recursion, 수업 용어로 순환(재귀)이에요. 일반 반복 iteration은 루프를 돌지만 별도의 자기 호출을 만들지 않아요.

종이에 적을 첫 줄

빈칸에 순환(recursion)을 적어요.

왜 이렇게 푸는지 함께 따라가요

답은 순환, 또는 동의어 재귀예요. 예를 들어 factorial(3)이 factorial(2)를 호출하면 작은 문제의 답을 받아 현재 답을 만들어요. 올바른 순환은 즉시 답을 주는 바닥 조건과 그 조건으로 다가가는 감소를 함께 가져요.

완성 답과 검산

반복문만 있는 sum은 자기 호출이 없어요. 반대로 함수 안의 자기 호출은 루프가 없어도 순환이에요. 이 차이로 용어를 확인해요.

이 문제에서 조심할 점

함수 이름을 두 번 썼다고 항상 실행 중 자기 호출은 아니에요. 실제 호출 관계를 보아요.

설명을 닫고 다시 해 봐요

  1. 빈칸에 순환(recursion)을 적어요.
  2. 자기 호출 = 순환/재귀
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄

빈칸에 순환(recursion)을 적어요.

떠올릴 개념·공식

자기 호출 = 순환/재귀

}

주어진 조건

C언어의 typedef을 이용하여 complex라고 하는 새로운 자료형을 정의하라. complex 자료형은 구조체로서 float형인 real 변수와 역시 float형인 imaginary 변수를 갖는다. complex 자료형으로 변수 c1과 c2를 선언하여보라.

기출 원문

C언어의 typedef을 이용하여 complex라고 하는 새로운 자료형을 정의하라. complex 자료형은 구조체로서 float형인 real 변수와 역시 float형인 imaginary 변수를 갖는다. complex 자료형으로 변수 c1과 c2를 선언하여보라.

문제를 내 말로 읽어요

실수부와 허수부를 갖는 타입 complex를 만들고 두 변수를 선언해요.

이 문제를 봤을 때 떠올릴 개념과 공식

typedef는 새로운 표현을 발명하는 것이 아니라 기존 타입에 이름 alias를 붙여요. real과 imaginary는 float, c1과 c2는 이 두 필드를 갖는 객체예요.

종이에 적을 첫 줄

typedef struct { 로 시작해요.

왜 이렇게 푸는지 함께 따라가요

typedef struct {
    float real;
    float imaginary;
} complex;
complex c1, c2;

완성 답과 검산

complex c1,c2는 각각 두 float 멤버를 가진 변수를 만들어요. C 컴파일에서 c1.real=1.0f, c2.imaginary=2.0f 접근이 가능해요. typedef 선언만으로는 c1,c2 객체가 생기지 않으므로 별도 선언을 확인해요.

이 문제에서 조심할 점

complex를 구조체 태그와 변수 이름으로 혼동하지 않아요.

설명을 닫고 다시 해 봐요

  1. typedef struct { 로 시작해요.
  2. typedef 별명 뒤 변수 c1,c2 선언
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄
