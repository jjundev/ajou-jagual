문제를 내 말로 읽어요

two[0]부터 two[9]까지 2⁰..2⁹를 저장하고 출력해요.

이 문제를 봤을 때 떠올릴 개념과 공식

“이전 값의 두 배”라는 점화식 two[i]=2×two[i−1]로 거듭제곱 power를 만들 수 있어요. C의 ^는 거듭제곱이 아니라 XOR이므로 쓰지 않아요.

종이에 적을 첫 줄

int two[10];
two[0] = 1;

왜 이렇게 푸는지 함께 따라가요

#include <stdio.h>
int main(void) {
    int two[10];
    two[0] = 1;
    for (int i=1; i<10; ++i) two[i] = 2*two[i-1];
    for (int i=0; i<10; ++i) printf("%d%s", two[i], i==9?"\n":" ");
    return 0;
}

완성 답과 검산

출력은 1 2 4 8 16 32 64 128 256 512예요. 귀납적으로 첫 원소 2⁰이고 직전 2ⁱ⁻¹의 두 배가 2ⁱ예요. 독립 정수 거듭제곱과 C 출력 모두 대조해요.

이 문제에서 조심할 점

i=0부터 직전 원소를 읽으면 two[−1]로 배열 범위를 벗어나요.

설명을 닫고 다시 해 봐요

  1. int two[10]; two[0] = 1;
  2. two[0]=1, 이전 원소×2
