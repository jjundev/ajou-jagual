문제를 내 말로 읽어요

이름·나이·월급을 한 사람의 구조체로 묶어요.

이 문제를 봤을 때 떠올릴 개념과 공식

서로 다른 타입 필드는 structure의 단서예요. name은 문자 배열 char[], age는 int, salary는 문제에서 지정한 float예요.

종이에 적을 첫 줄

struct person { 를 먼저 적어요.

왜 이렇게 푸는지 함께 따라가요

struct person {
    char name[100];
    int age;
    float salary;
};

완성 답과 검산

세 필드의 타입과 이름을 요구사항과 하나씩 대조해요. name의 100칸은 설계 선택이며 최대 99바이트와 종료 널을 보관해요. 문제는 길이를 지정하지 않아 다른 적절한 길이도 가능해요. C 컴파일로 멤버 접근과 선언을 확인해요.

이 문제에서 조심할 점

서로 다른 필드를 int 배열 하나로 대신하지 않아요. 구조체 선언 끝의 세미콜론도 필요해요.

설명을 닫고 다시 해 봐요

  1. struct person { 를 먼저 적어요.
  2. char name[], int age, float salary
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

첫 줄

검산

본문의 조건과 독립 추적을 함께 확인해요.

  • name[100]은 길이가 지정되지 않은 문제의 설계 선택으로 최대 99바이트와 종료 널을 담아요. 구조체 선언 끝에는 세미콜론이 필요해요.
