문제를 내 말로 읽어요

원판 3개를 막대 A에서 C로 옮기는 hanoi_tower(3, 'A', 'B', 'C')의 이동 순서 7번을 추적하고, 순환 호출에서 막대 역할이 바뀌는 이유와 최소 이동 횟수 점화식을 구하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “하노이 코드의 매개변수 역할”이에요. 가장 큰 원판 n을 from에서 to로 옮기려면 위의 n-1개를 먼저 보조 막대 tmp로 옮겨야 하므로, 첫 순환 호출의 도착 막대는 tmp가 되고 최소 이동 횟수는 T(n) = 2T(n-1) + 1 = 2^n - 1을 따라요.

종이에 적을 첫 줄

가장 큰 원판 3을 A→C로 옮기기 전후로 hanoi_tower(2, 'A', 'C', 'B')와 hanoi_tower(2, 'B', 'A', 'C')를 적어요.

왜 이렇게 푸는지 함께 따라가요

(a) 첫 호출 hanoi_tower(2, 'A', 'C', 'B')가 위 2개 원판을 B로 옮기며 1:A→C, 2:A→B, 1:C→B를 출력해요. 이어서 원판 3을 옮기는 3:A→C를 출력하고, 두 번째 호출 hanoi_tower(2, 'B', 'A', 'C')가 1:B→A, 2:B→C, 1:A→C를 출력해요.

(b) 가장 큰 원판을 to로 옮기기 전에 위 n-1개를 보조 막대 tmp에 모아 두어야 하므로 첫 순환 호출에서는 tmp가 도착 막대, to가 보조 막대 역할을 맡아요. 위 n-1개 이동, 가장 큰 원판 1회, 다시 위 n-1개 이동이 필요하므로 T(1) = 1, T(n) = 2T(n-1) + 1(일반식 $2^n - 1$)이며 T(3) = 7이에요.

완성 답과 검산

(a) 총 출력 줄 수는 3 + 1 + 3 = 7줄이고, 가운데 4번째 이동이 3:A→C이며 원판 1이 홀수 번째(1, 3, 5, 7번째)마다 이동하므로 규칙과 일치해요.

(b) 점화식에 대입하면 T(1) = 1, T(2) = 2(1) + 1 = 3, T(3) = 2(3) + 1 = 7로 일반식 $2^3 - 1 = 7$과 일치해요.

이 문제에서 조심할 점

from, tmp, to는 고정된 막대 이름이 아니라 현재 호출에서 맡은 역할이에요.

설명을 닫고 다시 해 봐요

  1. n = 3 호출을 n = 2 앞뒤 호출과 원판 3 이동으로 나누어 7줄을 적어요.
  2. 첫 순환 호출에서 왜 to와 tmp 자리가 바뀌는지 설명해요.
  3. 점화식 T(n) = 2T(n-1) + 1로 T(3) = 7을 검산해요.

첫 줄

맨 큰 원판 3을 A→C로 옮기려면 위 2개를 A→B로 먼저 옮겨요.

떠올릴 개념·공식

첫 순환 호출은 도착 막대가 tmp이고, 이동 횟수는 T(n) = 2T(n-1) + 1 = 2^n - 1이에요.

검산

(a) 1:A→C, 2:A→B, 1:C→B, 3:A→C, 1:B→A, 2:B→C, 1:A→C (b) T(1)=1, T(n)=2T(n-1)+1, T(3)=7.

조건·구분과 확인

  • n≥1에서 from·tmp·to는 고정된 막대 이름이 아니라 현재 호출의 출발·임시·도착 역할이에요.
