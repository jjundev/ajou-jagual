문제를 내 말로 읽어요

person 구조체에서 변수 간 대입 b = a;가 배열 멤버까지 복사하는지, 복사 뒤 한쪽 멤버만 수정할 때 다른 쪽이 영향을 받는지, 그리고 구조체 비교 연산을 어떻게 써야 하는지 묻는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘구조체 대입’은 모든 멤버의 값 복사이고, ‘나이가 더 많음’은 비교할 특정 멤버의 선택을 뜻해요. C는 같은 구조체 타입의 통째 대입 b = a;를 지원하지만 구조체 전체에 대한 비교 연산자(>, ==)는 정의하지 않아요.

종이에 쓰는 첫 줄

b = a: 같은 타입의 구조체 값 복사(내부 배열 멤버 포함), a > b: 구조체 전체 비교 불가라고 적어요.

왜 이렇게 푸는지 함께 따라가요

(a) 같은 person 타입끼리의 b = a; 대입은 가능하며, 구조체 안의 문자 배열 멤버 name까지 모든 멤버 값이 별도 객체 b로 복사돼요. 두 객체는 서로 다른 메모리 공간을 쓰므로 대입 뒤 b.age만 바꿔도 a.age는 원래 값 그대로 유지돼요.

(b) 구조체 전체를 비교하는 if (a > b)는 C에서 허용되지 않아 컴파일 오류가 나요. 나이가 더 많은지 비교하려면 정수 멤버를 직접 지정해 a.age > b.age로 비교해야 해요.

완성 답과 검산

(a) 예를 들어 a.age = 20일 때 b = a; 뒤 b.age = 21;을 실행하면 a.age는 20, b.age는 21로 서로 독립임을 확인할 수 있어요.

(b) a.age와 b.age는 모두 int 타입이므로 a.age > b.age는 int끼리의 유효한 관계 연산식이 돼요.

이 문제에서 조심할 점

구조체 대입 가능을 구조체 > 비교 가능으로 확대하지 않아요. 배열 멤버가 있다는 이유로 구조체 대입 전체가 금지된다고 하지 않아요.

설명을 닫고 다시 해 봐요

  1. b = a; 실행 시 name 배열 복사와 b.age 수정의 독립성을 적어요.
  2. a > b가 왜 불가능한지와 올바른 나이 비교 식 a.age > b.age를 적어요.

떠올릴 개념·공식

C는 같은 구조체 타입의 값 대입(b = a)을 허용하지만 구조체 전체 비교(a > b)는 허용하지 않아요.

첫 줄

b = a: 같은 타입의 구조체 값 복사라고 적어요.

핵심 답

(a) b=a 가능, name 배열도 복사되며 b.age 수정 시 a.age는 유지됨 (b) a>b 불가, a.age>b.age로 비교.
