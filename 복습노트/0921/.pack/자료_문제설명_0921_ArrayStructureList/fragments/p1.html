문제를 내 말로 읽어요

10행 20열의 int 배열 전체 바이트 수를 구해요. int=4바이트는 문제에서 정한 값이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

“배열이 차지하는 공간”은 원소 개수×원소 한 개의 크기예요. 배열은 같은 타입 원소를 연속 배치하므로 별도 행 포인터 10개가 붙는 것이 아니에요.

종이에 적을 첫 줄

원소 수=10×20=200을 적어요.

왜 이렇게 푸는지 함께 따라가요

200×4=800바이트, 정답 (4)예요. 각 행이 20×4=80바이트이고 10행을 합쳐도 800이에요.

완성 답과 검산

두 방식 200원소×4와 10행×80이 같아요. 실제 C 검산에서도 sizeof(int)==4인 환경의 sizeof a가 800이에요.

이 문제에서 조심할 점

10+20으로 원소 수를 세거나 int**의 저장 크기와 섞지 않아요.

설명을 닫고 다시 해 봐요

  1. 원소 수=10×20=200을 적어요.
  2. 행×열×int 크기 = 800
  3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.
