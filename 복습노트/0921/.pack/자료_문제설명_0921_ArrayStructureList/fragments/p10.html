문제를 내 말로 읽어요

A=8x^3+7x+1, B=10x^3+3x^2+1을 강의의 두 저장 방식으로 더하세요. 모든 차수 배열의 내림차순 결과 계수를 쓰고 S3 p8에서 높은 차수 쪽만 읽을 때 왜 다른 쪽 인덱스는 그대로인지 설명하세요. 0이 아닌 (계수,차수) 쌍을 합치는 S3 p11의 >,=,< 분기에서 어느 입력 인덱스를 전진시키는지와 출력 쌍을 쓰세요. 한쪽이 먼저 끝날 때, 같은 차수의 계수 합이 0일 때 처리와 두 방식의 시간복잡도를 차수 D 및 항 수 m,n으로 설명하세요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘정렬된 차수 두 묶음’은 병합(merge)의 단서예요. 차수가 큰 항부터 확정하면 뒤에서 같은 차수보다 큰 항이 새로 나타나지 않아요. 같을 때 양쪽을 소비하고 나머지 분기에서는 한쪽만 소비해요. 입력 포인터가 후퇴하지 않아 총 전진 수로 시간복잡도를 셀 수 있어요.

종이에 쓰는 첫 줄

A의 계수 [8,0,7,1], B의 계수 [10,3,0,1]이라고 적어요.

왜 이렇게 푸는지 함께 따라가요

계수 배열은 같은 차수끼리 맞추므로 [8,0,7,1]+[10,3,0,1]을 써요.

각 자리 합으로 [18,3,7,2]를 얻어요. 차수가 높은 입력만 처리했다면 다른 쪽 항은 아직 기다려요.

희소 방식은 현재 차수를 비교해 큰 쪽을 복사하고, 같으면 계수를 합쳐 양쪽을 전진해요.

차수3은 18, 차수2는 B의3, 차수1은 A의7, 차수0은 합2를 저장해요.

while이 끝나면 남은 입력을 복사해 누락을 막고, 같은 차수 합이0이면 저장만 건너뛰되 양쪽 입력은 전진해요.

각 입력 위치가 한 번씩 전진하므로 길이에 비례해요. 배열 길이는 D+1, 희소 입력 길이는 m+n이에요.

결과는 18x^3+3x^2+7x+2, 내림차순 계수 [18,3,7,2], 쌍 [(18,3),(3,2),(7,1),(2,0)]이에요. >에서는 A만, =에서는 양쪽, <에서는 B만 전진해요. 높은 차수만 출력한 경우 다른 입력의 현재 항은 아직 처리하지 않았기 때문이에요. 한쪽 종료 뒤 다른 쪽 남은 항을 복사해요. 희소 방식은 합이 0인 항을 저장하지 않아요. 모든 차수 배열은 O(D+1), 희소 병합은 O(m+n)이에요.

완성 답과 검산

결과는 18x^3+3x^2+7x+2, 내림차순 계수 [18,3,7,2], 쌍 [(18,3),(3,2),(7,1),(2,0)]이에요. >에서는 A만, =에서는 양쪽, <에서는 B만 전진해요. 높은 차수만 출력한 경우 다른 입력의 현재 항은 아직 처리하지 않았기 때문이에요. 한쪽 종료 뒤 다른 쪽 남은 항을 복사해요. 희소 방식은 합이 0인 항을 저장하지 않아요. 모든 차수 배열은 O(D+1), 희소 병합은 O(m+n)이에요.

x=1을 대입하면 A=16, B=14, 결과=30으로 일치해요. 계수별 직접 덧셈이 희소 병합 출력과도 같아요. 별도 경계로 A=x, B=-x이면 출력 항이 없고, A=x^2+x+1, B=x^2이면 마지막 x와1을 나머지 복사해야 해요.

이 문제에서 조심할 점

코드 줄 수가 길다고 더 높은 차수의 시간복잡도라고 판단하지 않아요. 두 표현의 D와 m,n은 서로 다른 입력 크기예요.

설명을 닫고 다시 해 봐요

  1. 주어진 조건과 첫 상태를 적어요.
  2. 핵심 규칙을 떠올려 답을 다시 완성해요.
  3. 경계 조건과 보존되는 상태를 확인해요.
