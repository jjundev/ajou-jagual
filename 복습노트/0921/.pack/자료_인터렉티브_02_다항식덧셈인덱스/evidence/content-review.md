## 단계별 C 의미 (note 사례, trace-walkthrough.txt)
1. 초기 상태: A={5,{10,0,0,0,6,3}}, B={3,{10,3,0,1,0,0}}(초기값 목록에 없는 원소 0), C·스칼라는 미초기화.
2. 12–13줄: 위치 0, degree_a=5, degree_b=3(A.degree/B.degree 읽은 뒤 복사). 14줄: 5 > 3 → C.degree=5.
3. while 조건: Apos, A.degree, Bpos, B.degree를 읽는다. && 왼쪽이 거짓이면 오른쪽을 읽지 않는다(마지막 검사에서 Bpos 읽기 없음).
4. 반복 1–2(5>3, 4>3): A 계수 10, 0을 C[0], C[1]에 복사, Cpos·Apos 증가, degree_a 감소.
5. 반복 3–6(3==3 … 0==0): else if에서 degree_a, degree_b를 다시 읽고(조건식 재평가), A+B를 C[2..5]에 → 10,3,6,4. 두 카운터 함께 감소, 마지막에 -1.
6. Apos=6 > 5로 종료. 후처리 두 while 모두 첫 검사에서 거짓(한 번도 돌지 않음). 최종 C={5,{10,0,10,3,6,4}} = 정리노트 결과 10x⁵+10x³+3x²+6x+4.
- `C.coef[Cpos++]= A.coef[Apos++]`에서 ++ 증가와 배열 쓰기의 상대 순서는 C가 정하지 않음을 설명에 명시. 인덱스는 증가 전 값으로 확정하므로 결과는 하나다.

## 다른 사례
- same: {3,{18,3,7,2}} = 정리노트 18x³+3x²+7x+2. C.coef[4], [5]는 미초기화로 남음(차수 범위 밖).
- bigb: else 분기(B항 > A항) 2회 후 같아짐 → {3,{10,3,6,4}}.
- cancel: 3 + (-3) = 0을 C.coef[0]에 저장, C.degree는 2로 남음 → 방법 #1은 0도 자리를 차지하고 이 코드는 차수를 줄이지 않는다고 설명(정리노트의 방법 #2 `if( tempcoef )`와 대비 가능).
- constant(k=-2): 차수 0 경계, 반복 1번, Apos=Bpos=1에서 종료. boundary(k=99): 7 + 99 = 106.
- zero-const(note, k=-3): 3 + (-3) = 0을 C.coef[5]에 저장(방법 #1은 0도 자리 차지), 결과 10x⁵+10x³+3x²+6x.
- k 입력: 모든 사례에서 B의 마지막 초기값만 {{k}}로 바뀐다(소스 템플릿 치환, 줄 수 불변). 독립 검산은 k ∈ {-99,-3,-1,0,1,7,12,13,14,63,64,99} × 5사례 격자.
- 범위 밖 칸 읽기/쓰기 없음: 모든 접근 인덱스 ≤ degree.
