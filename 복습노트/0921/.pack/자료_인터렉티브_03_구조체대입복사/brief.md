# 구조체 대입 b = a: 필드마다 값 복사

0921 수업 구조체의 대입과 비교(Software_3 p17, 정리노트 `s4-struct-assign`)와 자체 참조 구조체(p18, `s4-self-ref`)를 필드 저장 공간으로 확인한다.

## 핵심 질문
같은 타입 구조체의 대입 b = a는 무엇을 복사하고, 복사 후 한쪽을 바꾸면 다른 쪽도 바뀌는가? 포인터 필드가 있으면?

## 학습자에게 남길 것
같은 타입 구조체의 대입은 모든 필드를 하나씩 값으로 복사한다. 복사가 끝나면 두 변수는 따로 바뀐다. 포인터 필드는 주소 값만 복사하므로 대상은 함께 쓴다. 구조체 전체 비교(a > b)는 없고 a.age > b.age처럼 필드를 골라 비교한다.

## 입력과 사례
- 입력: 첫 값(a.age · n1.data, -999..999), 둘째 값(a.height · n2.data), 예제(b = a 강의 / a 미초기화 강의 main / 포인터 필드 보충)
- preset: a = {20, 170}, 두 필드 같은 값, 경계 -999, 경계 999, 강의 main처럼 a 미초기화(첫 필드 읽기에서 중단), 포인터 필드 link 복사(n1.link와 c.link가 같은 n2 → 별칭)
- 주소는 기호. 구조체 첫 필드 주소는 구조체 주소와 같다고 표시(&a.age (= &a)).

## 출처와 보충
- 강의 코드: Software_3 p17 person·main, p18 ListNode(sha256 `765ff7fae303bdcf…`). source.c에 원문을 주석으로 보존.
- 단순화: 화면은 정수·포인터 값만 그리므로 name[10] 생략, height를 int(cm)로, ListNode data를 int로. 초기값·a.age 변경·필드 비교(정리노트 보충)·link 예제 main은 보충.
- uninit: 강의 main 그대로 a를 초기화하지 않고 b = a. 주소를 쓰지 않은 미초기화 자동 변수 읽기는 정의되지 않은 동작이므로 첫 필드 읽기에서 중단하고, 설명에서 "문법상 대입이 가능하다"는 강의 요지와 구분했다.
- 독립 검산: `compiler_unavailable`(fact와 같은 환경). Python 표로 모든 쓰기와 별칭 최종 상태를 재계산.
