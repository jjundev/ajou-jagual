### P6. 하노이 코드의 매개변수 역할

**강의 예제 기반 자체 출제** S2 p19

n≥1이에요. hanoi_tower(3,'A','B','C')의 이동을 원판 번호와 출발·도착 막대로 쓰세요. 첫 번째 순환 호출에서 to와 tmp의 위치가 바뀌는 이유와 최소 이동 횟수의 점화식도 설명하세요.

```c
void hanoi_tower(int n, char from, char tmp, char to)
{
    if(n==1) printf("원판1을%c에서%c으로옮긴다.\n",from,to);
    else {
        hanoi_tower(n-1,from,to,tmp);
        printf("원판%d을%c에서%c으로옮긴다.\n",n,from,to);
        hanoi_tower(n-1,tmp,from,to);
    }
}
```

현재 구조체 정의 안에서는 struct ListNode라는 태그로 자신을 지칭할 수 있어요. typedef 이름은 정의 끝에서 만들어져요.

</details>

<details><summary>풀이 보기</summary>

1. 현재 구조체 정의 안에서는 struct ListNode라는 태그로 자신을 지칭할 수 있어요. typedef 이름은 정의 끝에서 만들어져요.
2. 포인터는 다른 노드의 주소만 보관하므로 크기가 유한해요. 노드 자체를 값으로 포함하는 선언은 불가능해요.
3. p가 유효한 노드를 가리킬 때 -&gt;로 필드를 읽어요. p-&gt;link는 다음 노드의 주소이고 \*(p-&gt;link)는 그 노드예요.

**정답:** struct ListNode \*link;. 같은 구조체를 값으로 포함하면 자신의 크기를 무한히 포함해야 하므로 완성할 수 없다. 데이터 p-&gt;data, 다음 노드 p-&gt;link.

포인터 선언만으로 다음 노드가 자동 할당되지는 않아요.

</details>

### P9. 배열 ADT와 행 우선 주소 계산

**강의 예제 기반 자체 출제** S3 p3 · 추가 근거 p4,5

배열 ADT의 객체를 설명하고 create(6), store(A,2,7), retrieve(A,2)가 하는 일을 쓰세요. 이어 int A\[3\]\[4\]의 시작 주소를 1000, int 크기를 4바이트로 가정할 때 A\[2\]\[1\]의 주소를 구하고 인덱스 범위가 유효한지 확인하세요.

<details><summary>강의 예제 보기</summary>

S3 p3 · 추가 근거 p4,5 · Software_3_ArrayStructureList.pdf. 강의의 개념·그림·코드 연산을 바탕으로 조건과 질문을 새로 작성한 자체 출제예요. 제시 코드는 있는 경우 학습 확인용 자체 코드이며 강의 원문 발췌가 아니에요. 질문·입력 조건·검산은 자체 작성했어요.

</details>

<details><summary>힌트 보기</summary>

A\[2\]\[1\] 앞의 원소 수 = 2×4+1이라고 적어요.

</details>

<details><summary>풀이 보기</summary>

1. ADT는 가능한 객체와 연산의 의미를 먼저 정하고 물리 주소 계산과 구별해요.
2. store 뒤 같은 인덱스 retrieve 결과는 저장한 7이에요.
3. 앞선 두 행에 8개, 현재 행 앞에 1개가 있으므로 총 9개 원소를 건너뛰어요.
4. 9개에 원소 크기 4바이트를 곱해 시작 주소에 더해요.

**정답:** 객체는 인덱스와 요소 쌍의 집합이에요. create(6)은 6개 요소의 배열 생성, store는 2번 위치에 7 저장, retrieve는 그 위치의 7 반환이에요. C 행 우선 배열 A\[2\]\[1\]의 앞에는 2×4+1=9개 원소가 있어 주소는 1000+9×4=1036이에요. 0≤2&lt;3, 0≤1&lt;4로 유효해요.

행 번호에 행 수 3을 곱하지 않아요. 한 행의 열 수 4를 곱해요. 범위를 벗어난 인덱스에 주소 공식을 적용해 유효한 접근이라고 하지 않아요.

</details>

### P10. 두 표현의 다항식 덧셈과 남은 항 처리

**강의 예제 기반 자체 출제** S3 p11 · 추가 근거 p7,8,9,10

A=8x^3+7x+1, B=10x^3+3x^2+1을 강의의 두 저장 방식으로 더하세요. 모든 차수 배열의 내림차순 결과 계수를 쓰고 S3 p8에서 높은 차수 쪽만 읽을 때 왜 다른 쪽 인덱스는 그대로인지 설명하세요. 0이 아닌 (계수,차수) 쌍을 합치는 S3 p11의 &gt;,=,&lt; 분기에서 어느 입력 인덱스를 전진시키는지와 출력 쌍을 쓰세요. 한쪽이 먼저 끝날 때, 같은 차수의 계수 합이 0일 때 처리와 두 방식의 시간복잡도를 차수 D 및 항 수 m,n으로 설명하세요.

<details><summary>강의 예제 보기</summary>

S3 p11 · 추가 근거 p7,8,9,10 · Software_3_ArrayStructureList.pdf. 강의의 개념·그림·코드 연산을 바탕으로 조건과 질문을 새로 작성한 자체 출제예요. 제시 코드는 있는 경우 학습 확인용 자체 코드이며 강의 원문 발췌가 아니에요. 질문·입력 조건·검산은 자체 작성했어요.

</details>

<details><summary>힌트 보기</summary>

A의 계수 \[8,0,7,1\], B의 계수 \[10,3,0,1\]이라고 적어요.

</details>

<details><summary>풀이 보기</summary>

1. 계수 배열은 같은 차수끼리 맞추므로 \[8,0,7,1\]+\[10,3,0,1\]을 써요.
2. 각 자리 합으로 \[18,3,7,2\]를 얻어요. 차수가 높은 입력만 처리했다면 다른 쪽 항은 아직 기다려요.
3. 희소 방식은 현재 차수를 비교해 큰 쪽을 복사하고, 같으면 계수를 합쳐 양쪽을 전진해요.
4. 차수3은 18, 차수2는 B의3, 차수1은 A의7, 차수0은 합2를 저장해요.
5. while이 끝나면 남은 입력을 복사해 누락을 막고, 같은 차수 합이0이면 저장만 건너뛰되 양쪽 입력은 전진해요.
6. 각 입력 위치가 한 번씩 전진하므로 길이에 비례해요. 배열 길이는 D+1, 희소 입력 길이는 m+n이에요.

**정답:** 결과는 18x^3+3x^2+7x+2, 내림차순 계수 \[18,3,7,2\], 쌍 \[(18,3),(3,2),(7,1),(2,0)\]이에요. &gt;에서는 A만, =에서는 양쪽, &lt;에서는 B만 전진해요. 높은 차수만 출력한 경우 다른 입력의 현재 항은 아직 처리하지 않았기 때문이에요. 한쪽 종료 뒤 다른 쪽 남은 항을 복사해요. 희소 방식은 합이 0인 항을 저장하지 않아요. 모든 차수 배열은 O(D+1), 희소 병합은 O(m+n)이에요.

코드 줄 수가 길다고 더 높은 차수의 시간복잡도라고 판단하지 않아요. 두 표현의 D와 m,n은 서로 다른 입력 크기예요.

</details>

### P11. 구조체 대입과 비교 연산

**강의 예제 기반 자체 출제** S3 p17

강의의 person이 char name\[10\], int age, float height 멤버를 가진다고 해요. a와 b가 유효하게 초기화된 person일 때 b=a;와 if(a&gt;b)는 각각 가능한가요? b=a; 뒤 b.age를 바꾸면 a.age도 바뀌나요? 나이가 더 많은지를 비교하는 올바른 조건을 쓰고 배열 멤버도 대입 때 복사되는지 설명하세요.

<details><summary>강의 예제 보기</summary>

S3 p17 · Software_3_ArrayStructureList.pdf. 강의의 개념·그림·코드 연산을 바탕으로 조건과 질문을 새로 작성한 자체 출제예요. 제시 코드는 있는 경우 학습 확인용 자체 코드이며 강의 원문 발췌가 아니에요. 질문·입력 조건·검산은 자체 작성했어요.

</details>

<details><summary>힌트 보기</summary>

b=a: 같은 타입의 구조체 값 복사라고 적어요.

</details>

<details><summary>풀이 보기</summary>

1. b=a는 같은 구조체 타입의 값을 별도 객체로 대입해요.
2. 구조체 안의 배열 멤버도 이 구조체 대입에 포함돼요. 배열만 단독으로 b.name=a.name이라고 대입하는 것과 달라요.
3. 두 객체는 같은 주소가 아니므로 b.age 수정은 a.age를 바꾸지 않아요.
4. 비교 기준이 나이이면 정수 멤버 a.age와 b.age를 비교해요.

**정답:** 같은 person 타입의 b=a는 가능하고 멤버 값이 복사되어 name 배열의 내용도 복사돼요. b와 a는 별도 객체이므로 b.age만 바꾸면 a.age는 유지돼요. 구조체 전체의 a&gt;b는 C에서 허용되지 않으며 a.age&gt;b.age로 나이를 비교해요.

구조체 대입 가능을 구조체 &gt; 비교 가능으로 확대하지 않아요. 배열 멤버가 있다는 이유로 구조체 대입 전체가 금지된다고 하지 않아요.

</details>
