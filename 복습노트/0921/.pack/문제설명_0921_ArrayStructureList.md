### P1. 함수 foo가 하는 일

2019-mid-q8 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p1)

아래에 함수 foo의 코드가 있어요. 이 함수를 호출(사용)했을 때 무엇을 하는 함수인지 답해 보세요.

함수 foo는 ( ) 함수이다.

`int foo (int x, int y){
    if (x % y == 0) return y;
    else
        return foo(y, x % y);
}`

#### 문제를 내 말로 읽어요

코드가 어떤 문제를 푸는지 이름이 아니라 인자 변화로 판단해요. 입력은 양의 정수 x,y로 두어요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

x%y라는 “나머지”와 (y,x%y) 호출은 Euclidean algorithm의 단서예요. x=qy+r일 때 x,y의 공약수 집합은 y,r의 공약수 집합과 같아요. y&gt;0일 때 0≤r&lt;y예요.

#### 종이에 적을 첫 줄

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

(48,18)→(18,12)→(12,6)에서 나머지가 0이 되어 6을 반환해요. 공약수 d가 x,y를 나누면 x−qy=r도 나누고, 반대로 y,r을 나누면 qy+r=x도 나눠요. 그래서 매 호출의 최대공약수가 같아요. 나머지가 양의 이전 y보다 작아 종료해요.

#### 완성 답과 검산

48의 약수와 18의 약수 중 공통 최대는 6이에요. 순서를 바꾼 foo(18,48)도 (48,18)로 이어져 6이에요. 따라서 답은 최대공약수 GCD예요.

#### 이 문제에서 조심할 점

원 함수는 y=0에서 %0이므로 정의되지 않아요. 양의 입력 조건 없이 모든 정수에 안전하다고 쓰지 않아요.

#### 설명을 닫고 다시 해 봐요

1. foo(48,18)에서 나머지 12를 첫 줄에 적어요.
2. 나머지로 줄이는 유클리드 호제법
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

foo(48,18)에서 나머지 12를 첫 줄에 적어요.

#### 떠올릴 개념·공식

#### 문제를 내 말로 읽어요

빈 gcd 본문을 채워 양의 두 정수의 최대공약수를 반환해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“순환 함수”와 “최대공약수”에서 gcd(i,j)=gcd(j,i%j)를 떠올려요. %를 계산하기 전에 j=0을 검사해야 나눗셈 오류 없이 종료해요.

#### 종이에 적을 첫 줄

`if (j == 0) return i;`

#### 왜 이렇게 푸는지 함께 따라가요

`int gcd(int i, int j) {
    if (j == 0) return i;
    return gcd(j, i % j);
}`

#### 완성 답과 검산

gcd(48,18)→(18,12)→(12,6)→(6,0)→6이에요. 반환값은 추가 계산 없이 위 호출로 전달돼요. 공약수 집합 보존과 두 번째 인자의 감소가 정확성과 종료를 증명해요. 입력 변환 성공과 양의 int 범위를 가정해요.

#### 이 문제에서 조심할 점

if 앞에서 i%j를 계산하면 마지막 호출에서 %0을 하게 돼요. “0이 모든 수를 나눈다”가 아니라 모든 양의 수가 0을 나눈다는 뜻이에요.

#### 설명을 닫고 다시 해 봐요

1. if (j == 0) return i;
2. j=0 종료, 아니면 gcd(j,i%j)
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

if (j == 0) return i;

#### 떠올릴 개념·공식

j=0 종료, 아니면 gcd(j,i%j)

### P3. 자기 자신을 다시 부르는 기법

2018-mid-c102-q1 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p3)

함수가 수행 도중에 자기 자신을 다시 호출하여 문제를 해결하는 기법을 ( ) 이라고 해요. 빈칸을 채워 보세요.

#### 문제를 내 말로 읽어요

함수가 자기 자신을 호출한다는 설명에 맞는 이름을 쓰는 문제예요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“자기 자신을 다시 호출”은 recursion, 수업 용어로 순환(재귀)이에요. 일반 반복 iteration은 루프를 돌지만 별도의 자기 호출을 만들지 않아요.

#### 종이에 적을 첫 줄

빈칸에 순환(recursion)을 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

답은 순환, 또는 동의어 재귀예요. 예를 들어 factorial(3)이 factorial(2)를 호출하면 작은 문제의 답을 받아 현재 답을 만들어요. 올바른 순환은 즉시 답을 주는 바닥 조건과 그 조건으로 다가가는 감소를 함께 가져요.

#### 완성 답과 검산

반복문만 있는 sum은 자기 호출이 없어요. 반대로 함수 안의 자기 호출은 루프가 없어도 순환이에요. 이 차이로 용어를 확인해요.

#### 이 문제에서 조심할 점

함수 이름을 두 번 썼다고 항상 실행 중 자기 호출은 아니에요. 실제 호출 관계를 보아요.

#### 설명을 닫고 다시 해 봐요

1. 빈칸에 순환(recursion)을 적어요.
2. 자기 호출 = 순환/재귀
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

빈칸에 순환(recursion)을 적어요.

#### 떠올릴 개념·공식

자기 호출 = 순환/재귀

<details><summary>기출 원문 보기</summary>

3장 배열, 구조체, 포인터 · 04번 · 책 98쪽

크기가 10인 배열 two[]를 선언하고 여기에 2의 제곱 값들을 저장해보자. 즉 배열의 첫 번째 요소에는 2⁰을 저장하고 두 번째 요소에는 2¹값을 저장한다. 마지막 요소에는 2⁹값을 저장한다. for 루프를 이용하여 two[] 배열의 전체 요소의 값을 출력하는 프로그램을 작성하라.

#### 문제를 내 말로 읽어요

two[0]부터 two[9]까지 2⁰..2⁹를 저장하고 출력해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“이전 값의 두 배”라는 점화식 two[i]=2×two[i−1]로 거듭제곱 power를 만들 수 있어요. C의 ^는 거듭제곱이 아니라 XOR이므로 쓰지 않아요.

#### 종이에 적을 첫 줄

`int two[10];
two[0] = 1;`

#### 왜 이렇게 푸는지 함께 따라가요

`#include <stdio.h>
int main(void) {
    int two[10];
    two[0] = 1;
    for (int i=1; i<10; ++i) two[i] = 2*two[i-1];
    for (int i=0; i<10; ++i) printf("%d%s", two[i], i==9?"\n":" ");
    return 0;
}`

textbook-ch03-q06 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p8)

C언어의 typedef을 이용하여 complex라고 하는 새로운 자료형을 정의하라. complex 자료형은 구조체로서 float형인 real 변수와 역시 float형인 imaginary 변수를 갖는다. complex 자료형으로 변수 c1과 c2를 선언하여보라.

#### 이 문제를 봤을 때 떠올릴 개념과 공식
