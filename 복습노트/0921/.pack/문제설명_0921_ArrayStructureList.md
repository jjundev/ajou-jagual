### P1. 2차원 배열의 바이트 수

textbook-ch03-q01 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p1)

int a[10][20]에서 배열이 차지하는 메모리 공간의 크기는 얼마인가? int형은 4바이트라고 하자.

#### 문제를 내 말로 읽어요

10행 20열의 int 배열 전체 바이트 수를 구해요. int=4바이트는 문제에서 정한 값이에요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“배열이 차지하는 공간”은 원소 개수×원소 한 개의 크기예요. 배열은 같은 타입 원소를 연속 배치하므로 별도 행 포인터 10개가 붙는 것이 아니에요.

#### 종이에 적을 첫 줄

원소 수=10×20=200을 적어요.

#### 왜 이렇게 푸는지 함께 따라가요

200×4=800바이트, 정답 (4)예요. 각 행이 20×4=80바이트이고 10행을 합쳐도 800이에요.

#### 완성 답과 검산

두 방식 200원소×4와 10행×80이 같아요. 실제 C 검산에서도 sizeof(int)==4인 환경의 sizeof a가 800이에요.

#### 이 문제에서 조심할 점

10+20으로 원소 수를 세거나 int**의 저장 크기와 섞지 않아요.

#### 설명을 닫고 다시 해 봐요

1. 원소 수=10×20=200을 적어요.
2. 행×열×int 크기 = 800
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

원소 수=10×20=200을 적어요.

#### 떠올릴 개념·공식

행×열×int 크기 = 800

### P2. 배열에 2의 거듭제곱 저장

textbook-ch03-q04 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p2)

크기가 10인 배열 two[]를 선언하고 여기에 2의 제곱 값들을 저장해보자. 즉 배열의 첫 번째 요소에는 2⁰을 저장하고 두 번째 요소에는 2¹값을 저장한다. 마지막 요소에는 2⁹값을 저장한다. for 루프를 이용하여 two[] 배열의 전체 요소의 값을 출력하는 프로그램을 작성하라.

<details><summary>교과서 원문 보기</summary>

크기가 10인 배열 two[]를 선언하고 여기에 2의 제곱 값들을 저장해보자. 즉 배열의 첫 번째 요소에는 2⁰을 저장하고 두 번째 요소에는 2¹값을 저장한다. 마지막 요소에는 2⁹값을 저장한다. for 루프를 이용하여 two[] 배열의 전체 요소의 값을 출력하는 프로그램을 작성하라.

#### 문제를 내 말로 읽어요

two[0]부터 two[9]까지 2⁰..2⁹를 저장하고 출력해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

“이전 값의 두 배”라는 점화식 two[i]=2×two[i−1]로 거듭제곱 power를 만들 수 있어요. C의 ^는 거듭제곱이 아니라 XOR이므로 쓰지 않아요.

#### 종이에 적을 첫 줄

`int two[10];
two[0] = 1;`

#### 왜 이렇게 푸는지 함께 따라가요

`#include <stdio.h>
int main(void) {
    int two[10];
    two[0] = 1;
    for (int i=1; i<10; ++i) two[i] = 2*two[i-1];
    for (int i=0; i<10; ++i) printf("%d%s", two[i], i==9?"\n":" ");
    return 0;
}`

#### 완성 답과 검산

출력은 1 2 4 8 16 32 64 128 256 512예요. 귀납적으로 첫 원소 2⁰이고 직전 2ⁱ⁻¹의 두 배가 2ⁱ예요. 독립 정수 거듭제곱과 C 출력 모두 대조해요.

#### 이 문제에서 조심할 점

i=0부터 직전 원소를 읽으면 two[−1]로 배열 범위를 벗어나요.

#### 설명을 닫고 다시 해 봐요

1. int two[10]; two[0] = 1;
2. two[0]=1, 이전 원소×2
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

int two[10]; two[0] = 1;

#### 떠올릴 개념·공식

two[0]=1, 이전 원소×2

person이라는 구조체를 만들어보자. 이 구조체에는 문자 배열로 된 이름, 사람의 나이를 나타내는 정수 값, 각 개인의 월급을 나타내는 float 값 등이 변수로 들어가야 한다.

#### 이 문제에서 조심할 점

서로 다른 필드를 int 배열 하나로 대신하지 않아요. 구조체 선언 끝의 세미콜론도 필요해요.

#### 설명을 닫고 다시 해 봐요

1. struct person { 를 먼저 적어요.
2. char name[], int age, float salary
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

### P4. typedef로 complex 만들기

textbook-ch03-q06 · [원 문제 보기](../%EB%B3%B5%EC%8A%B5%EB%AC%B8%EC%A0%9C_0921_ArrayStructureList.html#p4)

C언어의 typedef을 이용하여 complex라고 하는 새로운 자료형을 정의하라. complex 자료형은 구조체로서 float형인 real 변수와 역시 float형인 imaginary 변수를 갖는다. complex 자료형으로 변수 c1과 c2를 선언하여보라.

C언어의 typedef을 이용하여 complex라고 하는 새로운 자료형을 정의하라. complex 자료형은 구조체로서 float형인 real 변수와 역시 float형인 imaginary 변수를 갖는다. complex 자료형으로 변수 c1과 c2를 선언하여보라.

</details>

#### 문제를 내 말로 읽어요

실수부와 허수부를 갖는 타입 complex를 만들고 두 변수를 선언해요.

#### 이 문제를 봤을 때 떠올릴 개념과 공식

typedef는 새로운 표현을 발명하는 것이 아니라 기존 타입에 이름 alias를 붙여요. real과 imaginary는 float, c1과 c2는 이 두 필드를 갖는 객체예요.

#### 종이에 적을 첫 줄

typedef struct { 로 시작해요.

#### 왜 이렇게 푸는지 함께 따라가요

`typedef struct {
    float real;
    float imaginary;
} complex;
complex c1, c2;`

#### 완성 답과 검산

complex c1,c2는 각각 두 float 멤버를 가진 변수를 만들어요. C 컴파일에서 c1.real=1.0f, c2.imaginary=2.0f 접근이 가능해요. typedef 선언만으로는 c1,c2 객체가 생기지 않으므로 별도 선언을 확인해요.

#### 이 문제에서 조심할 점

complex를 구조체 태그와 변수 이름으로 혼동하지 않아요.

#### 설명을 닫고 다시 해 봐요

1. typedef struct { 로 시작해요.
2. typedef 별명 뒤 변수 c1,c2 선언
3. 조건·끝 상태와 검산 근거를 직접 다시 확인해요.

**페이지 요약**

#### 첫 줄

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “행렬 예제를 C 배열과 세 쌍으로 표현하기”예요. 행 0에서 2,3을 기록하고 0은 빼요. 행 1에는 세 값이 모두 있고 행 2에는 첫 칸과 끝 칸이 있어요. 0이 조금 있다고 희소 표현이 항상 작은 것은 아니에요. t가 충분히 작아야 주소 정보의 추가 비용을 상쇄해요.

행 0, 열 0의 값 2를 (0,0,2)로 적어요.

항 개수 7개와 저장하는 정수 개수 21개를 혼동하지 마세요.

#### 설명을 닫고 다시 해 봐요

1. 주어진 시작 상태와 필요한 입력 조건을 적어요.
2. 첫 줄부터 연산 순서를 따라 답을 완성해요.
3. 경계 경우와 오류 경로를 확인해요.

#### 떠올릴 개념·공식

`void hanoi_tower(int n, char from, char tmp, char to)
{
    if(n==1) printf("원판1을%c에서%c으로옮긴다.\n",from,to);

#### 이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “하노이 코드의 매개변수 역할”예요. 가장 큰 원판을 A에서 C로 옮기기 전에 위의 2개를 B로 옮겨야 해요. 그래서 첫 호출의 도착 막대는 tmp(B)이고 보조 막대는 to(C)가 돼요. 위 n-1개 이동, 가장 큰 원판 1회, 위 n-1개 이동이 반드시 필요해요. 같은 전략으로 이 하한을 달성하므로 점화식은 최소 횟수예요.

#### 종이에 적을 첫 줄

맨 큰 원판 3을 A→C로 옮기려면 위 2개를 A→B로 먼저 옮겨요.

#### 왜 이렇게 푸는지 함께 따라가요

1. 가장 큰 원판을 A에서 C로 옮기기 전에 위의 2개를 B로 옮겨야 해요. 그래서 첫 호출의 도착 막대는 tmp(B)이고 보조 막대는 to(C)가 돼요.
2. hanoi(2,A,C,B)는 1:A→C,2:A→B,1:C→B를 출력해요. 이어서 3:A→C를 출력해요.
3. 마지막 hanoi(2,B,A,C)는 1:B→A,2:B→C,1:A→C를 출력해요.
4. 위 n-1개 이동, 가장 큰 원판 1회, 위 n-1개 이동이 반드시 필요해요. 같은 전략으로 이 하한을 달성하므로 점화식은 최소 횟수예요.

1:A→C, 2:A→B, 1:C→B, 3:A→C, 1:B→A, 2:B→C, 1:A→C. T(1)=1, T(n)=2T(n-1)+1, T(3)=7.

#### 완성 답과 검산

1:A→C, 2:A→B, 1:C→B, 3:A→C, 1:B→A, 2:B→C, 1:A→C. T(1)=1, T(n)=2T(n-1)+1, T(3)=7.

시작 조건에서 다시 추적한 결과가 위 답과 일치해요. 위 n-1개 이동, 가장 큰 원판 1회, 위 n-1개 이동이 반드시 필요해요. 같은 전략으로 이 하한을 달성하므로 점화식은 최소 횟수예요.

#### 이 문제에서 조심할 점

from,tmp,to는 고정된 막대 이름이 아니라 현재 호출에서 맡은 역할이에요.

#### 설명을 닫고 다시 해 봐요

1. 주어진 시작 상태와 필요한 입력 조건을 적어요.
2. 첫 줄부터 연산 순서를 따라 답을 완성해요.
3. 경계 경우와 오류 경로를 확인해요.

**페이지 요약**

맨 큰 원판 3을 A→C로 옮기려면 위 2개를 A→B로 먼저 옮겨요.

#### 떠올릴 개념·공식

#### 검산

1:A→C, 2:A→B, 1:C→B, 3:A→C, 1:B→A, 2:B→C, 1:A→C. T(1)=1, T(n)=2T(n-1)+1, T(3)=7.

### P8. 자체 참조 구조체의 링크 타입
