문제를 내 말로 읽기

계산할 숫자를 잠깐 보관했다가 바로 앞의 값부터 꺼낼 도구를 골라요.

이 문제를 봤을 때 떠올릴 개념과 공식

“후위 표기식의 계산”라는 단서에서 후위 표기(postfix)와 스택(stack)을 떠올려요. 스택은 마지막에 넣은 값을 먼저 꺼내는 후입선출(LIFO)이에요.

피연산자(operand)는 계산할 숫자이고, 연산자(operator)는 +·−·*·/ 같은 계산 표시예요. 숫자는 push로 넣고, 이항 연산자는 오른쪽 값을 먼저 pop하고 왼쪽 값을 다음에 pop한 뒤 계산 결과를 다시 push해요.

정상적인 이항 후위식에서는 연산자마다 값 두 개가 준비되어 있어야 하고, 마지막에는 결과 한 개가 남아요. 뺄셈·나눗셈은 왼쪽 값 op 오른쪽 값 순서가 중요해요.

종이에 쓰는 첫 줄

연산자 앞에서 가장 최근 값 두 개를 꺼낸다 → 스택

왜 이렇게 푸는지 함께 따라가요

  1. 숫자는 스택에 넣어 기다리게 해요.
  2. 연산자를 읽을 때 최근 결과 두 개를 꺼내요.
  3. 계산 결과를 다시 넣어 다음 연산의 피연산자로 써요. 따라서 답은 스택이에요.

완성 답과 검산

정답: 스택. 후위식은 각 연산자의 바로 앞에 완성된 두 피연산자가 놓이는 구조라, 최근 값을 먼저 꺼내는 LIFO 규칙이 맞아요.

확인 예시 2 3 + 4 *에서 [2] → [2,3] → [5] → [5,4] → [20]이 돼요. 계산한 5도 새로운 피연산자가 되어 스택에 다시 들어가요.

이 문제에서 조심할 점

숫자만 넣고 중간 결과를 넣지 않으면 다음 연산이 불가능해요. 이 계산에서는 연산자는 실행 신호이며 숫자 스택에 저장하는 값이 아니에요.

혼자 다시 풀어 보기

  1. 숫자·연산자를 만났을 때의 동작을 말해요.
  2. 계산 결과를 다시 넣는 이유를 설명해요.

떠올릴 개념·공식

후위식은 최근 피연산자 둘을 먼저 사용해요.

첫 줄

최근 값을 꺼내는 도구는 스택이에요.

완성 답·검산

정답 스택. 결과도 다시 넣어요.
