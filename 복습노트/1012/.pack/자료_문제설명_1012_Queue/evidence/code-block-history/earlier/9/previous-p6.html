문제를 내 말로 읽기

push·pop의 빈칸과 후위식을 읽는 반복문을 각각 채워요. 주어진 선언과 오류 분기는 그대로 두고 빈칸에 들어갈 문장만 써요.

이 문제를 봤을 때 떠올릴 개념과 공식

“top”, “push”, “pop”이라는 단서에서 배열 스택의 상태를 떠올려요. top은 마지막 유효 원소의 인덱스이고 -1은 빈 상태예요. push는 top을 먼저 증가시키고 저장하며, pop은 현재 값을 보관한 뒤 top을 감소시켜 반환해요.

“한 자리 숫자(0~9), +와 *, 공백 없이”라는 조건은 각 문자 하나가 숫자 또는 연산자라는 뜻이에요. str[i] - '0'은 숫자 문자를 정수로 바꿔요. 덧셈·곱셈은 두 값을 꺼내 계산하고 다시 넣어요. 이미 선언된 op1·op2를 사용하므로 새 변수 선언은 필요 없어요.

실행 가정: 입력은 정상적인 후위식이며 길이는 99자 이하여야 해요. 연산자 앞에 값이 두 개 이상 있고, 스택 용량을 넘지 않으며, 정수 계산 결과가 C의 int 범위 안에 있어야 해요. 원문은 이런 잘못된 입력을 모두 막는 코드가 아니에요.

종이에 쓰는 첫 줄

push의 첫 줄은 s->top = s->top + 1;이에요. pop의 첫 줄은 item = s->stack[s->top];이에요. 반복문에서는 먼저 현재 문자가 +인지 검사해요.

왜 이렇게 푸는지 함께 따라가요

① push의 else 빈칸
s->top = s->top + 1;
s->stack[s->top] = item;

top이 -1이라면 먼저 0으로 올려야 첫 배열 칸에 저장할 수 있어요. 기존 top에 저장하면 맨 위 값을 덮어써요.

② pop의 else 빈칸
item = s->stack[s->top];
s->top = s->top - 1;
return item;

top을 줄이기 전에 현재 값을 item에 보관해요. 그 뒤 top을 내리고 보관한 값을 돌려줘요.

③ main의 for문 빈칸
if (str[i] == '+') {
    op1 = pop(&s);
    op2 = pop(&s);
    push(&s, op1 + op2);
} else if (str[i] == '*') {
    op1 = pop(&s);
    op2 = pop(&s);
    push(&s, op1 * op2);
} else {
    push(&s, str[i] - '0');
}

op1은 먼저 꺼낸 오른쪽 값, op2는 다음에 꺼낸 왼쪽 값이에요. 여기서는 +·*만 있으므로 순서를 바꿔도 계산값은 같아요. 숫자 분기는 문자와 '0'의 차이를 push해요. op라는 변수를 추가하지 않고 원래 빈칸 안에서 해결했어요.

완성 답과 검산

완성 답은 위 세 코드 블록이에요. 원문에 빈칸 답만 삽입해 C11로 컴파일하고, 정상 입력을 실행했어요. 공백 오류 종료나 scanf의 폭 제한을 추가하지 않았어요.

입력손으로 계산실제 출력
23+4*(2+3)*4=20result:20
52*3+5*2+3=13result:13
00result:0
99*9+9*9+9=90result:90

검산에서는 모든 정상 입력이 같은 결과를 냈어요. 배열 원소 개수는 top+1이고, 정상 push 뒤 1 늘며 정상 pop 뒤 1 줄어드는 불변식도 확인했어요. 여기서는 마지막 printf가 결과를 pop하므로 실행 뒤 스택이 비어요.

이 문제에서 조심할 점

원문의 pop은 빈 스택 분기에서 값을 반환하지 않아요. 반환값을 사용하는 공백 pop은 정의된 정상 답으로 취급할 수 없고, 실제 컴파일에도 이 경로의 경고가 나와요. 무제한 scanf("%s", str)도 긴 입력에 안전하지 않아요. 따라서 검산 결과는 위 실행 가정을 만족하는 입력에 한정해요. 원 코드는 고치지 않았어요.

혼자 다시 풀어 보기

  1. top이 -1일 때 push의 두 줄을 추적해요.
  2. 현재 값을 먼저 보관하고 top을 내리는 pop을 써요.
  3. 23+4*의 각 문자와 스택 상태를 확인해요.

떠올릴 개념·공식

배열 스택의 top은 맨 위 인덱스예요. 한 자리 문자는 0 문자를 빼요.

첫 줄

push: top 증가 / pop: 현재 값 보관 / main: 문자 분기

완성 답·검산

빈칸만 채운 원문 코드로 정상 입력 4개 검산. 잘못된 입력은 보장하지 않아요.
