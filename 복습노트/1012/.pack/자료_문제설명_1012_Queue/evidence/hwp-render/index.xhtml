15. 임의의 두 양의 정수의 최대 공약수를 구해주는 gcd를 순환 함수로 구현하시오.

( main함수에서 임의의 두 양의 정수를 입력 ) [5 points]

#include <stdio.h>

int gcd(int i, int j){

if ( j == 0 ) return i;

else return gcd( j, i%j );

}

int main(){

int i, j;

printf("임의의 두 양의 정수 입력:");

scanf("%d %d", &i, &j);

printf("gcd:%d\n", gcd(i, j));

return 0;

}
