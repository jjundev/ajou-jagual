# 배열 스택: ++top과 top--의 위치

1012 수업(Software_5 Stack p13·14, 정리노트 `s0-array / s0-pushpop`)의 코드를 메모리 저장 공간 변화로 확인한다.

## 핵심 질문
push의 ++(s->top)과 pop의 (s->top)--는 각각 어느 인덱스를 쓰고 top을 언제 바꾸는가?

## 학습자에게 남길 것
push는 "증가부터 하고 쓴다": ++(s->top)의 새 값이 저장 위치입니다. pop의 (s->top)--는 감소 전 값으로 원소를 고르고, 함수가 돌아가기 전에 top을 하나 내립니다.

## 입력과 사례
- 입력: push할 값(-99..99), 시작 원소 수(0..5), push 증가 위치(전위 ++ (강의) / 후위 ++ (오류 예))
- preset: [7, 9]에 4 넣고 꺼내기, 후위 ++로 바꾸면?, 빈 스택(top = -1), 빈 스택 + 후위 ++, 꽉 찬 스택에 push, 마지막 칸에 -99
- 주소는 기호(&s, &D 등)이며 실제 번지·ABI 배치를 주장하지 않는다.
