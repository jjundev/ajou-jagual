풀이 보기

  2. count_nodes는 head에서 출발해 p가 NULL이 될 때까지 이동하며 세어요.
  3. 입력 3, 5, 6, 7이면 결과는 3이에요. 빈 리스트는 0이에요. 생성한 노드는 마지막에 반납해요.
  4. 수업과의 연결: 1005 수업 정리노트의 “1. 방문 연산 display: 반복과 순환” 토픽과 강의록에서 다룬 연산·표현을 적용해요.
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int data; struct Node *link; } Node;
int count_nodes(Node *head) {
    int count = 0;
    for (Node *p = head; p != NULL; p = p->link) ++count;
    return count;
}
int main(void) {
    int n, value;
    Node *head = NULL, *tail = NULL;
    if (scanf("%d", &n) != 1 || n < 0) return 1;
    for (int i = 0; i < n; ++i) {
        if (scanf("%d", &value) != 1) return 1;
        Node *p = malloc(sizeof *p);
        if (p == NULL) return 1;
        p->data = value;
        p->link = NULL;
        if (tail == NULL) head = p;
        else tail->link = p;
        tail = p;
    }
    printf("%d\n", count_nodes(head));
    while (head != NULL) {
        Node *next = head->link;
        free(head);
        head = next;
    }
    return 0;
}

P4. 역순 코드의 세 포인터

강의 예제 기반 자체 출제 S4 p32

A→B→C→NULL에 대해 각 반복이 끝난 직후 p,q,r과 이미 뒤집힌 부분을 적으세요. q->link=r을 p=p->link보다 먼저 실행하면 원래 나머지 리스트를 잃는 이유와 빈 리스트의 반환값도 설명하세요.

ListNode *reverse(ListNode *head)
{
    ListNode *p,*q,*r;
    p=head; q=NULL;
    while(p!=NULL) {
        r=q;
        q=p;
        p=p->link;
        q->link=r;
    }
    return q;
}

{
    ListNode *p,*q,*r;

힌트 보기

p는 아직 처리하지 않은 부분의 첫 노드이고 q는 이미 뒤집힌 부분의 첫 노드예요.

풀이 보기
  1. p는 아직 처리하지 않은 부분의 첫 노드이고 q는 이미 뒤집힌 부분의 첫 노드예요.
  2. 현재 p를 q로 옮기기 전 기존 q를 r에 보관해요. 다음 처리 위치 p->link를 저장한 뒤 q->link를 r로 뒤집어요.
  3. 링크를 먼저 뒤집으면 p와 q가 같은 노드를 가리키므로 p->link가 원래 다음 노드가 아니게 돼요.
  4. 반복이 끝나면 p=NULL이고 q가 전체 역순 리스트의 첫 노드예요.

정답: 1회 p=B,q=A,r=NULL, A→NULL. 2회 p=C,q=B,r=A, B→A→NULL. 3회 p=NULL,q=C,r=B, C→B→A→NULL. 빈 입력 반환 NULL.

원래 head 변수가 자동으로 새 첫 노드를 가리키는 것은 아니에요. 반환값을 받아야 해요.

P5. 연결 리스트 삽입의 세 경우

강의 예제 기반 자체 출제 S4 p25

각 상황은 독립적이고 new_node=N은 새로 할당한 노드예요. 빈 리스트, A→B→NULL에서 p=NULL, 같은 리스트에서 p=A인 경우의 결과를 쓰세요. phead가 이중 포인터인 이유와 마지막 두 대입문의 순서가 중요한 이유도 설명하세요.

void insert_node(ListNode **phead,ListNode *p,ListNode *new_node)
{
    if(*phead==NULL) {
        new_node->link=NULL;
        *phead=new_node;
    } else if(p==NULL) {
        new_node->link=*phead;
        *phead=new_node;
    } else {
        new_node->link=p->link;
        p->link=new_node;
    }
}

힌트 보기

*phead는 호출자의 head예요. 빈 리스트에서는 N만 연결하면 돼요.

풀이 보기
  1. *phead는 호출자의 head예요. 빈 리스트에서는 N만 연결하면 돼요.
  2. 맨 앞 삽입에서는 N의 link에 기존 head를 보관하고 head를 N으로 바꿔요.
  3. 중간 삽입에서는 기존 p->link=B를 N->link에 먼저 저장해요. 그다음 p->link를 N으로 바꿔요.
  4. p->link=N을 먼저 쓰면 다음 문장에서 N->link=N이 되어 원래 뒷부분을 잃어요.

정답: 빈 리스트 N→NULL. p=NULL이면 N→A→B→NULL. p=A이면 A→N→B→NULL. 호출자의 head 값을 바꾸기 위해 그 주소를 받는다. N의 다음 링크를 먼저 보관해야 B를 잃거나 자기 순환을 만들지 않는다.

p==NULL은 비어 있다는 뜻이 아니라 선행 노드가 없어 맨 앞에 삽입한다는 뜻이에요.

P6. 삭제할 노드를 해제하기 전의 연결

강의 예제 기반 자체 출제 S4 p28

리스트 A→B→C→NULL의 노드는 각각 malloc으로 할당했어요. B를 삭제할 p와 removed, A를 삭제할 p와 removed를 쓰세요(두 상황은 독립적). 하나뿐인 A를 삭제하면 head는 무엇이 되나요? free를 먼저 하면 안 되는 이유도 설명하세요.

void remove_node(ListNode **phead,ListNode *p,ListNode *removed)
{
    if(p==NULL) *phead=(*phead)->link;
    else p->link=removed->link;
    free(removed);
}

    else p->link=removed->link;

힌트 보기

p는 삭제 대상이 아니라 그 선행 노드예요. removed는 실제로 반납할 노드예요.

풀이 보기
  1. p는 삭제 대상이 아니라 그 선행 노드예요. removed는 실제로 반납할 노드예요.
  2. 중간 삭제는 A의 link를 B의 다음인 C로 우회시켜요. 맨 앞 삭제는 head를 기존 head의 link로 옮겨요.
  3. 단일 노드의 link는 NULL이므로 head도 NULL이 돼요. 링크를 읽고 갱신한 다음 free해야 해요.

정답: B 삭제: p=A,removed=B, 결과 A→C. A 삭제: p=NULL,removed=A, 결과 B→C. 단일 노드 삭제 뒤 head=NULL. free 뒤 removed->link를 읽으면 해제된 메모리 접근이다.

이 함수는 removed가 유효하고 p가 올바른 선행 노드라는 전제가 필요해요. 빈 리스트 삭제를 호출하면 안 돼요.

풀이 보기
  1. 원형 리스트의 시작은 head 자체가 아니라 head->link예요. B->link=A를 먼저 N->link에 저장해요.

여기서 head를 첫 노드라고 해석하면 모든 결과가 한 칸씩 달라져요.

풀이 보기
  1. 새 노드의 양쪽을 먼저 A,B로 정해요. 그런 다음 기존 B의 왼쪽과 A의 오른쪽을 N으로 바꿔요.
  2. 세 번째 문장의 before->rlink는 아직 B여야 해요. 네 번째 문장을 먼저 실행하면 이 식이 N을 가리키므로 다른 링크를 고치게 돼요.

정답: N->llink=A,N->rlink=B,B->llink=N,A->rlink=N. 순서를 뒤집으면 before->rlink가 N이어서 N->llink=N으로 바뀌고 B->llink가 갱신되지 않는다. 삭제: N->llink->rlink=N->rlink; N->rlink->llink=N->llink; 뒤에 free(N).

새 노드 자신의 링크 두 개만 설정해서는 기존 두 노드가 새 노드를 가리키지 않아요.

P9. 방문 순서와 탐색의 반환값

유한한 단순 리스트 A(data10)→B(data=20)→C(data30)→NULL에 아래 두 함수를 적용하세요. display_recur(head)가 출력하는 순서, search(head,20)과 search(head,99)의 반환값, 호출 후 원래 head와 링크가 바뀌는지를 쓰세요. 빈 리스트에서 두 함수의 결과와 재귀 호출로 방문하는 함수가 종료하는 이유도 설명하세요. search가 반환하는 것은 값20인가요, 노드 주소인가요?

void display_recur(ListNode *head)

ListNode *search(ListNode *head,int x)

P10. 헤드 포인터와 헤드 노드의 공백 표현

강의 예제 기반 자체 출제 S4 p37 · 추가 근거 p33,34,35,36,45,46,44,47,48

데이터 노드가 하나도 없는 세 구현을 비교하세요: 헤드 노드 없는 단순 리스트, 헤드 노드 없는 원형 단순 리스트(꼬리를 head로 둠), 헤드 노드 H가 있는 원형 이중 리스트. 각 구현에서 head 또는 H의 두 링크가 가져야 할 값을 쓰고, 헤드 포인터와 헤드 노드의 차이를 설명하세요. H를 데이터로 세거나 삭제하면 안 되는 이유와, H의 왼쪽·오른쪽 링크로 각각 무엇에 즉시 접근하는지도 설명하세요. 추가로 강의 ListType은 헤드 노드 없이 head와 length를 보관합니다. 빈 ListType의 head·length, 노드가 세 개일 때 get_length가 링크를 순회해야 하는지와 그 비용, 삽입·삭제 때 length도 함께 갱신해야 하는 이유를 쓰세요. 끝으로 리스트 ADT의 add/delete가 받는 위치 정수와 insert_node/remove_node가 받는 노드 포인터를 구별하고, 새 함수를 처음부터 다시 짜지 않고 두 인터페이스를 연결하는 방법을 한 문장으로 설명하세요(구체 호출 추적은 묻지 않습니다).

강의 예제 보기

S4 p37 · 추가 근거 p33,34,35,36,45,46,44,47,48 · Software_4_List.pdf. 강의 개념·그림을 근거로 질문을 직접 작성했습니다. 강의 원문 코드의 전사가 아닙니다. 질문·입력 조건·검산은 자체 작성했어요.

힌트 보기

단순(헤드 노드 없음): head=NULL. 이중 원형(헤드 노드 있음): H↔H.

풀이 보기
  1. 헤드 노드가 없는 구조는 데이터가 없으면 가리킬 노드가 없어 head=NULL이에요.
  2. 헤드 노드가 있는 구조는 데이터가 없어도 H가 남아 양방향으로 자신을 가리켜요.
  3. H의 두 링크는 빈 경우에도 유효하므로 삽입·삭제의 경계 처리에 도움이 돼요.
  4. H는 실제 데이터가 아니므로 데이터 수가 0인 상태에 노드 H가 존재해도 모순이 아니에요.
  5. ListType은 센티널 노드가 아니라 head와 length를 묶은 구조체예요. 헤드 노드 없는 빈 구조에서는 head=NULL, length=0이며 실제 노드 수와 length가 항상 같아야 해요.
  6. 위치는 사용자 관점이고 노드 주소는 연결 구현 관점이에요. 위치를 주소로 변환하는 경계를 두면 기존 연결 함수를 다시 작성하지 않아도 돼요.

정답: 앞 두 구현은 head=NULL입니다. 헤드 노드가 있는 공백 이중 원형 리스트는 H.llink=H,H.rlink=H입니다. 헤드 포인터는 주소 변수이고 헤드 노드는 구조를 단순화하는 별도 노드입니다. H는 데이터항목이 아니므로 길이에 세거나 일반 데이터 삭제 대상으로 삼지 않습니다. 비어 있지 않으면 H.rlink는 첫 데이터,H.llink는 마지막 데이터이며 공백이면 둘 다H입니다. 헤드 노드 없는 빈 ListType은 head=NULL,length=0입니다. get_length는 저장된 length를 바로 반환하므로 O(1)이며, 삽입·삭제 성공 때 실제 노드 수와 맞도록 length를 늘리거나 줄여야 합니다. ADT 연산은 항목 위치를 받고 하위 연결 함수는 선행·대상 노드 주소를 받습니다. 위치를 필요한 노드 포인터로 변환한 뒤 검증된 삽입·삭제 함수를 호출하고 길이를 갱신하여 재사용합니다.

모든 공백 리스트의 head가 NULL이라는 일반화를 하지 않아요. 헤드 노드 유무가 전제예요.

P11. 연결 다항식의 지수 비교와 포인터 이동

강의 예제 기반 자체 출제 S4 p41 · 추가 근거 p40,42,43

지수 내림차순 리스트 A=(3,12)→(2,8)→(1,0), B=(8,12)→(-3,10)→(10,6)을 더하세요. 쌍은 (계수,지수)이며 입력은 서로 다른 유한 리스트입니다. 각 비교에서 결과에 붙이는 항과 이동하는 포인터 p·q, 한쪽이 끝난 뒤 처리, 최종 다항식을 쓰세요. 지수가 같을 때 계수 합이0이면 어떻게 처리해야 하는지와 결과의 꼬리 포인터를 유지하여 항 추가가 O(1)일 때 두 리스트 길이 m,n에 대한 선형 병합 비용도 설명하세요.

강의 예제 보기

S4 p41 · 추가 근거 p40,42,43 · Software_4_List.pdf. S4 p40–43의 연결 리스트 그림과 덧셈 규칙을 문제로 옮겼습니다. 계수·지수는 강의 예제를 따르며 C 원문 코드가 없는 그림 기반 자체 출제입니다. 질문·입력 조건·검산은 자체 작성했어요.

힌트 보기

p=(3,12), q=(8,12): 같은 지수 → (11,12), p와q모두 다음.

풀이 보기
  1. 지수가 같은 12에서는 계수 3+8=11이며 두 입력 항을 모두 소비해요.
  2. 지수 8과 10에서는 높은 지수 10의 B 항을 먼저 붙이고 q만 옮겨요.
  3. 지수 8과 6에서는 높은 지수 8의 A 항을 붙이고 p만 옮겨요.
  4. 지수 0과 6에서는 B의 지수 6 항을 붙여 B가 끝나요. A의 상수항을 결과에 붙여요.
  5. 같은 지수에서 계수가 상쇄돼도 두 입력 항을 처리한 것이므로 두 포인터를 모두 옮겨요.

정답: 같은 지수 12에서는 (11,12)를 붙이고 p, q를 모두 이동합니다. 8<10에서는 (-3,10)을 붙이고 q만, 8>6에서는 (2,8)을 붙이고 p만, 0<6에서는 (10,6)을 붙이고 q만 이동합니다. B가 끝나면 A의 (1,0)을 복사합니다. 결과는 11x^12−3x^10+2x^8+10x^6+1입니다. 같은 지수의 계수 합이 0이면 결과에 붙이지 않되 p, q를 모두 이동합니다. 각 항을 한 번씩 소비하므로 O(m+n)입니다.

계수가 큰 쪽을 선택하지 않아요. 비교하는 것은 지수예요. 한쪽이 끝났다고 다른 쪽의 남은 항을 버리지 않아요.
