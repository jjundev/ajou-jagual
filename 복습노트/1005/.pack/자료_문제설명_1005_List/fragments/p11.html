문제를 내 말로 읽어요

지수 내림차순으로 연결된 두 다항식 A와 B를 포인터 p, q로 비교하며 더하는 과정과 선형 병합 시간 복잡도를 구하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “연결 다항식의 지수 비교와 포인터 이동”이에요. 두 항의 지수가 같으면 계수를 더하고 p, q를 모두 전진시키며, 한쪽 지수가 더 크면 그 항만 결과에 붙이고 해당 포인터만 전진시켜요.

종이에 쓰는 첫 줄

p = (3, 12), q = (8, 12): 지수가 12로 같으므로 (11, 12)를 붙이고 p, q 모두 이동해요.

왜 이렇게 푸는지 함께 따라가요

(a) ① 지수 12 == 12: (11, 12)를 추가하고 p, q 모두 이동해요. ② 지수 8 < 10: (-3, 10)을 추가하고 q만 이동해요. ③ 지수 8 > 6: (2, 8)을 추가하고 p만 이동해요. ④ 지수 0 < 6: (10, 6)을 추가하고 q만 이동해 B가 끝나요. ⑤ 남은 A의 (1, 0)을 복사해 최종 다항식은 $11x^{12} - 3x^{10} + 2x^8 + 10x^6 + 1$이에요.

(b) 같은 지수의 계수 합이 0이면 결과 다항식에 항을 붙이지 않지만 두 입력 항은 모두 소비했으므로 p, q를 둘 다 다음 노드로 이동해요. 매 비교마다 적어도 한 포인터가 전진해 각 항을 한 번씩만 처리하므로 전체 시간 복잡도는 $O(m + n)$이에요.

완성 답과 검산

(a) 지수별로 검산하면 $12$차($3+8=11$), $10$차($-3$), $8$차($2$), $6$차($10$), $0$차($1$)로 내림차순 5개 항이 정확히 일치해요.

(b) 입력 항 총 $3 + 3 = 6$개가 후퇴 없이 한 번씩만 소비되므로 선형 시간 $O(m + n)$이 성립해요.

이 문제에서 조심할 점

계수가 큰 쪽이 아니라 지수가 큰 쪽을 먼저 선택하며, 한쪽 리스트가 끝났다고 다른 쪽에 남은 항을 버리지 않아요.

설명을 닫고 다시 해 봐요

  1. 4번의 지수 비교 단계마다 추가되는 항과 이동하는 포인터(p 또는 q)를 적어요.
  2. B가 끝난 뒤 남은 A의 항 처리와 최종 다항식을 적어요.
  3. 계수 합이 0일 때의 포인터 이동과 시간 복잡도 $O(m + n)$을 확인해요.

떠올릴 개념·공식

높은 지수 항을 먼저 결과에 붙이고 해당 포인터를 전진시키며, 지수가 같으면 계수를 더하고 p, q를 함께 전진시켜요.

첫 줄

p = (3, 12), q = (8, 12): 지수가 12로 같으므로 (11, 12)를 붙이고 p, q 모두 이동해요.

핵심 답

(a) (11, 12)(p,q) → (-3, 10)(q) → (2, 8)(p) → (10, 6)(q) → (1, 0) 복사, $11x^{12} - 3x^{10} + 2x^8 + 10x^6 + 1$ (b) 계수 합 0이면 미추가 후 p, q 모두 이동, 시간 복잡도 $O(m + n)$

조건·구분과 확인

  • O(m+n)은 결과 리스트의 마지막 포인터를 유지해 항 추가가 O(1)이라는 조건에서 성립해요.
