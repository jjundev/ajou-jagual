# 쾨니히스베르크 다리 건너기

## 학습 질문

다리를 한 번씩 쓰고 출발점으로 돌아오려면, 각 땅에 닿는 다리는 어떻게 짝을 이뤄야 할까요?

- 강의록 S10 p3의 땅 A–D와 다리 a–g를 그대로 사용한다. 같은 두 땅을 잇는 다리는 각각 센다.
- a를 뺀 사례는 C에서 출발해 D에서 끝난다. a와 g를 빼면 A에서 출발해 A로 돌아온다. 연결이 끊긴 사례는 A–B의 a·b와 C–D의 g·h를 사용한다. h는 보충 다리다.
- 사례를 바꾸고 출발점을 직접 선택한다. 한 단계마다 현재 땅에 닿은 미사용 다리 중 이름순으로 첫 다리를 고른 뒤 건넌다. 마지막에는 시도 결과와 오일러 경로의 존재 조건을 함께 확인한다.

## 상태와 검산

- 강의 그림의 정점·간선을 화면 배치로 사용한다. 추적 상태에는 출발점과 다리별 건넌 순서를 저장한다. 그림, 현재 위치, 차수, 사용한 간선, 이동 기록은 단계 상태에서 계산한다.
- 이름순 건너기는 한 번의 시도다. 예를 들어 회로가 존재하는 배치에서도 이름순 선택은 일부 다리를 남길 수 있다.
- 열린 경로와 회로의 조건을 구별한다. 차수 0인 정점을 제외하고 연결 여부를 확인한다.
- 강의는 원문 C를 제시하지 않았다. 화면의 의사코드는 보충이다. 독립 Python 검산은 각 단계의 다리 사용과 이동을 대조하고 모든 가능한 경로의 끝점을 완전탐색한다.
