핵심 조건과 구할 것

“단순 경로 + 시작 정점 = 종료 정점”을 만족하는 경로의 이름을 빈칸에 써요.

  • 단순 경로: 같은 정점을 두 번 지나지 않는 경로예요.
  • 시작 = 끝: 마지막에 출발 정점으로 되돌아와 고리가 닫혀요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 개념이 문제에 쓰는 이유
‘경로’경로(path) = 간선으로 이어진 정점의 나열빈칸의 답도 정점 나열의 한 종류라서, 나열이 어떤 모양인지로 이름을 정해요(정리노트).
‘단순 경로’정점이 반복되지 않는 경로예: G1의 0, 1, 2, 3. 이 조건이 중간 정점의 겹침을 막아요.
‘시작 = 종료’사이클(cycle)단순 경로의 끝을 출발점으로 되돌리면 0, 1, 2, 0처럼 닫힌 고리가 돼요. 강의록 S10 p7이 이 둘을 나란히 보여 줘요.

종이에 쓰는 실제 첫 줄

단순 경로 예: 0, 1, 2, 3   (끝 ≠ 시작)
끝을 시작으로: 0, 1, 2, 0   (끝 = 시작, 중간 정점 겹침 없음) → 이름은?

왜 이렇게 푸는지 함께 따라가요

  1. 경로는 정점을 차례로 늘어놓은 것이고, 단순 경로는 그중 같은 정점이 다시 나오지 않는 것이에요.
  2. 단순 경로 0, 1, 2에서 마지막에 간선 (2, 0)을 따라 시작 정점 0으로 돌아오면 0, 1, 2, 0이 돼요. 반복되는 것은 시작과 끝의 0 하나뿐이에요.
  3. 이렇게 시작과 끝이 같은 단순 경로를 사이클(cycle)이라고 불러요. 빈칸의 답은 사이클이에요.

완성 답과 검산

완성 답: 사이클(cycle)

  • 정의에 대입: G1(간선 0–1, 0–2, 0–3, 1–2, 2–3)에서 0, 1, 2, 0은 간선 0–1, 1–2, 2–0이 모두 있고, 시작·끝이 0으로 같으며, 마지막 0을 빼면 0, 1, 2가 서로 달라요. 세 조건을 모두 만족해요.
  • 반대 사례로 경계 확인: 0, 1, 2, 3은 끝이 3이라 사이클이 아니에요. 0, 1, 2, 0, 3, 2, 0은 시작=끝이지만 중간에 0과 2가 다시 나와 단순 경로가 아니므로 사이클이 아니에요.

오해하기 쉬운 이유와 반례

  • “시작과 끝이 같으면 다 사이클”이라고 외우면: 0, 1, 2, 0, 3, 2, 0처럼 시작=끝이어도 중간에 0·2를 다시 밟는 나열까지 사이클로 잘못 판정해요. ‘단순 경로’ 조건이 빠졌기 때문이에요.
  • “경로의 길이”와 헷갈리면: 길이는 쓰인 간선 수(0, 1, 2, 0은 3)라는 숫자이고, 빈칸은 경로의 이름을 묻고 있어요.

해설을 닫고 스스로 확인해요

  1. 정점 나열을 보면 → ① 시작=끝인지 ② 마지막을 뺀 정점이 모두 다른지 ③ 이웃한 두 정점마다 간선이 있는지 순서대로 체크해 보세요.
  2. 0, 2, 3, 0이 G1에서 사이클인지 위 세 단계로 판정해 보세요.

떠올릴 개념

경로 = 정점의 나열, 단순 경로 = 정점 반복 없음, 단순 경로 + 시작=끝 = 사이클.

첫 줄

단순 경로 0, 1, 2, 3과 닫힌 0, 1, 2, 0을 나란히 적어 비교.

판단과 검산

답은 사이클. 0, 1, 2, 0은 세 조건 만족, 중간 정점이 반복되는 닫힌 나열은 사이클이 아님.
