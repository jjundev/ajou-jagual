핵심 조건과 구할 것

방향 그래프가 n×n 인접 행렬 a로 주어질 때 (1) 진출 차수, (2) 진입 차수, (3) 전체 간선 수를 세는 함수를 쓰고 각각의 시간 복잡도를 답해요.

  • a[i][j] = 1은 간선 <i, j>(i에서 j로)가 있다는 뜻이에요. 행 = 출발, 열 = 도착이에요.
  • 원문의 “크기가 n×n인 방향 그래프”는 정점이 n개라는 뜻으로 읽어요(행렬이 n×n).

이 문제를 봤을 때 떠올릴 개념과 공식

문제 단서꺼낼 도구이 문제에 쓰는 이유
(1) ‘진출차수’ = 나가는 간선v행의 합 $\sum_{j} a[v][j]$ <v, j>는 모두 v행에 있어요(정리노트).
(2) ‘진입차수’ = 들어오는 간선v열의 합 $\sum_{i} a[i][v]$ <i, v>는 모두 v열에 있어요. 방향 그래프는 행렬이 대칭이 아니라 행과 열의 합이 달라요.
(3) ‘간선들의 개수’행렬 전체 합방향 간선 하나가 1 한 칸이라 1의 총개수가 곧 간선 수예요.
‘시간 복잡도’반복문이 보는 칸 수한 행·한 열은 n칸, 전체는 $n^2$칸이에요. 1이 몇 개인지와 상관없이 칸을 모두 봐요.

종이에 쓰는 실제 첫 줄

out(v) = a[v][0] + a[v][1] + ... + a[v][n-1]    /* v행 */
in(v)  = a[0][v] + a[1][v] + ... + a[n-1][v]    /* v열 */

왜 이렇게 푸는지 함께 따라가요

세 함수는 행렬을 int a[][MAX_VERTICES]로 받고 실제 정점 수 n을 따로 받아요.

(1) 진출 차수: j를 0부터 n-1까지 돌며 a[v][j]를 더해요.

#define MAX_VERTICES 50

int out_degree(int a[][MAX_VERTICES], int n, int v)
{
    int j, count = 0;
    for (j = 0; j < n; j++)
        count += a[v][j];
    return count;
}

반복이 n번이고 한 번에 상수 시간이라 $O(n)$이에요.

(2) 진입 차수: 이번에는 열을 고정하고 i를 돌려 a[i][v]를 더해요.

int in_degree(int a[][MAX_VERTICES], int n, int v)
{
    int i, count = 0;
    for (i = 0; i < n; i++)
        count += a[i][v];
    return count;
}

역시 칸 n개라 $O(n)$이에요.

(3) 간선 수: 이중 반복문으로 n×n칸을 모두 더해요.

int edge_count(int a[][MAX_VERTICES], int n)
{
    int i, j, count = 0;
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            count += a[i][j];
    return count;
}

바깥 n번 × 안쪽 n번이라 $O(n^2)$이에요. 방향 그래프라 합을 2로 나누지 않아요. (무방향 그래프였다면 간선 하나가 대칭인 두 칸에 들어가 합/2가 간선 수예요.)

완성 답과 검산

(1) 완성 답: v행의 합, $O(n)$. 수업 G3(<0,1>, <1,0>, <1,2>, 행렬 {0,1,0}, {1,0,1}, {0,0,0})에서 정점 1의 진출 차수는 1행 1 0 1의 합 2이고, 실제로 1에서 나가는 화살표도 1→0, 1→2 두 개예요. 정점 2는 0(나가는 간선 없음, 경계값)이에요.

(2) 완성 답: v열의 합, $O(n)$. G3에서 정점 1의 진입 차수는 1열 1, 0, 0의 합 1(0→1 하나)이에요. 진출 2와 달라서 행과 열을 바꿔 쓰면 틀린다는 것이 드러나요.

(3) 완성 답: 행렬 전체 합, $O(n^2)$. G3은 $1 + 2 + 0 = 3$으로 간선 3개와 같아요. 또 교과서 8번 그래프(간선 13개)에서는 진출 차수 합 $3+3+4+1+2$와 진입 차수 합 $3+3+3+2+2$가 모두 13이고, 전체 합도 13이에요. 위 세 함수를 cc -std=c11 -Wall로 컴파일해 두 그래프에 돌린 결과도 같았어요. 간선이 0개인 행렬과 모든 칸이 1인 행렬에서도 본 칸 수는 n, n, $n^2$으로 같았어요.

오해하기 쉬운 이유와 반례

  • 무방향 습관대로 행 합을 진입 차수로도 쓰면: G3의 정점 2는 행 합 0이지만 1→2가 들어와 진입 차수는 1이에요. 방향 그래프 행렬은 대칭이 아니에요.
  • 간선 수에서도 2로 나누면: G3에서 $3 / 2 = 1$(정수 나눗셈)이 되어 간선 3개와 어긋나요. 방향 간선은 한 칸에만 들어가요.

해설을 닫고 스스로 확인해요

  1. “진출/진입”을 보면 → a[출발][도착]을 먼저 적고, 고정할 인덱스가 행인지 열인지 정해 보세요.
  2. “간선 수” 함수를 쓰면 → 방향인지 확인해 2로 나눌지 결정하고, 이중 반복이라 $O(n^2)$인지 점검해 보세요.
  3. 같은 세 질문을 인접 리스트로 바꾸면 (1)의 비용은 어떻게 달라질까요?

떠올릴 개념

a[i][j]=1 ⇔ <i,j>. 행 = 출발, 열 = 도착, 방향 그래프 행렬은 비대칭.

답

(1) v행 합 $O(n)$ (2) v열 합 $O(n)$ (3) 전체 합 $O(n^2)$, 방향이라 2로 나누지 않음.

검산

G3 정점 1: 진출 2, 진입 1, 간선 3. 교과서 8번: 진출·진입 합 모두 13.
