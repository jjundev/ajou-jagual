# 인접 행렬로 진출·진입 차수 읽기

## 학습 질문

정점 1에 화살표가 세 개 닿는 G3에서, 나가는 것과 들어오는 것을 행렬의 어느 줄에서 각각 세나요?

- 강의록 S10 p6–7, p9의 G3와 문제설명 P9를 근거로 고른다. G3의 방향 간선은 0→1, 1→0, 1→2다.
- 정점 1의 진출·진입은 각각 2·1이다. 정점 2의 합은 0·1, 정점 0의 합은 1·1이다. 간선이 없는 보충 그래프의 모든 차수는 0이다.
- 현재 읽는 행·열과 행렬 칸을 강조한다. 1인 칸을 읽으면 같은 방향의 화살표를 강조하고, 이어 누적값의 변화를 보여 준다.

## 상태와 검산

- 문제설명 P9의 두 반복문을 크기 3의 행렬을 받는 보충 C 함수 한 개로 구성했다. 화면에 나온 함수는 source.c와 일치한다.
- 호출자가 합을 담을 두 칸을 0으로 초기화한다. 시뮬레이션은 함수 진입 이후 행렬 접근과 누적에 집중하며 인자 바인딩, 반복 제어, 주소 표시는 생략한다. 같은 C 문장의 읽기와 누적을 별도 단계로 보여 준다.
- 행과 열을 각각 3칸 읽는다. 일반 크기 n에서는 각각 O(n)이다.
- 독립 검산은 컴파일한 C 원형과 계측 버전의 결과를 대조한다. 계측 버전의 6개 접근 방향, 칸 값, 누적 전후값을 각 사례의 단계 기록과 비교한다.
