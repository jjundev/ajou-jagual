# 내용 대조

- 강의록 S10 p6의 G3 간선 세 개와 p9 행렬을 대조했다. 행 0은 0 1 0, 행 1은 1 0 1, 행 2는 0 0 0이다. 인접 행렬의 행은 출발, 열은 도착이다.
- 문제설명 P9의 식을 대조했다. 6행에서 v를 행에 고정해 m[v][i]를 읽어 sum[0]에 더한다. 9행에서는 v를 열에 고정해 m[i][v]를 읽어 sum[1]에 더한다. 0을 읽는 단계도 수식에 포함한다.
- G3의 정점 1은 서로 반대 방향인 0↔1을 올바르게 구별해 1→0과 1→2를 진출에, 0→1을 진입에 더한다. 정점 2는 진출 0이고 진입 1이다. 그래프에 간선이 없을 때에도 각 축의 칸을 세 번씩 읽는다.
- 계측용 헤더, main 및 로그 삽입은 evidence/oracle.py에 있으며 화면 코드에는 없다.
