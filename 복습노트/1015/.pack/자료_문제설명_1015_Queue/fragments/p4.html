문제를 내 말로 읽어요

단순 연결 큐의 enqueue와 dequeue 의사코드를 공백·단일 노드 경계 조건에 주의하며 C 포인터 대입문으로 옮기는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

문제의 단서는 “연결 큐 의사코드를 대입문으로 옮기기”예요. 첫 노드를 넣을 때는 기존 rear가 없으므로 front = N으로 두고, 마지막 노드를 꺼내 front == NULL이 되면 rear = NULL까지 함께 초기화해야 해요.

종이에 적을 첫 줄

공백 큐 조건 front == NULL(양 끝 모두 NULL)을 먼저 적어요.

왜 이렇게 푸는지 함께 따라가요

(a) enqueue에서 큐가 비어 있으면(front == NULL) front = N;으로 첫 노드를 가리키게 하고, 비어 있지 않으면 rear->link = N;으로 기존 꼬리 뒤에 연결한 뒤, 두 경우 모두 rear = N;으로 꼬리 포인터를 갱신해요.

(b) dequeue에서는 old = front; item = old->data; front = old->link;로 값을 꺼내고 머리를 옮긴 뒤, 만약 front == NULL이면 마지막 노드가 삭제된 것이므로 rear = NULL;로 함께 비워 주고 free(old);를 호출해요. 그렇지 않으면 rear가 해제된 노드를 가리키게 돼요.

완성 답과 검산

(a) 빈 큐에 N 하나를 enqueue하면 front = rear = N, N->link = NULL이 되어 단일 노드 큐 불변식이 성립해요.

(b) 그 유일한 노드 N을 dequeue하면 front = N->link = NULL이 되고 if (front == NULL) rear = NULL;에 의해 초기 공백 상태 front = rear = NULL로 정확히 돌아와요.

이 문제에서 조심할 점

의사코드의 각 단계를 빠짐없이 대입문으로 옮기세요. 빈 큐와 노드가 하나뿐인 경우를 따로 확인해요.

설명을 닫고 다시 해 봐요

  1. front == NULL일 때와 아닐 때 enqueue의 대입문을 각각 적어요.
  2. dequeue에서 노드 해제 전후로 수행할 포인터 갱신문을 순서대로 적어요.
  3. front == NULL일 때 rear = NULL을 생략하면 남는 문제를 확인해요.

첫 줄

공백 큐 조건 front == NULL(양 끝 모두 NULL)을 먼저 적어요.

떠올릴 개념·공식

빈 큐 삽입은 front = rear = N, 마지막 노드 삭제 후에는 front = rear = NULL로 맞춰요.

검산

(a) if (front == NULL) front = N; else rear->link = N; rear = N; (b) old = front; item = old->data; front = old->link; if (front == NULL) rear = NULL; free(old);
