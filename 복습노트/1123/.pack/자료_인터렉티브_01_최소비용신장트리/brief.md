# 1123 최소 비용 신장 트리

같은 그래프에서 Kruskal과 Prim이 다음 간선 후보를 어디에서 찾는지 비교한다. Kruskal에서는 간선 검사·두 연결 요소 비교·채택 또는 제외를 따라간다. Prim에서는 시작 정점 a로부터 트리의 경계 간선을 확인하고, 간선과 바깥 정점이 함께 들어오는 것을 관찰한다.

- 강의 입력은 정점 a–g와 비용이 있는 무방향 간선 9개다. 두 알고리즘의 선택 순서가 달라지고 결과 간선 집합은 같아진다.
- 보충 동률 입력은 a–b의 비용을 29에서 27로 바꾼다. Kruskal은 같은 비용에서 강의 예제 목록 순서, Prim은 트리 안 끝점과 바깥 끝점의 알파벳 순서를 사용한다. 이 규칙으로 한 간선이 다른 두 MST가 나온다.
- 강의록 S10 pp.22–24의 Kruskal 선택과 union-find를 짧은 의사코드로 다시 썼다. 연결 요소를 합치는 시점까지 추적한다. 집합 내부의 부모 배열은 실행 모델에만 쓰며 화면에서는 연결 요소를 보여 준다.
- S10 pp.25–27의 Prim 규칙을 따른다. p25는 27과 29의 대소 관계를 서술하는 문장에 오기가 있어 실제 가중치 27 < 29와 그림의 선택을 따른다. p26의 반복 조건은 추가한 간선이 |V|−1개 모이는 시점과 동치인 정점 종료 조건으로 썼다. 선택 간선도 반환 대상으로 기록한다.
- 두 방법은 연결된 가중 무방향 그래프에서 최소 비용을 보장한다. 이 조건은 음성 전사의 최적성 설명과 차이가 있으며 1123 정리노트의 비교 절을 따른다.
- 출처 경로, 페이지, SHA-256은 source.json에 있다. 자료는 의사코드다. 독립 Python 검산은 각 단계의 후보·채택 상태를 확인하고 6개 간선 조합을 전수 비교한다.
