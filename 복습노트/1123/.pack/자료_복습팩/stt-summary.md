## 1. 최소 비용 신장 트리와 탐욕법 복습 (Part 01–03, 시각 미제공)

- 연결 무방향 그래프의 신장 트리(spanning tree)는 모든 정점을 연결하고 사이클이 없다. 정점이 $n$개이면 모든 신장 트리의 간선 수는 $n-1$이다. 최소 비용 신장 트리(MST, minimum spanning tree)는 그중 간선 가중치 합 $\sum_{e\in T}w(e)$가 최소인 트리다. 바로 전 수업에서는 신장 트리와 MST의 응용, Kruskal·Prim 이름, 탐욕법과 산길 비유까지 소개했고 알고리즘 설명은 이번 시간으로 미뤘다.
- 탐욕적 방법(greedy method), 교수 표현으로 ‘욕심쟁이 방법’은 매 단계에서 가능한 선택 중 그 시점의 최선으로 보이는 것을 고르는 설계 기법이다. 이 선택이 전역 최적해를 주는지는 문제별로 검증한다.
- [슬라이드 외] 산 오르기(hill climbing)에서는 매번 높아지는 방향으로만 가면 이웃보다 높은 곳에서 멈춘다. 더 높은 봉우리를 가려면 내려갔다가 올라가야 할 수 있으므로 지역 최적(local optimum)이 전역 최적(global optimum)일 필요는 없다. 가장 맛있는 음식을 먼저 먹는 비유로도 지금 선택할 수 있는 최선이라는 뜻을 설명했다. 관심 있는 AI 프로젝트와 연구실의 컴파일러 이론을 결합해 프로그램 유사성 검사 연구를 한 일화도 같은 선택 방식을 설명하는 데 사용했다.
- [슬라이드 외] 분할 정복(divide-and-conquer)은 문제를 작은 문제로 쪼개 해결하는 방법이다. 병합 정렬(merge sort)과 퀵 정렬(quick sort)을 예로만 들었다.
- “욕심쟁이 방법은 알고리즘 설계에 있어서 굉장히 중요한 기법 중의 하나고” (Part 01)
- “탐욕적인 방법은 항상 최적의 해답을 주는지를 반드시 검증해야 되는데요.” (Part 01)
- “반드시 검증해야 된다, 그리고 크루스칼(Kruskal)의 알고리즘은 항상 최적의 해답을 주는 것으로 증명이 되어 있습니다.” (Part 01)
- “최적의 해답을 주면 반드시 트레이드오프(trade-off)가 있습니다.” (Part 01, 뒤의 도로 건설 순서와 장비 이동 비용 설명에 이어짐)

## 2. Kruskal과 union-find (Part 03–04, 시각 미제공)

- 간선을 가중치 오름차순으로 정렬하고 선택된 간선 집합 $E_T$를 공집합으로 시작한다. 모든 정점을 하나의 트리로 연결할 때까지 작은 간선부터 검사한다. 사이클이 생기지 않는 간선만 추가하고 $|V|-1$개가 되면 멈춘다. 시작 정점을 지정하지 않으며 중간에는 여러 연결 요소가 있을 수 있다.
- S10 p23 추적은 채택 순서 $(a,f):10\to(c,d):12\to(b,g):15\to(b,c):16\to(d,e):22\to(e,f):27$이다. $(d,g):18$과 $(e,g):25$는 두 끝점이 이미 같은 연결 요소에 속한다. $(a,b):29$는 채택이 끝난 시점에 사이클을 만드는 간선이라고 구두로 확인했다. 선택된 가중치 합은 $10+12+15+16+22+27=102$다.
- S10 p24의 union-find는 두 끝점이 속한 집합을 비교해 사이클을 판정한다. 같은 집합이면 간선을 건너뛰고 서로 다른 집합이면 간선을 채택한 뒤 두 집합을 합친다.
- 알고리즘의 목적·입력·출력을 먼저 쓰면 발표나 보고서에서 읽기 쉽다고 설명했다. 수업에서 읽은 것은 S10 p22의 의사코드다.

```text
// 최소비용 스패닝트리를 구하는 Kruskal의 알고리즘
// 입력: 가중치 그래프 G=(V,E)
// 출력: E_T, 최소비용 신장 트리를 이루는 간선들의 집합
kruskal(G)

  E를 w(e_i₁) ≤ … ≤ w(e_iₘ)이 되도록 정렬한다.
  E_T←Φ; ecounter←0
  k←0
  while ecounter < |V|−1 do
      k←k+1
      if E_T∪{e_iₖ}이 사이클을 포함하지 않으면
          then E_T←E_T∪{e_iₖ}; ecounter←ecounter+1
  return E_T
```

- 🕳️ 미룬 유도: union-find 전체 구현은 “책에 유니온 파인드 알고리즘 전체 코드 이런 거 다 있습니다.”라고 안내했다. Kruskal의 최적성은 증명된 성질로 언급했고 증명과 시간복잡도 분석은 전사에서 확인되지 않는다.

## 3. Prim과 두 MST 알고리즘의 차이 (Part 04, 시각 미제공)

- 시작 정점 $s$를 정하고 $V_T=\{s\}$에서 출발한다. 현재 트리 내부의 정점과 외부 정점을 잇는 간선 중 가중치가 가장 작은 것을 골라 바깥 정점을 편입한다. 이때 현재 트리의 모든 정점에서 바깥으로 나가는 간선을 후보로 삼는다. 채택 간선이 $|V|-1$개가 될 때까지 한 연결 트리를 확장한다.
- S10 p25·27에서 $a\to f\to e\to d\to c\to b\to g$ 순으로 편입한다. 채택 간선은 $af(10),fe(27),ed(22),dc(12),cb(16),bg(15)$이며 합은 $102$다. $a,f$가 이미 들어갔을 때 후보 $ab(29)$와 $fe(27)$ 중 $fe$를 고른다. 이 예제의 결과 간선 집합은 Kruskal과 같다.
- [슬라이드 외] 교수는 노란 정점 집합을 ‘내 땅’으로 비유했다. 도로 공사에서는 연결된 구간을 연속해서 건설하면 이미 깐 도로로 장비를 옮길 수 있다. 서로 떨어진 저비용 간선을 먼저 고르는 순서라면 별도의 장비 이동 비용이 생길 수 있다는 설명이었다.
- 수업에서는 S10 p26의 정점 집합 의사코드를 보여 주며 Kruskal의 $E_T$와 Prim의 $V_T$의 초기화를 비교했다. 아래는 슬라이드의 표기이며 카운터 조건 오기는 끝의 정정 항목 참조.

```text
// 최소 비용 신장 트리를 구하는 Prim의 알고리즘
// 입력: 네트워크 G=(V,E), s는 시작 정점
// 출력: V_T, 최소 비용 신장 트리를 이루는 정점들의 집합
Prim(G, s)

  V_T←{s}; vcounter←0
  while vcounter < |V| do
      (u,v)는 u∈V_T and v∉V_T인 최저 비용 간선;
      if (그러한 (u,v)가 존재하면)
          then V_T←V_T∪v; vcounter←vcounter+1
      else 실패
  return V_T
```

- “자 차이점을 확실히 알았을 거예요.” (Part 04)
- p28의 우선순위 큐, `distance[]`, `delete_min(Q)`와 시간복잡도는 전사에서 확인되지 않는다.

## 5. 위상 정렬과 정렬 영상 안내 (Part 05, 시각 미제공)

- 위상 정렬(topological sort)은 방향 그래프의 모든 정점을 나열하되 간선 $\langle u,v\rangle$마다 $u$를 $v$보다 앞에 두는 순서다. 하나의 그래프에서 가능한 순서가 여러 개일 수 있다. S10 p35에서 수강 순서를 예로 들었다.
- S10 p35–36의 선수 과목 관계는 $0\to2,0\to3,1\to3,1\to4,2\to3,2\to5,3\to5,4\to5$다. 처음에는 0과 1만 선택할 수 있다. 0을 지우면 1과 2가 후보이고 이어서 1을 지우면 2와 4, 2를 지우면 3과 4가 후보다. 교수의 예시 순서 $(0,1,2,3,4,5)$와 $(1,0,2,3,4,5)$ 모두 가능하고, p36 그림은 $(1,4,0,2,3,5)$를 나타낸다. $(2,0,1,3,4,5)$는 $0\to2$를 어긴다.
- 선행 정점이 없는 정점(진입 차수 0)을 하나 골라 출력하고 그 정점과 나가는 간선을 제거한다. 남은 정점에 같은 절차를 반복한다. 정점이 남아 있는데 모두 선행 정점을 가진다면 사이클이 있어 정렬이 불가능하다. 교수는 반복을 구두로 ‘재귀적’이라고 표현했고 슬라이드 의사코드는 for 루프 형식이다. 큐·C 구현과 시간복잡도 분석은 전사에서 확인되지 않는다.

```text
Input: 그래프 G=(V,E)
Output: 위상 정렬 순서

topo_sort(G)

for i←0 to  do
        if( 모든 정점이 선행 정점을 가지면 )
                then 사이클이 존재하고 위상 정렬 불가;
        선행 정점을 가지지 않는 정점 v 선택;
        v를 출력;
        v와 v에서 나온 모든 간선들을 그래프에서 삭제;
```

- “모든 정점이 선행 정점을 가진다면 안 돼요. 반드시 선행이 없는 거 하나가 있어야 얘가 제거가 되겠죠.” (Part 05)
- “오늘 과제도 여기서 출제가 될 거고요.” (Part 05)
- “두 개의 동영상이 올라올 테니까 소팅 반드시 듣고 오시고요.” (Part 05)
- “소팅이 그냥 단순히 정렬이다라고 하는 하고 보면 안 되고요. 여러분들이 복잡도(complexity)에 대한 고려나 뭐 이런 것들을 어 잘 생각할 수 있게 해주는 챕터예요.” (Part 05)
- 🕳️ 미룬 유도: 정렬과 분할 정복은 11/26 수업 영상으로 먼저 보고 다음 주 월요일 그래프를 마친 뒤 요약한다고 했다. Part 05의 “그 부분도 뭐 중요하지 않은 거는 어느 챕터도 없습니다.”도 이 안내에 이어 나온 발언이다.

## 말실수 정정

- “프림(Prim)은 줄 수도 있고 안 줄 수도 있습니다.” (Part 01, Part 04에서도 반복) → 표준 Prim과 Kruskal은 연결된 무방향 가중 그래프에서 모두 MST를 보장한다. 간선 가중치 동률에서 선택 순서에 따라 두 결과의 간선 집합은 달라질 수 있고 전체 비용은 같다. 장비 이동비를 별도로 도입하면 목적함수가 바뀐다.
- S10 p25 말풍선의 ‘27이 29보다 높다’ → $27<29$라서 $(f,e)$를 고른다. S10 p26의 `vcounter←0`은 시작 정점 이후 새로 추가한 정점 수를 센다. 이에 맞는 종료는 `vcounter < |V|−1` 또는 $|V_T|=|V|$에 도달하면 끝내는 것이다.
- 위상 정렬에서 “4는 2를 들어야 돼요.” 및 중간 후보 관련 즉흥 설명 → S10 p35의 표와 p36 그림에 따르면 4의 선수는 1이다. 0을 먼저 제거한 직후 후보는 1과 2이고, 1까지 제거하면 2와 4가 남는다. 1을 먼저 제거하면 0과 4, 그 뒤 0을 제거하면 2와 4가 후보다.
- S10 p37의 `for i←0 to  do`는 상한이 빠진 슬라이드 표기다. 정점이 남아 있는 동안 반복하며, 남은 그래프에서 선행 정점이 없는 정점을 못 찾으면 사이클로 종료한다.
- “5개를 또 2.5, 2.5로 나눠서”는 분할 설명 중의 반올림 전 표현이다. 예를 들어 원소 5개의 병합 정렬 분할은 2개·3개가 된다. Part 04의 가중치 “8, 20... 아, 18”은 발언 중 18로 바로잡았다. S10 p20의 `minimu spanning tree`는 `minimum spanning tree`가 맞다.
