# 1123 위상 정렬과 진입 차수

선수 과목 그래프에서 어떤 정점을 먼저 출력할 수 있고, 언제 정렬이 막히는지 확인한다. 각 간선 제거 단계에서 도착 정점의 진입 차수와 다음 후보가 함께 갱신된다. 이미 선택한 정점은 별도 강조하고, 그렇게 선택해 처리 중인 정점은 다음 후보에서 뺀다.

- 번호순 선택은 p35의 0, 1, 2, 3, 4, 5를 따른다. 강의 그림 순서는 p36의 1, 4, 0, 2, 3, 5를 따른다. 두 규칙은 진입 차수가 0인 정점만 선택한다.
- 보충 사이클 사례는 정리노트의 예처럼 5 → 0을 추가한다. 1과 4를 출력한 뒤 0, 2, 3, 5가 남으며 각각의 진입 차수는 1, 1, 2, 2다. 0 → 2 → 5 → 0을 강조한다.
- p37 의사코드의 비어 있는 반복 상한은 남은 정점 조건으로 보완했다. 정점과 나가는 간선의 제거를 여러 단계로 펼쳤다. 방금 제거한 화살표는 점선으로 한 단계만 표시하며 이미 진입 차수 계산에서 빠져 있다.
- 출처 경로, 페이지, SHA-256은 source.json에 있다. 자료는 의사코드다. 독립 Python 검산은 간선 하나가 제거될 때마다 차수를 다시 세고 정상 출력의 모든 선수 관계를 검사한다.
