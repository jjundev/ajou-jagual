# 내용 검토 · 위상 정렬과 진입 차수

- S10 pp.35–37의 선수 과목 표, 그래프, 제거 그림과 의사코드를 슬라이드 이미지에서 읽었다. 표와 그림에서 4의 선수 과목은 1이며, 전사와 달라 정리노트처럼 표의 1 → 4를 따른다.
- 줄 1–3의 검사는 남은 정점이 있을 때 적용한다. 처음 진입 차수는 (0,0,1,3,1,3)이다. 0을 먼저 고른 사례에서는 0 → 2를 없앨 때 2의 차수가 1에서 0으로 줄고, 0 → 3을 없앨 때 3은 3에서 2로 줄어 여전히 기다린다.
- 줄 4는 선택 정점 하나를 한 번만 출력한다. 이어서 줄 5는 그 정점에서 나가는 간선만 하나씩 지운다. 차수는 지워진 간선 수만큼 도착 정점에서 줄어든다. 줄 6에서는 간선을 모두 지운 뒤 선택 정점을 남은 집합에서 뺀다. 두 정상 사례 모두 줄 7에서 완료한다.
- 5 → 0을 추가한 보충 사례는 1, 4 이후 후보가 없어서 줄 2에서 끝난다. 남은 0, 2, 3, 5 모두 진입 차수가 양수다. 부분 출력과 사이클이 실패 화면에서 함께 보인다.
