무엇을 구하나요?

간선을 가벼운 순으로 살피며 선택·제외와 최종 비용을 추적해요. 두 제외 간선은 검사 순간의 연결 집합으로 설명해요.

  • 정점 7개 · 처음엔 모두 별개
  • 선택을 할 때만 두 집합을 합침

이 문제를 봤을 때 떠올릴 개념과 공식

단서개념과 적용 이유
가중치가 주어짐 Kruskal은 전체 간선을 오름차순으로 검사해요.
처음엔 정점별 집합 분리 집합(union-find)의 find로 두 끝의 연결 상태를 읽고, 다를 때 union해요.
정점 7개 합치기 6번이면 집합이 하나가 돼요. 간선을 검사한 횟수와 선택한 횟수를 따로 세요.

종이에 적을 첫 줄

초기 집합은 {A} {B} {C} {D} {E} {F} {G}이고 첫 검사 간선은 AF(10)이에요.

왜 이렇게 푸는지 함께 따라가요

(a) 표의 집합은 각 간선을 검사한 직후 상태예요. 같은 집합이면 상태를 유지해요.

검사 간선판정검사 뒤 연결 집합
AF(10) 선택 AF / B / C / D / E / G
CD(12) 선택 AF / B / CD / E / G
BG(15) 선택 AF / BG / CD / E
BC(16) 선택 AF / BCDG / E
DG(18) 제외 AF / BCDG / E
DE(22) 선택 AF / BCDEG
EG(25) 제외 AF / BCDEG
EF(27) 선택 ABCDEFG

EF(27)에서 여섯 번째 간선을 채웠으므로 AB(29)는 검사 전에 남겨 둬요. 채택 순서 AF, CD, BG, BC, DE, EF · 제외 DG, EG · 합 102예요.

(b) DG를 검사할 때 D와 G는 둘 다 {B,C,D,G}예요. 이미 D–C–B–G가 있어 DG를 닫으면 순환해요. EG를 검사할 때는 DE가 먼저 들어왔으므로 E와 G가 {B,C,D,E,G}에 있어요. 기존 경로는 E–D–C–B–G예요.

완성 답과 검산

(a) 결과 간선을 다른 순서로 읽으면 A–F–E–D–C–B–G라는 단일 경로예요. 정점 7개를 한 번씩 지나고, 반씩 더해도 $(10+12+15)+(16+22+27)=37+65=102$예요.

(b) DG에서 되돌아오는 경로의 간선 CD, BC, BG는 모두 그전에 골랐어요. EG에서 필요한 DE도 22에서 이미 들어왔어요. 따라서 두 사이클의 모든 경로 간선은 각 검사 시점에 실제로 존재해요.

헷갈리는 지점

  • 검사한 간선 수로 종료하면 DE를 검사한 여섯 번째 단계에서 멈춰요. 이때 채택은 5개뿐이고 AF와 BCDEG가 따로 남아요.

해설을 가리고 다시 풀어요

  • 간선 옆에 두 끝의 현재 집합을 나란히 적어요.
  • 간선을 채택했을 때만 채택 수를 올리고, 6이 되는 줄에 종료 표시를 해요.

선택과 종료

오름차순으로 검사해 집합이 다른 끝만 합쳐요. EF가 여섯 번째 채택이고 합은 102예요.

사이클

DG는 D–C–B–G, EG는 E–D–C–B–G가 이미 있어서 제외해요.
