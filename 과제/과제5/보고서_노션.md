## read_graph

<table header-row="true">
<tr><td>소스코드</td><td>기능 명세와 분석</td></tr>
<tr>
<td>int read_graph(ProcessGraph \*graph) \{<br>  int edge_count;<br>  int i;<br>  int from, to;<br><br>  \*graph = (ProcessGraph)\{0\};<br>  if (scanf("%d %d", &graph-\>n, &edge_count) != 2 \|\| graph-\>n \< 1 \|\|<br>      graph-\>n \> MAX_PROCESSES \|\| edge_count \< 0 \|\|<br>      edge_count \> graph-\>n \* (graph-\>n - 1) / 2) \{<br>    return 0;<br>  \}<br><br>  for (i = 0; i \< edge_count; i++) \{<br>    if (scanf("%d %d", &from, &to) != 2 \|\| from \< 0 \|\| from \>= graph-\>n \|\|<br>        to \< 0 \|\| to \>= graph-\>n \|\| from == to \|\|<br>        graph-\>adjacency_matrix\[from\]\[to\] != 0) \{<br>      return 0;<br>    \}<br>    graph-\>adjacency_matrix\[from\]\[to\] = 1;<br>  \}<br>  return 1;<br>\}</td>
<td>#분석<br>• 그래프를 0으로 초기화하고 프로세스 수와 간선 수를 읽는다. 입력 순서쌍마다 출발 PID를 행, 도착 PID를 열로 하여 해당 칸에 1을 저장한다.<br>• 입력 검사에 걸리면 0, 주어진 간선을 모두 기록하면 1을 돌려준다.</td>
</tr>

<tr>
<td>void topological_sort(const ProcessGraph \*graph, int order\[\]) \{<br>  int indegree\[MAX_PROCESSES\] = \{0\};<br>  int completed\[MAX_PROCESSES\] = \{0\};<br>  int step;<br>  int pid;<br><br>  calculate_indegree(graph, indegree);<br>  for (step = 0; step \< graph-\>n; step++) \{<br>    pid = select_next_process(graph, indegree, completed);<br><br>    if (pid == -1) \{<br>      printf("STATE_ERROR\\n");<br>      exit(1);<br>    \}<br><br>    order\[step\] = pid;<br>    complete_process(graph, pid, indegree, completed);<br>  \}<br>\}</td>
<td>#분석<br>• indegree와 completed를 0으로 초기화한 뒤 각 PID의 초기 진입 차수를 계산한다.<br>• 매 단계 실행 가능한 PID를 구해 order에 저장하고, 완료 상태와 후속 PID의 진입 차수를 갱신한다. 다음 단계는 이 갱신을 반영한 상태에서 시작한다.</td>

## calculate_indegree (구현)

<table header-row="true">
<tr><td>소스코드</td><td>기능 명세와 분석</td></tr>
<tr>
<td>void calculate_indegree(const ProcessGraph \*graph, int indegree\[\]) \{<br>  for (int row = 0; row \< graph-\>n; row++) \{<br>    for (int col = 0; col \< graph-\>n; col++) \{<br>      if (graph-\>adjacency_matrix\[row\]\[col\] == 1) \{<br>        indegree\[col\]++;<br>      \}<br>    \}<br>  \}<br>\}</td>
<td>#기능 명세<br>• 인자: 그래프와 진입 차수 배열 / 반환값: 없음<br>• 상태 변경: indegree에 각 PID로 들어오는 간선 수를 누적한다.<br><br>#분석<br>• 진입 차수는 한 PID로 들어오는 간선의 수다. 행에서 열로 간선이 있으면 도착점인 열의 값을 올린다. 예를 들어 0 → 2를 만나면 P2의 선행 프로세스가 하나 추가되므로 indegree\[2\]를 증가시킨다.</td>
</tr>
</table>

<table header-row="true">
<tr><td>소스코드</td><td>기능 명세와 분석</td></tr>
<tr>
<td>int select_next_process(const ProcessGraph \*graph, const int indegree\[\],<br>                        const int completed\[\]) \{<br>  for (int i = 0; i \< graph-\>n; i++) \{<br>    if (indegree\[i\] == 0 && completed\[i\] == 0) \{<br>      return i;<br>    \}<br>  \}<br>  return -1;<br>\}</td>
<td>#기능 명세<br>• 인자: 그래프, 진입 차수 배열, 완료 여부 배열 / 반환값: 선택한 PID 또는 후보가 없을 때 -1<br>• 상태 변경: 없음<br><br>#분석<br>• 진입 차수가 0이고 아직 완료되지 않은 PID만 선택할 수 있다. PID 0부터 검사해 조건을 처음 만족한 값을 반환하면, 현재 실행 가능한 후보 중 가장 작은 PID가 선택된다.</td>

# 실행결과 분석

## 여러 선행 관계가 있는 그래프

**입력**

```text
6 8
0 2
0 3
1 3
1 4
2 3
2 5
3 5
4 5
```

**실제 출력**

```text
ORDER 0 1 2 3 4 5
```

**실제 터미널 실행 화면**

![](터미널_스크린샷/01-공식예시-7쪽.png)

**결과 분석**

P3의 초기 진입 차수는 P0, P1, P2에서 들어오는 간선 세 개로 결정된다. P0·P1을 완료한 뒤에도 P3은 P2를 기다리며, P2가 완료된 뒤에야 P3의 진입 차수가 0이 되어 다음에 선택된다.

## 선행 관계가 한 줄로 연결된 그래프

**입력**

```text
4 3
3 1
1 0
0 2
```

**실제 출력**

```text
ORDER 3 1 0 2
```

**실제 터미널 실행 화면**

![](터미널_스크린샷/02-공식예시-10쪽-왼쪽.png)

**결과 분석**

처음에는 P3만 진입 차수가 0이다. P3의 완료로 P1이 실행 가능해지고, 같은 방식으로 P0과 P2가 차례로 실행 가능해진다.

## 동시에 실행 가능한 PID가 있는 그래프

**입력**

```text
6 3
0 2
2 4
1 3
```

**실제 출력**

```text
ORDER 0 1 2 3 4 5
```

**실제 터미널 실행 화면**

![](터미널_스크린샷/03-공식예시-10쪽-오른쪽.png)

**결과 분석**

P0을 완료하면 후행 프로세스 P2의 진입 차수가 1에서 0으로 줄어든다. 그 시점에 P1과 P2가 모두 실행 가능하며, PID가 더 작은 P1이 먼저 선택된다.
