# 과제1 산출물 경로와 출처

이 문서는 2026-09-26에 확인한 로컬 파일과 스킬·스크립트의 출력 경로를 기록한다. 파일의 형태만으로 생성 스킬을 단정하지 않는다.

| 파일 | 현재 위치 | 확인된 출처·역할 |
|---|---|---|
| `HW1.pdf`, `과제 채점기준.pdf`, `HW1_skeleton.c` | 과제1 최상위 | 과제 입력 자료 |
| `보고서.md`, `보고서_노션.md` | 과제1 최상위 | 로컬 보고서와 Notion 현재 다운로드. 후자는 `notion-report-sync`의 `pull` 대상 |
| `보고서_노션-backup-*.md` | `검토자료/노션_백업/` | `notion-report-sync/scripts/notion_report.py`와 과거 HW1 전용 `검토자료/notion_sync.py`가 변경 전 다운로드를 보존할 때 생성. 개별 파일마다 어느 명령이 만들었는지는 확인되지 않음 |
| `notion_api/` 및 검토 JSON | `검토자료/` | Notion 변경 전 상태와 실행 검토 기록 |
| `01`~`08` PNG | `터미널_스크린샷/` | 실행 증빙. `terminal-evidence-capture` 스킬의 산출물 형태와 맞지만 개별 PNG의 생성 명령은 확인되지 않음 |
| `HW1-eli5.html` | `학습자료/` | 학습용 설명 자료. 생성 스킬은 확인되지 않음 |
| `본인작성과_이해도_점검기준.md` | `검토자료/` | 보고서 검토 기준. 생성 스킬은 확인되지 않음 |
| `HW1`, `HW1.dSYM/` | `검토자료/보관/` | 기존 실행 파일과 디버그 산출물. 새 실행 증빙은 임시 위치에서 빌드 |
| `표지.pdf` | 과제1 최상위 | 표지 제작 결과. 현재 `assignment-report-merge`가 이 경로를 입력으로 사용하며, 새 표지는 `assignment-cover`로 생성 가능 |
| `HW1.c`, PDF 두 개 | `제출용/` | 제출 후보. 두 PDF의 관계와 최종 선택은 파일명만으로 확인되지 않아 모두 보존 |

앞으로 Notion 다운로드의 현재본은 `보고서_노션.md`, 변경 전 백업은 `검토자료/노션_백업/`에 저장한다. 공통 동기화 스크립트의 `--backup-dir`로 다른 경로를 지정할 수 있다. 표지와 병합 PDF는 기존 스킬이 사용하는 경로에 둔다. 터미널 증빙을 위한 새 실행 파일은 과제1 최상위가 아닌 임시 위치에 빌드한다.
