# 과제02 노션 서식 적용 확인

과제1의 실제 노션 페이지와 과목 기본 양식을 비교하여 과제2 페이지에 서식을 적용했다.

- 과제1 확인값: 기본 글꼴, 작은 텍스트 끔, 전체 너비 켬. 과제1은 수정하지 않았다.
- 과제2: 동일한 설정을 적용했고 웹 페이지 새로고침 후에도 전체 너비 켬과 작은 텍스트 끔을 확인했다. 기본 글꼴 선택도 화면에서 확인했다.
- 대단원 사이 빈 블록 2칸, 같은 대단원의 소단원 사이 1칸, 첫 소단원 앞 추가 빈 블록 없음. 총 23개 빈 블록을 추가했다. 기존 목차 다음 빈 블록 1칸은 유지했다.
- 입력·실제 출력·실행 화면의 반복 제목 18개를 굵은 일반 문단으로 변경했다. 목차에는 제목 1·2에 해당하는 대단원·소단원 23개가 남는다.
- 함수별 좌측 코드·우측 설명의 표 13개, 코드 행 20개, 실행 이미지 6개, 전체 소스 부록과 다른 본문 문구는 유지했다. 변경 전후 블록과 자식 블록을 대조했다. 노션 이미지의 서명 URL·만료 시각 갱신은 콘텐츠 변경에서 제외했다.
- 서식 적용 전 전체 블록과 Markdown은 notion_api/formatting/before.json 및 before.md에 보존했다. 기존 블록 전체를 교체하지 않고 반복 제목과 빈 블록만 대상으로 수정했다.
- 이전 노션 Markdown 다운로드와 현재 다운로드: 제목 3이 굵은 문단으로 바뀌고 빈 블록 간격이 추가된 차이다. 변경된 이전 다운로드를 검토자료/노션_백업에 보존한 뒤 보고서_노션.md를 갱신했다.
- 로컬 보고서 초안과 현재 노션 다운로드: 위 서식 차이 외에 목차·코드 표·이미지 URL의 노션 직렬화 차이가 있다. 로컬 원고와 PDF는 갱신하지 않았다.
- 노션 PDF 내보내기는 아직 수행하지 않았다. A4 가로·페이지 번호 없음·실제 PDF 표 배치 확인은 내보내기 시 별도로 검사해야 한다.
