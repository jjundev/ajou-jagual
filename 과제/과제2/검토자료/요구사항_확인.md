- 사용자가 별도 Antigravity IDE 앱의 내장 터미널을 지정했다. `com.google.antigravity-ide` 앱에 새 터미널 창을 만들고 그 창에서만 캡처했다. Antigravity 2.0 앱이나 macOS Terminal 앱의 화면을 실행 증빙으로 사용하지 않았다.
- 현재 HW2.c를 별도로 빌드한 임시 실행 파일로 대표 사례 6건을 다시 실행했다. 전체 크기·명령 개수·각 명령을 한 줄씩 입력하고 입력 뒤 UI 상태를 확인했다. 실제 입력과 출력 및 프로세스 종료 코드 0을 캡처했다.
- 실제 대화 로그 6건에서 입력 순서·명령 결과·모든 메모리 지도를 기존 기록과 비교해 일치함을 확인했다. 빌드 명령·소스 및 실행 파일의 SHA-256·터미널 대화·캡처 경로는 `터미널_캡처기록.json`에 보관했다.
- 화면은 `../터미널_스크린샷/`에 PNG 6장으로 저장했다. 도구가 반환한 JPEG 원본과 픽셀이 같은 PNG 사본은 `원본/`에 함께 보존했다. 크롭 스크립트로 창 장식·빈 여백만 제거하고 원본 사본의 해당 영역과 픽셀 일치를 검증했다. 텍스트·결과·입력은 수정하지 않았다.

- 산출물: `../보고서_초안.md`, `../보고서_초안.html`, `../보고서_초안.pdf`.
- 과제1 보존 제출 PDF의 2·3·6·10쪽과 편집용 Markdown을 참고했다. A4 가로, 함수별 좌우 코드·분석, 입력·실제 출력·상태 변화 분석의 구조를 적용했다. 기존 과제1 파일은 수정하지 않았다.

- 현재 소스를 다시 검증한 기록은 `실행기록_보고서.json`이다. 32/32건 통과했으며 현재 코드의 SHA-256과 일치한다. 본문에는 공식 예제 3건과 추가 사례 3건, 총 6건을 수록했다. 수록 입력·실제 출력이 PDF에서 추출되고 실행 기록과 일치함을 확인했다.
- Mac용 전체 코드 부록은 HTML DOM에서 현재 소스와 정확한 텍스트 일치를 확인했다. PDF에서는 레이아웃에 의한 공백·줄바꿈을 제외하고 전체 소스 텍스트가 일치했다.

- 작성자 이해: 선택형 핵심 개념 질문에 정답을 선택했으나 자유 서술 설명은 확보하지 못했다. 선택한 권장 답안을 독립적인 설명·직접 저작의 증거로 간주하지 않는다. 반복 인터뷰를 추가하지 않고 이 상태를 미확인으로 유지했다.

## 2026-10-24 기록: 참고 구현 작성 후

- `../HW2.c`를 별도로 작성했다. Codex가 작성한 참고 구현임을 파일 머리말에 명시했다. 이 파일의 실행 성공을 학생의 직접 구현·이해 확인으로 간주하지 않는다.
- 원본 스켈레톤은 유지했다. 원본과 비교하여 학생 구현 함수 5개의 본문 및 출처 머리말 외에는 제공 코드·매크로·구조체·함수 형식이 동일함을 확인했다. 추가 함수는 없다.
- `verify_hw2.py`를 먼저 작성하고 제공 스켈레톤에 실행했다. 32건 중 명령이 없는 사례만 통과했고 31건이 미구현으로 실패했다. 이 최초 기록은 `/tmp/hw2-skeleton-baseline.json`에 있으며 임시 파일이다.
- 현재 `HW2.c` 검증은 `실행기록.json`에 저장했다. 기록에서 계산한 결과는 32/32 통과다: 공식 예제 3건, 명명한 경계·분기 사례 8건, 시드별 80명령 시퀀스 20건, 할당 실패·링크 확인 하네스 1건. 테스트 수는 과제 요구가 아닌 이번 검증 범위다.
- 검증 빌드: Apple clang, C11, `-Wall -Wextra -Wpedantic -fsanitize=address,undefined -g`. 컴파일 및 실행 진단은 없었다. 별도로 sanitizer 없는 `-Werror` 빌드도 성공했다. 세부 환경·현재 소스 SHA-256·사례 입력·실제 출력·종료 코드는 JSON에 있다.
- 명령 시퀀스는 독립적인 주소별 배열 모델과 매 명령 결과·메모리 지도를 대조했다. 하네스는 새 분할 노드 생성 실패 시 기존 블록과 링크 유지, 정확한 크기에서는 새 노드 생성 없이 할당, 병합 후 원형 양방향 링크를 확인했다. malloc 실패는 테스트 하네스에서만 주입했고 실제 메모리 고갈을 관측한 것은 아니다.
- 입력 계약 안의 양의 정수로 검증했으며, 모든 가능한 입력·다른 OS·정수 범위를 벗어난 입력의 동작을 검증한 것은 아니다. 공식 조건 밖 입력에 대한 일부 방어 조건은 전체 입력 검증을 보장하지 않는다.
