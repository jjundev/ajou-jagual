# 과제02 노션 업로드 확인

- 페이지: [HW2: 프로세스 메모리 관리 보고서](https://app.notion.com/p/HW2-404b06d263bc81cdb588d36e59ca3a77)
- 위치: 과제1과 같은 자구알 26-2 상위 페이지 아래에 새 페이지 생성. 과제1 페이지는 변경하지 않았다.
- 편집 가능한 본문 블록: 122개. 제목·목차·설명·표·입력/출력·전체 코드 부록 포함.
- 코드·분석 표: 13개, 코드 행 20개. 읽어 온 셀의 선행 U+00A0를 ASCII 공백으로 바꾸면 현재 소스 조각과 정확히 일치한다. 코드 셀의 inline-code 주석은 없음을 확인했다.
- 실제 실행 이미지: 6개. 업로드 후 노션의 파일 URL에서 다시 내려받아 해당 PNG와 픽셀 일치를 확인했다.
- 전체 소스 부록: 현재 HW2.c와 정확한 텍스트 일치 확인.
- 본문 전체를 블록별로 다시 읽어 업로드 계획의 텍스트·표 셀·순서와 비교했다.
- 노션 Markdown을 보고서_노션.md에 별도 저장했다. 최초 다운로드이므로 이전 다운로드와의 비교는 없다. 로컬 원고와의 차이는 목차 직렬화, 표 셀의 줄바꿈·들여쓰기, 로컬 이미지 경로에서 노션 호스팅 이미지로의 전환 등 노션 표현의 차이다. 로컬 원고를 노션 다운로드로 덮어쓰지 않았다.
- 작성자 직접 작성 설명과 AI 참고 설명의 구분 고지를 유지했다.
- 노션에서 PDF 내보내기는 아직 수행하지 않았다. 기존 로컬 보고서_초안.pdf는 로컬 HTML에서 생성한 파일이다.
- 아주BB 제출 및 표지 병합은 수행하지 않았다.

상세 근거는 notion_api/manifest.json, upload-plan.json, remote-blocks.json에 있다. 인증 토큰은 환경 변수에서만 사용하며 기록에 저장하지 않았다.
