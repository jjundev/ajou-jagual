# 복습문제 전체 개편 검증 기록 — 2026-10-17

전체 10개 팩을 핵심 범위 충족 우선으로 재편했다. 기존 72문항 중 32문항을 유지하고 40문항을 제거·통합·교체했으며, 강의 예제 기반으로 직접 작성한 30문항을 넣어 최종 62문항으로 구성했다. 강의 코드·의사코드 예제가 28문항, 강의 그림을 코드로 옮겼다고 명시한 자체 문제가 2문항이다.

1001은 배열 리스트 삽입·삭제의 이동 방향, 경계, 실행 추적, 복잡도를 두 통합 문제로 다룬다. 1008도 스택의 핵심 평가 목표를 세 문제에 담았으며 수를 채우는 변형은 추가하지 않았다. 강의 예제에는 최댓값 탐색, 재귀, 배열·구조체·포인터, 리스트, 스택, 수식 처리, 큐 코드 등이 포함된다. 각 문제에는 실제 PDF 페이지·해시·수업 범위와 평가 목표를 연결했다.

전체 날짜의 같은 원문 계열, 본문, 코드 서명과 그림을 비교한 최종 검사에서 차단 중복 0건, 미판정 유사 후보 0건이다. 자동 유사도만으로 제거하지 않고 각 판정의 근거를 기록했다. 1012 p1은 push/pop 횟수와 마지막 결과의 보관을, p2는 중위식 변환 및 중간 스택 상태를 평가하므로 서로 다른 목표로 유지했다. 기존 72문항의 개별 처리와 새 번호 대응은 동명 JSON의 `packs[].old_card_mapping`에 있다.

복습문제 HTML·MD, 문제설명 HTML·MD와 문제·답안 PDF 20개를 모두 현재 문항에 맞게 발행했다. 정리노트·기존 그림·STT·강의록·기출 및 교과서 원자료는 개편 전 해시와 일치한다. 문제 번호가 바뀐 뒤 예전 풀이 완료 표시가 새 문제에 붙지 않도록 내용별 저장 키를 적용했다.

`ds-review-pack`에 `revise-existing` 절차와 전체 날짜 중복 검사, 강의 출처 계약, 핵심 범위 우선 원칙, 독립 검산, 문제설명·PDF 동시 갱신을 추가했다. 신규 생성과 기존 갱신에도 공통 검사를 요구한다. 검증기는 한글 NFC/NFD 경로, 질문 표현을 바꾼 코드 복제, 서로 다른 그림의 오인 판정을 회귀 검사한다. `ds-problem-explain`은 출처에 맞는 원문 표시를 지원한다.

검증 근거는 다음과 같다.

- 별도 검산자가 답과 해설을 보지 않고 62문항을 풀었으며, 조건을 명확히 한 6문항은 다시 독립 검산했다.
- C11 검증 코드를 경고를 오류로 취급해 컴파일하고 실행했다. 10개 팩의 `answers.py`도 모두 실행에 성공했다. 오류 진단용 코드의 정의되지 않은 동작은 정상 실행 사례에 포함하지 않았다.
- 실제 Chrome에서 리뷰 248회, 문제설명 372회의 화면·테마 조합을 검사했고 620개 화면을 직접 확인했다. 기존 완료 상태 무시, 새 상태의 새로고침 후 유지, 원문·힌트·풀이·탭도 확인했다.
- 문제·답안 PDF 142페이지를 전부 렌더링해 직접 확인했다. 실제 강의 출처 36페이지와 교과서·기출 출처 26페이지도 대조했다.
- 현재 산출물 재검사, 전체 중복 검사, 폴더 배치 검사, 스킬 형식 검사, `git diff --check`를 통과했다. 복습팩 전체 테스트 250개(추가 하위 검사 154개), 문제설명 전체 테스트 130개가 통과했다. 세부 결과는 동명 JSON의 `tests`와 첨부 로그에 있다. 미해결 사항은 없다.

독립 최종 리뷰에서 Critical 0건, Important 3건이 나왔다. 세 검증기 결함을 실패 테스트로 재현한 뒤 한 차례 수정하여 통과시켰다. 문항의 확인된 오답은 없었다. 세 수정은 NFD 경로 누락·빈 입력 통과 방지, 문장과 별도의 코드 유사도 검사, 그림을 반영한 동일성 판정이다.
