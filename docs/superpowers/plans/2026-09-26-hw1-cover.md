# 자료구조 과제 1 표지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 확인된 학번·이름을 넣은 A4 가로 표지 PDF 한 페이지를 만들고 렌더링·크기·텍스트 추출을 검증한다.

**Architecture:** ReportLab의 벡터 텍스트로 표지를 그린다. 한 번 실행할 생성 스크립트와 검사 코드는 `tmp/pdfs/hw1-cover/`에 두고 최종 산출물 `과제/과제1/표지.pdf`만 남긴다. 실제 학번·이름은 실행 시 환경변수로 받고 로그에 출력하지 않는다.

**Tech Stack:** Python 3, ReportLab, pypdf, Poppler (`pdfinfo`, `pdftotext`, `pdftoppm`, `pdffonts`), AppleGothic.ttf.

**Spec:** `docs/superpowers/specs/2026-09-26-hw1-cover-design.md`

## Global Constraints

- 출력은 `과제/과제1/표지.pdf` 한 파일이며 A4 가로 한 페이지다.
- 표기 문자열은 `[2026-2] 자료구조 및 알고리즘 이해`, `과제 1`, `Banker's algorithm`이다.
- 학번·이름이 없거나 `미제공`이면 생산용 PDF를 만들지 않는다.
- 페이지 번호, 제출일, 교수명은 넣지 않는다.
- Notion 본문, PDF 병합, 제출 작업은 수행하지 않는다.
- 현재 `과제/과제1/보고서.md` 7–8행은 실제 학번·이름이 아니므로 사용자에게 값을 받아야 한다.
- 기존 미추적 파일은 건드리지 않는다. 커밋은 범위에 포함하지 않는다.

## Review Focus

- `미제공` 학번 또는 이름: 생성 함수가 `ValueError`로 중단하고 출력 파일을 만들지 않아야 한다. Task 1 검사 1.
- 공백만 있는 학번 또는 이름: 같은 방식으로 중단해야 한다. Task 1 검사 1.
- 한글 이름: PDF의 텍스트 추출에서 원래 글자가 유지되어야 한다. Task 1 검사 2.
- 용지 방향·페이지 수 오류: 1페이지 A4 가로가 아니면 검사 실패. Task 1 검사 2.
- 글꼴 누락·글자 겹침: 임베딩 검사와 렌더링 육안 확인을 통과해야 한다. Task 1 검사 3–4.

```python
import tempfile
import unittest
from pathlib import Path

from pypdf import PdfReader
from create_cover import make_cover


class CoverTests(unittest.TestCase):
    def test_rejects_missing_identity_without_output(self):
        with tempfile.TemporaryDirectory() as directory:
            output = Path(directory) / "cover.pdf"
            for student_id, name in [("미제공", "홍길동"), ("123456789", "미제공"), ("  ", "홍길동"), ("123456789", " ")]:
                with self.assertRaises(ValueError):
                    make_cover(student_id, name, output)
                self.assertFalse(output.exists())

    def test_extractable_a4_landscape_one_page(self):
        with tempfile.TemporaryDirectory() as directory:
            output = Path(directory) / "cover.pdf"
            make_cover("123456789", "홍길동", output)
            reader = PdfReader(output)
            self.assertEqual(len(reader.pages), 1)
            page = reader.pages[0]
            self.assertAlmostEqual(float(page.mediabox.width), 841.89, delta=0.2)
            self.assertAlmostEqual(float(page.mediabox.height), 595.28, delta=0.2)
            content = page.extract_text()
            for expected in ("[2026-2] 자료구조 및 알고리즘 이해", "과제 1", "Banker's algorithm", "123456789", "홍길동"):
                self.assertIn(expected, content)
            for forbidden in ("미제공", "제출일", "교수", "Page."):
                self.assertNotIn(forbidden, content)

    def test_rejects_text_outside_print_area(self):
        with tempfile.TemporaryDirectory() as directory:
            output = Path(directory) / "cover.pdf"
            with self.assertRaises(ValueError):
                make_cover("123456789", "가" * 100, output)
            self.assertFalse(output.exists())


if __name__ == "__main__":
    unittest.main()
```

- [ ] **Step 4: 최소 생성 코드를 작성한다**

`tmp/pdfs/hw1-cover/create_cover.py`를 다음 내용으로 만든다.

```python
import os
from pathlib import Path

from reportlab.lib.pagesizes import A4, landscape
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.pdfgen import canvas

FONT_NAME = "CoverAppleGothic"
FONT_FILE = "/System/Library/Fonts/Supplemental/AppleGothic.ttf"
COURSE = "[2026-2] 자료구조 및 알고리즘 이해"


def make_cover(student_id: str, name: str, output_path: Path) -> None:
    student_id = student_id.strip()
    name = name.strip()
    if not student_id or not name or "미제공" in (student_id, name):
        raise ValueError("학번과 이름의 실제 값이 필요합니다.")
    if "\n" in student_id or "\n" in name or "\r" in student_id or "\r" in name:
        raise ValueError("학번과 이름은 한 줄이어야 합니다.")

    pdfmetrics.registerFont(TTFont(FONT_NAME, FONT_FILE))
    page_width, page_height = landscape(A4)
    right_edge = page_width - 72
    identity_lines = (("학번", student_id, 135), ("이름", name, 103))
    for label, value, _ in identity_lines:
        if pdfmetrics.stringWidth(f"{label}  {value}", FONT_NAME, 17) > page_width - 144:
            raise ValueError(f"{label}이 표지의 인쇄 영역보다 깁니다.")
    output_path.parent.mkdir(parents=True, exist_ok=True)
    document = canvas.Canvas(str(output_path), pagesize=(page_width, page_height))
    document.setTitle("과제 1 - Banker's algorithm")
    document.setAuthor("")

    document.setFont(FONT_NAME, 16)
    document.drawString(72, page_height - 82, COURSE)
    document.setLineWidth(0.8)
    document.line(72, page_height - 105, right_edge, page_height - 105)

    document.setFont(FONT_NAME, 42)
    document.drawCentredString(page_width / 2, 322, "과제 1")
    document.setFont(FONT_NAME, 28)
    document.drawCentredString(page_width / 2, 272, "Banker's algorithm")

    for label, value, baseline in identity_lines:
        line = f"{label}  {value}"
        document.setFont(FONT_NAME, 17)
        document.drawRightString(right_edge, baseline, line)

    document.showPage()
    document.save()


if __name__ == "__main__":
    make_cover(
        os.environ.get("COVER_STUDENT_ID", ""),
        os.environ.get("COVER_STUDENT_NAME", ""),
        Path("과제/과제1/표지.pdf"),
    )
```
