# 생명과학 UI 일치 구현 계획

기준: 사용자가 승인한 채팅 설계. 코드 왼쪽, 메모리 가운데. 현재 bio-interactive 템플릿 색상·치수·서랍·재생 바를 Native DOM에 이식한다. 원본 생명과학 파일과 C 엔진/시나리오는 수정하지 않는다.

- [x] 1. UI 회귀 테스트를 작성하고 기존 화면에서 실패를 확인한다.
- [x] 2. 셸/CSS/플레이어에 패널, 단계 목록, 속도, 2D 확대, 접근성을 구현한다.
- [x] 3. 스킬 지침과 검증 스크립트를 갱신하고 Node·독립 검산·브라우저 검증을 수행한다.
- [x] 4. 새 컨텍스트 리뷰와 필요 수정 후, 기존 세 HTML·pack 근거를 백업 보존 하에 갱신한다.
- [x] 5. 최종 파일·노트 링크·보존 해시를 확인하고 검증 기록을 남긴다.

검증: Node 전체 스킬 테스트, 독립 Python 검산, 3자료×3화면×2테마·전체 preset/step, 패널 너비·키보드·모바일 focus trap/닫기/복귀, 2D 화살표 위치, 오프라인 요청/콘솔/넘침. 기존 파일명 유지. evidence 갱신 후 review 해시 재계산. 모든 검토 통과 후 교체하며 오류 시 백업 복구.

Review focus: 서랍 전환 시 숨은 포커스/단축키 충돌; 긴 코드 자동 스크롤이 패널 제목을 밀어내는 문제; 확대 시 SVG 좌표; destroy 후 resize/timer 정리; 갱신한 review 증거의 정합성.
