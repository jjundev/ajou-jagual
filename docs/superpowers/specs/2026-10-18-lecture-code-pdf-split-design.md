# 강의 코드 복습문제 PDF 문제 영역 분해 — 설계

## 의도
강의 코드(lecture-code) 카드의 PDF 왼쪽 패널은 출처 배지·상황·여러 질문이 「구할 것」 한 문단에 뭉쳐 있다. PDF 변환 단계에서 이를 **조건**(상황 문장, 한 줄씩)과 **구할 것**(번호 목록)으로 나누고, `강의 예제 기반 자체 출제 S4 p5 …` 배지 문단은 PDF에서 삭제한 뒤, 0907–1015 10개 팩의 문제·답안 PDF를 재생성·발행한다.

분류: bounded — 기존 `pdf_cards.to_payload`와 템플릿의 기존 `conditions` 슬롯만 사용.

## 완료 후 동작
- 강의 코드 카드: 조건(문장마다 `<p>`) → 구할 것(`<ol>` 질문당 한 항목) → 코드(현행).
- 배지 문단(`<span class="badge">` 포함 `<p>`)은 문제·답안 PDF 어디에도 나오지 않는다.
- `후속 수업 보충:` 문단(0907 p4)은 조건 맨 위 회색 캡션(`<p class="ds-source">`)으로 남긴다(retained-supplement 공개 의무).
- 이미 `<ol>`/`<ul>`가 있거나 질문 0개면 배지만 빼고 원래 문단을 구할 것에 둔다.
- 늘어난 높이는 기존 측정·분할로 「(계속 N)」 페이지가 된다.

## 하지 않는 것
- 복습문제 HTML/MD 원본 수정, 기출·교과서 카드, EC2 템플릿 원본·글꼴 크기.

## 결정
| # | 결정 | 값 |
|---|---|---|
| 1 | 수정 위치 | PDF payload 단계(HTML 원본 불변) |
| 2 | 조건 슬롯 | 템플릿의 기존 `html.conditions` |
| 3 | 문장 분리 | `[.?!]` 다음 공백, 열린 요소·`$…$` 안에서는 분리하지 않음 |
| 4 | 질문 판별 | 끝 괄호주석 제거 후 `(세요\|시오\|하라\|보라)[.)]?$` 또는 `\?$` |
| 5 | 배지 문단 | **PDF에서 삭제** (사용자 지시) |
| 6 | 폴백 | ol/ul 존재 또는 질문 0개 → 원문 유지(배지는 삭제) |
| 7 | 재생성 범위 | 0907–1015 전체 10팩 × 문제·답안 |
| 8 | 발행 | backfill → check → 전 페이지 실화면 검토 → review.json → publish |
| 9 | 적용 카드 | 강의 코드 카드만 [confirmed by default] |
| 10 | HTML 원본 | 이번엔 PDF만 [confirmed by default] |
