## 확정한 의도와 범위

기존 복습문제 HTML을 우선 입력으로 사용하여 문제풀이 입문 설명 HTML·MD를 만든다. 독립 스킬 `ds-problem-explain`으로 이식한다. 과제·실습 PDF 직접 추출, 새 문제 출제, PDF·영상, 제출 코드 변경은 이번 범위에서 제외한다. 과제 카드 지원도 이번 구현에는 포함하지 않는다. 설치 중 실제 수업 문제설명을 발행하지 않는다.

사용자는 기존 HTML 우선과 머신러닝기초 템플릿 그대로 사용을 확정했다. 이 설계는 대화에서 확정한 설계를 구현 계획과 함께 보관한 것이다.

## 인터페이스와 입력

Python 3.10 이상, 실행기는 표준 라이브러리만 사용한다. `python3 .agents/skills/ds-problem-explain/scripts/mpe_cli.py extract --repo . --target 0914 --run tmp/ds-problem-explain/<고유ID>` 다음 `build`, `check`, `publish --run ...`을 사용한다. 날짜, 양끝 포함 날짜 범위, 저장소 내부 복습문제 HTML 경로를 지원한다. 인자 없음은 최신 날짜 팩이며 여러 slug/통합·개별 중복은 경로 명시를 요구한다. 최신 팩이 0문항이면 그 사실과 사용 가능한 비어 있지 않은 후보를 알리고 중단한다. 이전 날짜로 자동 이동하지 않는다.

`.problem` 전체와 원문·코드·그림·참고 풀이를 보존한다. ML 전용 `.conditions/.ask`와 workbook 레이아웃 파일을 요구하지 않는다. 자구알 기존 HTML은 `.problem` 하나에 조건과 질문이 함께 있다. 입력 어댑터는 이 전체를 conditions_html로 보관하고 ask_html은 빈 문자열로 둔다. 렌더러는 ask_html이 없으면 별도 '구할 것' 제목을 넣지 않는다. 설명의 understand에서 조건·질문을 읽어 준다. 원문 데이터는 새로 쓰거나 정규화해 의미를 바꾸지 않는다.

소문항은 명시적 표지 또는 최상위 질문 목록의 (a), (b) 같은 표지를 읽고, 단일 문항은 main이다. 다중 질문임이 분명하지만 경계가 모호하면 문항 id와 원인을 보고하고 추출을 보류한다. 카드 id가 중복되거나 출처가 누락되면 실패한다. 실제 기존 팩의 원문/변형 카드는 같은 기출 출처를 공유하므로 서로 다른 id의 출처 공유는 허용한다. NFC/NFD 경로를 지원하며 저장소 밖·symlink 자원, 없는 그림·anchor는 거부한다.

## 저작과 검증

일곱 직계 구역 `understand → recall → start → solve → verify → pitfall → retry`, 펼친 본문 답, 우측 sum[hidden] 요약을 유지한다. recall은 문제 단서·개념의 뜻·공식/규칙·기호·적용 조건·선택 이유를 연결한다. 공식이 없는 문항은 정의와 판단 기준을 설명한다. solve/verify는 모든 소문항별로 각각 한 번 필요하다. retry는 1~3개다. 추적 문제는 연산별 상태 표, 포인터 문제는 변수·주소·객체를 구분한다. '~해요' 체와 영어 용어 병기, 수업 밖 보충 표기를 사용한다.

원문/은행/강의록/STT/정리노트를 필요한 범위에서 실제로 읽는다. 원문 오타·잘못된 참고 답을 몰래 고치지 않는다. C 실행은 정의된 동작과 입력 가정을 먼저 확인하며 비종료·UB를 정상 정답으로 승인하지 않는다. 독립 시뮬레이션·컴파일 실행·논증 검토의 근거를 evidence에 기록한다. 수학 구분자 검사는 pre/code 내용을 제외한다.

기계 검사는 의미 검토를 대신하지 않는다. source_visual/content/independent/browser와 소문항별 검토는 실제 수행 후 현재 입력·참조·산출물 해시에 묶인다. rebuild는 not_run으로 초기화한다. 충돌·모호함은 disputed이며 해당 팩 발행을 막는다. 다른 독립 팩은 계속 처리할 수 있다.

브라우저는 1280×900/375×812, light/dark에서 모든 문항·목차·이전/다음·요약·수식·그림·코드·상태 표·링크를 확인한다. 콘솔·KaTeX 오류, 누락 자원, 외부 요청, 문서 가로 넘침은 0이어야 한다. 코드 블록 자체의 스크롤은 허용한다. 템플릿 결함이 발견되면 임의로 수정하지 않고 재현 근거를 보고한다.

## 산출물과 발행

입력과 같은 날짜 폴더에 `문제설명_<range>_<slug>.html/.md`, `figures_문제설명_<range>_<slug>/`, `자료_문제설명_<range>_<slug>/`을 발행한다. 생성 기록·검토·조각·검산·로컬 자원을 포함한다. 설명 소유 파일만 백업·교체하며 실패 시 복구한다. 기존 HTML/MD/그림·은행·정리노트는 변경하지 않는다. 정리노트 링크 자동 삽입도 하지 않는다. 커밋·푸시는 별도 사용자 요청 없이 실행하지 않는다.
