# 자구알 PDF 코드 가독성 설계

## 승인된 방향
2026-10-13 채팅에서 grill-yourself 설계를 제시했고 사용자는 `추천대로`를 선택했다. 결정 #6은 **최종 PDF 코드 12pt 고정, 페이지 증가 허용**으로 confirmed. 실행 방식은 이전에 선택한 Native를 유지한다. 이 문서는 구현 승인 자체가 아니다. writing-plans에 따른 계획 검토 후 실행한다.

## 목적과 범위
기존 9개 복습팩의 문제지·해설지 PDF 18개에서 코드의 가독성을 높인다. 문제 코드는 좌측 코드 섹션, 해설 코드는 중앙 풀이 영역을 유지한다. 기출/교과서 출처와 원문 문자·공백·줄 순서를 보존한다. 기존 HTML/MD/문제설명·그림은 수정하지 않는다.

## 시각 계약
- 영문 블록 코드: JetBrains Mono Regular, weight 400. 고정된 공식 배포 파일과 라이선스를 저장소에 포함하고 SHA256 기록. 로컬 시스템 글꼴에 의존하지 않는다.
- 한글 주석: 기존 번들 Pretendard Regular. 글꼴 합자 비활성화.
- 최종 1440×810pt PDF에서 블록 코드 실제 크기는 12pt, 검증 오차 ±0.05pt. CSS 값만으로 통과시키지 않는다.
- 코드 줄 간격 1.45, 검정 글자, 흰 배경, 기존 2mm 패딩과 1mm 모서리 유지.
- 패널/풀이 자동 축소율과 기존 `.prose code {font-size:.92em}`이 블록 코드의 고정 크기를 줄이지 않는다. 문장 속 inline code는 기존 크기를 유지한다.
- 코드가 길면 기존 공통 문제/해설 PageSlice 분할을 사용한다. 기존 139페이지를 맞추려 하지 않는다.
- 가로로 긴 줄은 화면상 줄바꿈과 2ch 내어쓰기로 표시한다. 원문 개행을 추가하지 않는다. 공백과 탭을 유지하고 tab-size는 4.
- 구문 강조와 줄 번호는 추가하지 않는다. 코드 내용을 자동 정렬하거나 수정하지 않는다.

## 호환성과 실패
EC2 원본 problem.html/answer.html/video-16x9.css/render.py의 바이트를 보존하고 DS 확장에서 구현한다. 16:9 전체 구조, 빈 조건 숨김, 작성표 배치, Hint와 이어지는 페이지 계약을 유지한다.
글꼴 누락/해시 불일치/12pt 위반/내용 누락/잘림/리소스 오류는 실패이며 기존 PDF를 교체하지 않는다. 새 보고서의 글꼴 계약을 검사하되 과거 보고서는 새 필드가 없는 경우 기존 검증 경로를 유지한다.

## 완료 증거
먼저 1012 P6 긴 코드를 최종 PDF 전체 페이지와 확대 이미지로 검토한다. 이후 PDF 18개를 재생성하고 모든 페이지를 시각 검토한다. 소스 보존, 글꼴 로딩·실제 사용, 실제 크기, 줄 분할 보존, 표 배치, offline 렌더링, backup/publication 해시를 검증한다. 결과 보고서에 실제 페이지 수, 테스트 결과, 글꼴 버전·라이선스·SHA, 시각 검토 증거, 교체와 백업 정보를 기록한다.
