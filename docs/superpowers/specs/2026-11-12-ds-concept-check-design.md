# 자구알 확인문제 HTML (`ds-concept-check`) — 설계

2026-11-12 대화(`/lateral` 검토 → `/grill-yourself`)에서 확정한 설계를 옮긴 문서다.

## 의도

수업 하나가 끝난 뒤 그 수업에서 **처음 배운 개념**을 이해했는지 5~10분 안에 확인하는 오프라인 HTML 한 장을 만든다. 문항은 전부 Claude가 생성한다. 4지 객관식과 한 단계 값 입력형을 섞고, 누르면 바로 채점하고 보기마다 설명을 보인다. 기출 중심 복습문제를 풀기 **전에** 오개념을 거르는 것이 목적이다.

완료: `복습노트/1102/확인문제_1102_Tree.html`이 정답 검산·블라인드 풀이 일치·브라우저 검사·`pack_layout` 검사를 통과해 발행된다.

분류: architectural — 자구알에는 생성 객관식·즉시 채점·보기별 설명 흐름이 없다(`ds-review-pack/assets/review-template.html`에는 `solved-btn`만 있다).

## 근거 사실

- 자구알 기출 118문항에 객관식은 0개다(trace 70, blank 18, code-write 11, ox 11, code-read 7).
- 생명과학 객관식은 웹과제(5지) 대비용이다. 이 기능은 시험 형식 대비가 아니라 개념 확인용이다.
- 생명과학 `bio-review-pack/scripts/review_interaction.py`와 `assets/review-interaction.{js,css}`, `review-prompt.js`가 객관식 즉시 채점·단답 `답 확인`·`다시 풀기`·복기 프롬프트를 구현한다. 자구알 `review-template.html`은 같은 계열이라 패치 지점(`function setupReview()`, `function setupNote()`, `g.className = 'aid';`, `od:screen` 리스너, `screens[cur].classList.remove(...)`)이 그대로 있다.

## 사용자 동작

- `/ds-concept-check 1102` → 이미 있는 1102 팩을 근거로 `확인문제_1102_Tree.html` 하나를 만든다. 복습팩은 재생성하지 않는다.
- 복습문제와 같은 상단 바·좌우 패널·페이지 넘김 바, 한 화면 한 문항, 수업 흐름(토픽) 순서.
- 객관식(4지): 고르면 즉시 정오, 고른 보기·정답 보기 설명 펼침, 다른 보기는 눌러 펼침, `다시 풀기`.
- 값 입력형: 입력 → `답 확인` → 허용답과 대조.
- 문항마다 근거(`S7 p8`)와 확인하는 개념 이름.
- 마지막에 복기 프롬프트 복사.
- 새로고침하면 답안 초기화, 테마 유지.
- STT 요약·manifest가 없으면 "팩이 없어 근거가 없습니다"로 멈춘다. 확인 목표가 6개 미만이면 만든 만큼 + 사유.

## 이번에 하지 않는 것

- 시험형(일괄 제출·채점표)
- 문제설명(ds-problem-explain) 연결
- 정리노트에서 들어오는 링크(relink)
- `ds-review-pack` 단계 편입, 15개 팩 일괄 생성
- `export-standalone-note` 대응
- 코드 작성형

## 방식 비교

| 안 | 내용 | 선택 |
|---|---|---|
| A | 새 형제 스킬 `ds-concept-check` → 팩 루트 HTML + `.pack/자료_확인문제_*` | ✔ 기존 팩 무변경, 1102 단독 시범 가능 |
| B | `ds-review-pack` 복습문제에 `partE` | — 팩 전체 재생성 필요 |
| C | 정리노트 섹션 끝 삽입 | — 따로 다시 풀 수 없음 |

## 문제 만드는 법

1. **확인 목표**: 팩의 `.pack/자료_복습팩/stt-summary.md`·`manifest.json`·`.pack/정리노트_*.md`에서 `objectives.json`을 만든다. 목표 = `{id, topic_id, 개념, 할 수 있어야 할 것, 근거 S<장> p<쪽> + STT 절, 종류}`. 종류는 `정의·구별`, `규칙 적용`, `절차 결과`, `코드 이해`, `이유`. 이전 강의 복습·예고 토픽·금지어·일화·정리 토픽은 뺀다.
2. **문항**: 목표 1개당 1문항(핵심만 2개까지). `절차 결과`·`규칙 적용` → 값 입력형, 나머지 → 4지 객관식. 오답 보기는 출처(STT 혼동 / 정리노트 주의 / 같은 장 기출 오답)가 있는 오개념만, 보기마다 설명 필수. 정답 위치 A~D 균등(차이 ±1), 부정형 ≤ 1/4. 트리 그림은 공통 헬퍼 SVG(inline `style` 금지). 같은 팩 복습문제와 발문이 겹치면 거부.
3. **검산**: 값 입력형과 계산 가능한 객관식은 파이썬 재계산. 정답을 가린 사본을 독립 에이전트(opus)가 풀어 대조, 다르거나 이의가 있으면 고치고 바뀐 문항만 재풀이, 최대 2회.
