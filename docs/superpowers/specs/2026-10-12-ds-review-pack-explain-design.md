# 복습팩과 문제설명 자동 연결 설계

## 목적과 범위

ds-review-pack이 최종 복습문제 HTML을 만든 뒤 ds-problem-explain의 저작·검산·검토·발행 절차를 자동으로 이어서 수행한다. 기존 리뷰팩 9개에도 현재 전체 문항의 해설을 만든다. 기존 흐름 확장이며 새 실행 엔진은 만들지 않는다.

## 완료 후 동작

- 신규 팩은 정리노트·복습문제·문제설명 각각 HTML과 MD를 제공한다.
- update-existing으로 문제를 갱신하면 전체 문항의 문제설명도 갱신한다.
- lite에서도 해설 작성·독립 검산·브라우저 검증을 수행한다.
- 해설이 실패하면 검증된 복습팩은 보존하고, “복습팩 생성됨 / 문제설명 보류”로 보고한다.
- bank 모드는 현재 절차를 유지한다.
- 출력은 기존 `문제설명_<range>_<slug>.html/.md`, `figures_문제설명_<range>_<slug>/`, `자료_문제설명_<range>_<slug>/`를 사용한다.

## 연결 계약

ds-review-pack의 MD 변환 뒤, 완료 보고 전에 공통 `references/problem-explain.md`를 실행한다. update-existing도 갱신된 복습문제 발행 이후 같은 절차를 실행한다. 최종 복습문제 HTML의 절대 경로를 지정한다. 날짜나 최신 팩 선택에 맡기지 않는다.

순서는 `extract → 원자료 확인 → 모든 문항 해설 저작 → 독립 검산 → build → check → 실제 검토 기록 → publish`다. CLI는 설명을 자동 저작하지 않는다. 호출한다는 문구만 추가하거나 extract/build만 실행해서 완료로 처리하지 않는다.

ds-problem-explain의 SKILL.md, references/authoring.md, references/verification.md를 실제로 읽고 기존 절차를 사용한다. 해설 스킬의 실행기·템플릿·이식 해시 기록은 변경하지 않는다. 별도 설명 CLI, 자동 승인 함수, 새 명령 모드를 추가하지 않는다.

## 보존과 검증

- Python 3.10 이상, 해설 실행기는 표준 라이브러리만 사용한다.
- 원 복습문제 HTML/MD·정리노트·그림·은행·자료_복습팩은 기존 팩 해설 추가 작업에서 변경하지 않는다.
- 일곱 직계 구역 `understand → recall → start → solve → verify → pitfall → retry`를 유지한다.
- 소문항별 solve/verify, 단서와 개념 연결, 실제 첫 줄, 펼친 완성 답, 독립 검산을 제공한다.
- 원문 오타·UB·비종료·정답 충돌은 disputed로 남기고 해당 팩 발행을 보류한다.
- 브라우저는 1280×900·375×812와 light/dark에서 모든 문항을 확인한다.
- 콘솔·KaTeX 오류, 누락 자원, 외부 요청, 문서 가로 넘침은 0이어야 한다.
- 실제 source_visual/content/independent/browser 검토와 현재 원본·참조·산출물 해시가 모두 통과해야 발행한다.
- 기존 해설은 통과 후 백업·교체한다. 미검토·실패·변경된 결과는 기존 해설을 교체하지 않는다.
- 교과서 갱신의 과거 validation.json은 수정하지 않는다. 그 기록의 해설 보존 해시는 당시 사실이다. 새 발행 기록으로 해설 소유 파일의 검증된 교체만 인정하며, 노트·원문·은행 보존 검사는 유지한다.

## 제외와 완료 보고

문제 추가·재출제, 템플릿 변경, 원본 HTML에 링크 삽입, 커밋·푸시는 제외한다. 날짜별 원문/해설 문항 수, 발행·보류 이유, 검증 근거, 백업 경로를 보고한다. 9팩 모두 발행·검증된 경우에만 전체 완료로 표시한다.

## 실행 중 확인한 최소 예외

1005 p3과 1012 p10의 기존 원문 그림은 교과서 렌더러가 만든 정적 inline style을 포함한다. 실행기의 일괄 style 거부로 두 팩의 조립이 실패했다. 원문을 변경하지 않고 source 구역에 한해 figure margin, figure-scroll의 max-width/overflow/background, SVG의 수치 width와 auto height라는 정확한 표시 선언만 허용한다. 해설 저작 style 금지와 나머지 위험 마크업 거부는 유지한다. 원 템플릿과 기존 이식 파일 해시 항목을 유지하며, 추가 코드와 회귀 검사를 local_overrides에 역복원 가능한 삽입 기록으로 붙인다. 원자료/과거 제작자료는 변경하지 않는다.

원문 결함 찾기 문제와 리뷰가 이미 명시한 수정 가정은 결함 및 조건부 답을 설명하는 대상으로 검토할 수 있다. literal 위험 코드의 정상 실행값은 승인하지 않는다. 이 구분으로 0914 p2의 원문에는 유한 T(n)을 부여하지 않고 k++ 가정의 답만 조건부로 설명한다.
