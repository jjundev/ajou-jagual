# 자료구조 과제 1 표지 설계

## 목표와 범위

Notion 본문 PDF 앞에 나중에 붙일 독립된 표지 한 페이지를 만든다. 이번 작업의 결과물은 `과제/과제1/표지.pdf` 하나다. 본문 수정, PDF 병합, 제출은 범위 밖이다.

## 확정 요구사항

- A4 가로, 한 페이지, 페이지 번호 없음.
- 과목명: `[2026-2] 자료구조 및 알고리즘 이해`.
- 과제명: `과제 1`과 `Banker's algorithm`. `과제/과제1/HW1.pdf` 첫 페이지의 표기를 따른다.
- 학번과 이름을 표지에 넣는다. 값은 사용자에게 확인받아야 한다. 현재 `과제/과제1/보고서.md` 7–8행에는 둘 다 `미제공`이다. 실제 값이 없으면 완성본을 만들지 않는다.
- 제출일·교수명은 넣지 않는다.
- 흰 배경, 상단 과목명, 중앙 제목, 하단 학번·이름의 간결한 구성. 글자는 PDF에서 선택·추출 가능해야 한다.

## 제작과 검증

- ReportLab으로 A4 가로 PDF를 생성한다. 한글을 지원하는 시스템 글꼴을 임베드한다.
- 제작 직전에 PDF 스킬의 artifact operation marker를 실행한다.
- `pdfinfo`로 A4 가로와 1페이지를 확인한다.
- `pdftotext`로 과목명, 과제명, 학번, 이름을 확인한다.
- `pdftoppm`으로 렌더링하고 글자 누락, 겹침, 정렬을 눈으로 확인한다.
- 학번·이름이 빠졌거나 `미제공`이면 PDF를 생성하지 않는다.

## 결정

- PDF는 기존 과제 디렉터리에 `표지.pdf`라는 안정적인 이름으로 저장한다.
- 제출일과 교수명은 과제 자료에 다른 날짜나 이름이 보이더라도 표지용으로 추정하지 않는다.
- 생성 보조 스크립트와 렌더링 PNG는 임시 파일이며 최종 산출물에 포함하지 않는다.
