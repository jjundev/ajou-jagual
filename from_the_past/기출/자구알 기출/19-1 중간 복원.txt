8. 아래에는 함수 foo에 대한 코드가 있으며 이 함수를 호출(사용)하였을 때 무엇을 하는 함수인지에 대해서 답을 하시오.
함수 foo는 ( x와 y의 최대공약수를 구해주는 ) 함수이다. (2점)

int foo (int x, int y){
	if (x % y == 0) return y;
	else
		return foo(y, x % y);
}
