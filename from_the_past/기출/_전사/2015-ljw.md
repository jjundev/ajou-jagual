## 1번

1. 다음문제에 답하시오. (총 30 점)
1) 이진트리는 모든 노드가 2개 이하의 서브트리를 가지는 트리이다. 균형 이진 트리를 잘 이용하면 time complexty를 log*n*에 비례하게 만들 수 있다. n을 노드의 수, 높이를 h라고 했을 때, 균형 이진 트리의 time complexty가 log*n*에 비례하게 되는 이유를 설명하시오. (4점)

2) 다음은 수식 트리이다. y=3, z=3일 때 ①중위순회한 결과는? ②결과값은? (6점)
(단, - 는 부호를 나타내는 unary operator, — 는 minus 연산이다. 또한 꼭 필요한 괄호만 넣으시오.)
[그림: 수식 트리. 레벨 0: + / 레벨 1: + 의 왼쪽 ÷, 오른쪽 2 / 레벨 2: ÷ 의 왼쪽 —(minus), 오른쪽 z / 레벨 3: — 의 왼쪽 -(unary), 오른쪽 × / 레벨 4: -(unary)의 자식 y(하나), × 의 왼쪽 6, 오른쪽 3]

3) AVL 트리는 ( ① ) 의 왼쪽 서브트리와 오른쪽 서브트리의 높이 차이를 1이하인 트리로 만들어 탐색시간을 항상 time complexity = ( ② ) 이하로 보장할 수 있다. 이때 왼쪽 서브트리와 오른쪽 서브트리의 높이 차이를 (③ )라 한다. (6점)

4) 다음 괄호를 채우시오. (4점)
• ( ) 정렬 알고리즘의 복잡도는 입력 자료의 구성에 따라 달라지는데, 입력 자료가 이미 정렬되어 있는 경우에는 O(n)번의 비교 연산이 이루어지고, 역순으로 정렬되어 있는 경우에는 O(n²)의 비교 연산이 이루어진다.
• ( ) 정렬 알고리즘은 기수정렬을 제외하고는 평균적으로 가장 빠른 알고리즘으로 divide-and-conquer 방식을 사용하며 특정값을 이용하여 partition한다.

5) 다음 시간 복잡도를 정의하라. (빅오표기법으로) (7 점)

6) 해싱의 클러스터링(집중과 결합) 현상은 왜 발생하며 이를 해결할 수 있는 방법은? (3점)

**원본 답:** 1) 노드의 개수가 높이 h인 균형 트리에서는 n=2^h-1, 2^h=n+1 h=log2(n+1) 이므로 균형 잡힌 경우 logn에 비례

6) 여러 key 값이 같은 주소로 해시되면 뒤따르는 순차 탐색이 너무 많은 (비용) 클러스터링 현상을 발생시킨다. 따라서 이를 전체 주소 범위에 균일하게 분포하도록 이차[?]사법을 사용.
