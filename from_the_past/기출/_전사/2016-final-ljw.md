1) 다음은 무슨 정렬방법인가? 그리고 장점과 단점 한 가지만 쓰시오.
```c
{
  int i, j, key;
  for(i=1; i<n; i++){
       key = list[i];
       for(j=i-1; j>=0 && list[j]>key; j--)
             list[j+1] = list[j]; /* 레코드의 오른쪽 이동 */
       list[j+1] = key;      /* 선택된 key값의 위치 */
  }
}
```
2) 정렬 방법 중에 최선, 평균, 최악의 time complexity가 동일한 정렬방법이 있다(단, 기수 정렬 제외)
①(    )정렬과 (    ) 정렬 알고리즘의 time complexity는 (    ) 이다.
②(    )정렬과 (    ) 정렬 알고리즘의 time complexity는 (    ) 이다.

학생 답안(채점됨): 1) ① insertion ② 장점: 이미 정렬되어 있으면 효율적 ③ 단점: 레코드가 크면 불리(이동). 2) ① 선택, 버블, O(n²) ② 힙, 합병, O(nlogn)
