## 적용 방법

이 기준을 읽은 뒤 현재 과제 지시·제공 코드·학생 코드·공식 변경 사항을 확인한다. 공통 기준과 과제별 요구를 함께 적용하며, 명시적인 공식 변경은 해당 범위에 반영한다. 두 공식 자료가 모순되고 변경 관계가 불명확하면 `자료 충돌`로 기록한다. 과제별 지시가 공통 항목을 언급하지 않았다는 이유만으로 그 항목을 면제하지 않는다.

[과목 보고서 양식](data-structures-course-format.md)은 필수 조건 안에서 적용할 작성자 선호이고, [과제1 사례](hw1-case-study.md)는 설명 수준과 실행 분석을 참고할 자료다. 어느 쪽도 공식 기준을 대체하거나 후속 과제 점수를 보장하지 않는다. 기존에 확인한 미확정 항목은 아래 기록을 재사용하고, 새 근거 없이 같은 확인 질문을 반복하지 않는다. 충돌하지 않는 작업은 계속한다.

## #7 미확정·적용 보류 기록

사용자는 별도 공식 안내가 없다고 답했고, 기존 설계 #7의 두 항목을 미확정으로 기록하도록 요청했다. 따라서 아래 항목은 **확정 적용 규정에 포함하지 않는다**. 다만 이전 대화에서 주장한 화면·추출문 충돌은 정확한 원본 재확인 결과와 구분한다.

| 항목 | 현재 원본에서 관찰한 내용 | 이전 대화의 충돌 주장 | 적용 상태 |
