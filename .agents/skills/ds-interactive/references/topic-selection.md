# 주제 선택과 출처

날짜 모드에서 실제 노트의 질문·코드·그림을 읽는다. 2–4개의 유용한 주제는 상한 가이드이며 강제 개수가 아니다. 소스가 충분한 한 함수·한 현상은 하나의 자료로 좁힌다.

| 범위 | 탐색 후보 |
|---|---|
| 포인터 | 값/주소 전달, p와 *p, 별칭, 이중 포인터, 수명 |
| 연결리스트 | head 교체, link 필드 변경, 삽입/삭제 순서 |
| 스택·큐 | push/pop, front/rear, 순환 인덱스 |
| 재귀·트리 | 호출/반환, 순회, 노드 연결 |
| 정렬·탐색·그래프 | 비교/이동, 경계, 방문·거리 변화 |

첫 세 예제는 examples/0928 아래 있다. p22 강의 swap 본문은 보존한다. 값 비교 모드·별칭은 보충. pointer-target은 p20 &/* 구분에서 보충한 함수 예제. double-pointer는 p25 주소 사슬에서 함수 호출로 확장한 보충이다. 두 번째·세 번째를 강의 원문 코드로 소개하지 않는다.

resolver는 날짜 폴더의 중복 후보를 숨기지 않는다. 명시 주제는 주제별 출력이 기본이며, 대응 날짜가 명백하면 그 날짜를 별도 resolve한다. C 파일 입력은 원문을 읽고 경로·해시를 source.json에 기록한다. 붙여 넣기는 원문 source.c를 보존한다. 의사코드는 C 실행 증거를 만들지 않는다.

새 자료구조 주제는 해당 상태·시각화 어댑터를 먼저 정의한다. 첫 버전의 c-memory 화면을 범용 큐/트리 렌더러라고 주장하지 않는다.
