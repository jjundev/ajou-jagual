# 학습 화면

## 디자인 기준

생명과학 bio-interactive의 현재 `assets/template.dc.html`과 같은 공통 UI를 사용한다. 색상만 비슷하게 만드는 것이 아니라 상단 바, 접고 너비를 조절하는 좌우 패널, 중앙 장면, 하단 재생 바, 모바일 서랍을 유지한다. 이 저장소 assets에 필요한 CSS·SVG·Native DOM 동작이 포함되어 있으므로 다른 과목 저장소를 실행 의존성으로 읽지 않는다. 참고 원본 해시는 assets/vendor/provenance.json에 있다.

라이트 배경 #ffffff, surface #f7f8fa, 강조 #1677ff. 다크 배경 #17171c, surface #212128, 강조 #3182f6. 나머지 ink/line/button/scroll 토큰도 공통 CSS를 따른다. 생명과학과 같은 Pretendard 1.3.9의 실제 Regular(400)·Medium(500)·SemiBold(600)·Bold(700)를 복습노트 공용 Pretendard 스타일시트에서 불러오며, 코드·주소만 고정폭이다. 8px 모서리, 4/8/12/16/24/32/48px 간격을 쓴다.

## 포인터 자료의 배치와 조작

상단: 조작 토글 · 제목 · 시나리오의 mode 선택 버튼(있을 때만) · 테마 · 설명 토글. 640px 미만 제목 숨김. 긴 모드 이름은 좁은 화면에서 줄바꿈하고 모든 조작부가 실제 뷰포트 안에 있어야 한다.

왼쪽: 주소/화살표 보기 옵션 → 사례·초기값 → 실행 코드 → 전체 단계 목록. 코드와 단계는 같은 Trace를 따르며 단계 목록을 4–7개로 억지로 축약하지 않는다. 현재 줄 추적은 코드 내부 스크롤만 바꾼다. 단계 목록은 선택 버튼을 숨기거나 재생마다 패널 전체를 스크롤하지 않는다.

가운데: 호출 프레임·Cell·포인터를 2D DOM/SVG로 표시한다. 확대/축소/화면 맞춤은 보기에만 적용하고 입력·단계를 바꾸지 않는다. 재생 바를 장면 아래에 배치해 메모리를 가리지 않는다. 처음/이전/재생/다음/마지막, 단계 슬라이더, 0.5/1/2배 선택 버튼을 제공한다.

오른쪽: 지금 일어나는 일 → 변경 전후 → 선택한 변수 → 꼭 기억해요 → 출처. Cell은 이름·타입·자신의 주소·저장 값을 표시하고, 선택 상세는 대상 값도 구별한다. NULL·미초기화·수명 종료를 텍스트로 구별한다. 읽기 점선, 쓰기 강조 테두리와 화살표는 실제 상태에서 계산한다.

1024px 이상: 좌우 패널을 독립적으로 접고 포인터 드래그 또는 separator 좌우 화살표로 너비를 조절한다. Home은 기본 너비. 중앙 장면을 최소 320px 남긴다. 기본 왼쪽 clamp(260px,20vw,320px), 오른쪽 clamp(320px,24vw,400px).

1024px 미만: 왼쪽 min(304px,88vw), 오른쪽 min(360px,88vw) 서랍. 최초에는 둘 다 닫혀 있고 한 번에 하나만 열린다. 배경 가림막·닫기·Escape로 닫는다. 열린 서랍 안에 Tab 포커스를 유지하고 닫으면 해당 토글로 복귀한다. 중앙 조작부는 서랍 동안 inert. 크기 전환 후 숨은 패널에 포커스를 남기지 않는다.

입력/사례/모드 변경은 재생 정지·초기 단계·선택 해제. 마지막에서 자동 정지. 무효 입력은 이유·수정 범위를 안내하고 실행 및 단계 선택을 막는다. 같은 값의 중복 input/change 이벤트로 실행을 다시 초기화하지 않는다.

44px 이상 주요 조작부, aria-pressed/expanded, 키보드 방향키·Space·Home/End, 설명 aria-live, 포커스 표시, reduced-motion을 지원한다. 아이콘은 SVG를 쓴다. 문서 스크롤 폭뿐 아니라 패널·상단·재생 바의 실제 경계도 확인한다. 구현 파일명·내부 데이터 형식은 학습자 조작 기능으로 노출하지 않는다.

## 트리 재귀 순회

1280px 이상에서는 왼쪽에 실행 코드와 줄 기록, 가운데에 전체 트리와 출력, 오른쪽에 호출 스택과 접힌 예제 정보를 배치한다. 두 패널은 기본으로 열고 상단 좌우 아이콘으로 독립적으로 접는다. 기본 너비는 왼쪽 320px, 오른쪽 300px이다. 안쪽 경계를 끌거나 포커스한 뒤 좌우 화살표(16px, Shift와 함께 64px)로 조절하고, 두 번 클릭하거나 Home을 눌러 기본 너비를 복원한다. 너비는 브라우저에 각각 저장하며, 중앙에 최소 400px를 남기도록 표시 너비를 줄일 수 있다. 화면이 다시 넓어지면 저장한 값을 복원한다. 1280px 미만에서는 두 서랍을 닫은 상태로 시작하고 상단 아이콘으로 한쪽씩 연다. 닫기·바깥 영역·Escape로 닫고 해당 아이콘으로 포커스를 돌린다. 사례 선택은 상단, 재생 막대는 하단에 둔다. 줄 기록 바로 아래에는 선택한 단계에서 호출한 자식, 출력한 값, 복귀한 호출을 실제 상태에 맞게 한 문장으로 설명한다. 왼쪽 패널을 접거나 좁은 화면을 쓰면 같은 설명을 출력 아래로 옮긴다. 코드와 줄 기록 사이 20px, 기록 제목과 목록 사이 8px, 기록 목록과 설명 사이 12px, 트리와 출력 사이 12px, 스택과 예제 정보 사이 20px를 둔다. 코드의 ▶는 이어서 실행할 줄을 가리킨다.

코드 아래의 줄 기록은 실행 코드와 같은 제목 서식을 쓰며 왼쪽 패널을 열면 바로 보인다. 줄 기록은 일반 제목과 스크롤 목록으로 구성한다. 한 행에 실제 실행한 호출 이름, 줄 번호와 짧은 단계명을 표시한다. 데스크톱과 모바일에서 목록 높이는 세 행이다. 자동 추적은 0단계를 맨 위에, 이후 단계는 가운데에 놓는다. 마지막 단계에는 아래쪽에 한 행 높이의 여백을 둔다. 직접 스크롤하면 따라가기를 멈추며, 실행 위치로 버튼으로 재개한다. 행을 선택하면 해당 단계로 이동한다. 사례를 바꾸면 기록은 첫 행부터 보여 준다.

1280px 이상에서는 재생 중에도 오른쪽 호출 스택을 갱신한다. 노드 메모리는 오른쪽 상세 패널에서 연다. 1280px 미만에서는 호출 스택과 예제 정보를 오른쪽 서랍에서, 노드 메모리를 하단 시트에서 연다. 서랍이나 노드 메모리를 열면 자동 재생을 정지한다. 선택한 호출을 따라 실행 위치를 바꿀 때 저장 값과 수명을 각각의 상태에서 읽는다.

하단 재생 바에 마우스를 올리거나 현재 배속 버튼을 누르면 바 위에 재생 옵션이 열린다. 여기에서 배속을 바꾸거나 첫·마지막 단계와 이전·다음 출력으로 이동할 수 있다. 팝업을 열어도 재생은 계속되고, 다른 단계로 이동하면 일시정지한다.

트리 화면에서는 확대·축소·화면 맞춤 버튼과 다음 실행 카드를 생략한다. 현재 실행은 코드 강조·선택된 기록 행·단계 설명으로 읽을 수 있다. 출처와 근거는 시나리오와 검토 자료에 기록하고 코드 밑의 출처 안내 문구는 숨긴다. 트리의 노드 좌표는 같은 사례를 실행하는 동안 고정한다. 굵은 경로와 채운 노드로 활성 경로와 현재 노드를 표시한다. NULL 호출에는 점선과 NULL 글자를 표시한다. 출력 직후 노드에 순번을 붙인다. 이전·다음 출력 버튼은 현재 위치보다 엄격히 앞·뒤의 출력 직후에 멈춘다. 되감으면 출력과 번호가 함께 돌아간다.

호출 스택은 활성 호출부터 표시한다. 대기 호출에는 재개할 줄을, 방금 반환한 호출에는 지역 Cell의 수명 종료를 표시한다. 메모리의 포인터 값은 대상 노드 주소로, 각 Cell의 자기 주소는 별도로 표현한다. 노드는 객체 ID, 호출은 프레임 ID로 추적한다. 노드 메모리는 선택한 노드의 세 필드를 표로 표시한다. 호출 스택에서 한 행을 펼치면 해당 프레임의 저장 값과 주소를 표시한다.
