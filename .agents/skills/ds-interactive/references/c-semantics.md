# C 의미 경계

- 인자는 값으로 전달한다. 주소 값도 복사한다. 매개변수 자신의 주소와 저장된 대상 주소는 다르다.
- `p=next`는 p에 쓰고 `*p=value`는 p의 대상에 쓴다. `*pp=next`는 pp의 대상인 포인터 변수에 쓴다. q의 대상이 a에서 b로 바뀌어도 a,b의 정수는 변하지 않는다.
- 두 매개변수에 같은 주소가 들어갈 수 있다. 서로 다른 Cell을 유지하며 동일 대상을 공유한다. 쓰기 이후 다음 읽기는 변경된 값을 읽어야 한다.
- 구조체 복사는 필드의 값 복사다. 포인터 필드가 있으면 대상은 공유하며 객체를 깊게 복사하지 않는다. 배열 매개변수는 포인터로 조정된다. 배열 전체 복사처럼 그리지 않는다.
- read는 초기화/수명/대상 연결을 검사한다. write도 대상의 수명·실제 포인터 사슬을 검사한다. uninitialized/NULL/범위 밖/종료 저장 공간/잘못된 해제는 진단으로 중단한다.
- free(NULL)은 정상 무동작. free는 할당 객체 시작 주소만 받는다. 해제 후 모든 살아 있는 별칭은 indeterminate가 된다. 과거 객체는 `수명 종료` 흔적으로만 표시하며 유효한 포인터처럼 따라가지 않는다. 읽지 않고 NULL을 새로 대입하는 것은 가능하다.
- return은 활성 호출의 자동 변수와 자동 객체를 종료하고 살아 있는 별칭을 무효화한다. 반환값은 종료 전에 평가·전달한다. main은 마지막 관찰 단계까지 유지한다.
- 모든 주소는 기호다. int=4바이트, 특정 스택 방향, 실제 주소, 물리 배치를 일반 사실로 고정하지 않는다.
- `f(i++,i++)` 같은 식의 평가 순서를 하나의 필수 순서로 만들지 않는다. 부수 효과의 순서와 UB를 구분해 보류 또는 diagnostic으로 표시한다. unsupported 코드를 자동으로 정상 실행시키지 않는다.
- 이 엔진은 명시 이벤트 검증기다. 타입 체계 전체, 포인터 산술 표현식, C 라이브러리, stdout 자동 실행을 제공하지 않는다. 이런 문법은 저작 이벤트와 별도 검산을 추가한 경우에만 다룬다.
