# 자구알 복습노트 내보내기

`복습노트/<날짜>/`의 정리노트·복습문제·문제설명·확인문제·인터랙티브를 각각 독립 HTML로 만든다. 기본 묶음에는 기존 문제·답안 PDF도 포함한다. 원본 노트·PDF·템플릿은 수정하지 않는다.

## 실행

`SKILL`은 이 파일의 폴더, `REPO`는 자구알 저장소 루트다. 사용할 수 있는 Python 3 실행기(`python` 또는 `python3`)로 아래 도구를 실행한다. 실행 의존성은 표준 라이브러리뿐이다. 저장소 밖에서 실행하면 `--repo`에 절대 경로를 지정한다.

```text
python <SKILL>/scripts/export_standalone_note.py 1015
python <SKILL>/scripts/export_standalone_note.py 1008 1015
python <SKILL>/scripts/export_standalone_note.py 0907-1015
python <SKILL>/scripts/export_standalone_note.py all
python <SKILL>/scripts/export_standalone_note.py 1015 --kind 문제설명
python <SKILL>/scripts/export_standalone_note.py <HTML절대경로>
python <SKILL>/scripts/export_standalone_note.py 1015 --no-pdf --out <출력폴더>
```

- 날짜는 `MMDD` 또는 실제 팩 이름 `MMDD-MMDD`. 범위는 안에 완전히 들어오는 기존 팩을 선택한다. 인자가 없으면 사용 가능한 날짜를 보여준다. 사용자가 날짜를 생략한 경우 대화에서 범위를 알 수 있으면 사용하고, 알 수 없으면 목록을 보여주고 날짜를 묻는다.
- 종류를 말하지 않으면 선택한 날짜의 학습 HTML과 기존 `복습문제_<날짜>_<주제>-문제.pdf`·`-답안.pdf`를 포함한다. PDF는 원본 바이트를 복사한다.
- `--kind 정리노트|복습문제|문제설명|확인문제|인터렉티브`는 해당 종류를 고른다. 인터랙티브가 여러 개면 모두 포함한다. 한 파일만 필요하거나 `주제별` 자료를 옮길 때는 HTML 경로를 직접 지정한다. `--no-pdf`는 기본 묶음에서 PDF를 뺀다.
- 기본 출력은 `~/Downloads`. 파일 1개면 원본과 같은 이름의 HTML, 2개 이상이면 `자구알_복습노트_<날짜>.zip`. 여러 날짜는 첫·끝을 `~`로 연결한다. 실제 포함 날짜는 출력 목록으로 확인한다.
- ZIP 안은 `<날짜>/<원본파일명>` 구조다. **압축을 푼 뒤** 열어야 문서 간 이동이 된다. 같은 이름의 출력은 검증 후 교체하며 기존 낱개 HTML은 지우지 않는다.

## 휴대성과 실패 처리

CSS·JS·그림·글꼴을 HTML 안에 넣는다. 공용 Pretendard는 OFL 고지와 함께 포함한다. 예전 HTML의 jsDelivr 주소는 동봉된 KaTeX 0.16.11·Pretendard 1.3.9로 치환한다. 글꼴은 CSS에 선언된 굵기의 woff2를 사용하며 결과가 클 수 있다.

동봉본과 해시가 같은 라이브러리를 제외한 동적 로딩 스크립트, 모듈·async 스크립트, iframe, srcset 등 지원하지 않는 의존성은 실패한다. 알 수 없는 외부 표시 자원을 자동 다운로드하지 않는다. 실패하면 원인과 경로를 보고하고 성공이라고 하지 않는다. 최종 결과는 모든 검사를 통과한 뒤 교체한다.

묶음에 포함된 HTML·PDF 링크는 재연결하고 HTML fragment까지 검사한다. 포함되지 않은 로컬 문서 링크는 `span`으로 바꾸고 목록을 보고한다. 내부 목차와 일반 웹 이동 링크는 유지한다. 본문·문제·답안의 내용이나 UI를 새로 작성하지 않는다.

## 확인과 보고

종료 코드 0과 `검사 통과`를 확인한다. 출력 경로·크기·파일 수·건너뛴 종류·제외한 로컬 링크·기존 파일 알림을 요약한다. 스크립트 검사는 렌더 확인을 대신하지 않는다.

처음 도입하거나 스크립트를 변경했다면 각 종류의 대표 HTML을 네트워크 차단 브라우저에서 열어 다음을 확인한다. 평소 내보내기는 대표 HTML 하나로 확인할 수 있다.

- 수식 `.katex` 렌더와 `.katex-error` 0, 깨진 그림 0, Pretendard 로드.
- 답안 펼치기·실제 위젯·그림 확대 등 문서에 있는 상호작용.
- 묶음 안의 문서 링크와 해당 문항 이동.

`file://`로 실제 파일을 열어 확인하는 것을 우선한다. 도구가 거부하면 임시 폴더에 압축을 풀고 `127.0.0.1` HTTP 서버로 확인한 뒤 서버를 종료한다. HTTP 확인만 했다면 `file:// 미확인`이라고 구분한다. 도구가 없으면 렌더 미확인을 명시한다. Windows 탐색기 더블클릭이나 다른 기기의 확인은 실제 수행했을 때만 보고한다.
