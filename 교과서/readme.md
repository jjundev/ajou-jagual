# 교과서 연습문제

교과서의 14장 연습문제 213개를 장별 UTF-8 JSON으로 정리했다. 원본 PDF는 `origin/`, 문제의 그림과 표를 다시 그린 SVG 46개는 `assets/`에 있다.

각 JSON은 해당 장의 `sources`, `chapters`, `questions`, `assets`와 `schema_version`을 포함한다. 문제 ID는 `ch04-q01` 형식이며 원문·코드·보기·소문항·출처와 검토 기록을 보존한다. 직접 작성한 정답이나 해설은 포함하지 않는다. 필기는 `observations`, 원본 오류와 외부 본문 참조는 `issues`에 구분했다.

## 읽기와 검증

[전체 문제 미리보기](제작자료/preview.html)에서 문제·그림·원본 PDF 링크를 확인할 수 있다. 출처와 자산의 `path`는 이 `교과서/` 폴더를 기준으로 해석한다. JSON을 다른 위치로 옮길 때는 참조 파일의 상대 위치도 유지해야 한다.

장별 파일은 각각 읽을 수 있다. 전체 완성도 검증은 14개 JSON을 메모리에서 합쳐 원본 PDF·인벤토리·그림 모델·검토 해시와 비교한다. 통합 JSON 파일은 생성하지 않는다.

`제작자료/` 폴더에서 실행한다.

```sh
python3 -m venv /tmp/textbook-check-venv
/tmp/textbook-check-venv/bin/python -m pip install -r scripts/requirements.txt
/tmp/textbook-check-venv/bin/python scripts/validate.py .. --complete
/tmp/textbook-check-venv/bin/python -m pytest -q
```

도구와 검수 기록은 [제작자료 안내](제작자료/README.md)에 정리했다. 임시 렌더·크롭·후보 자료는 최종 배포와 Git 커밋에 포함하지 않는다.
